# 放大矩阵模板（Amplification Matrix）

基于 Meta 1×6×5=30 框架的逆向放大矩阵，用于把拆解结果转化为可执行的放大方案。

## 来源

这份矩阵来自 2026-07-20 记录的 Meta 广告素材工业化方法（小红书 @AYLA 独立站操盘手），并适配为内容创作场景。

## 核心逻辑

一条爆款 = 核心信息（发动机）× 格式 × 变量。

逆向拆解时：把原版的每个变量位拆出来，逐个判断「保留/升级/替换/差异化」。

正向放大时：固定发动机，有计划地替换变量，每条只换一个，测试哪个组合最爆。

## 6 个变量位

### VAR1 · Hook（钩子）

原版用了什么钩子（套用钩子分类学）。

放大选项：
- **保留**：钩子是发动机的一部分 → 换皮保留逻辑
- **升级**：钩子有效但不够强 → 换更强的同类钩子
- **替换**：钩子不适合你的领域 → 换适合的钩子类型
- **差异化**：和原版用不同的钩子路径 → 建立辨识度

每次只换一个钩子变量，对比测试哪个最有效。

### VAR2 · 主角（谁在说）

- 品牌方说
- 用户说（UGC）
- 创始人说
- 专家说
- 第三方/媒体说

放大逻辑：同一信息，换不同人说，触达不同人群。

### VAR3 · 场景（在哪说）

- 日常使用场景
- 开箱场景
- 对比场景
- 极端/特殊场景
- 失败案例场景
- 使用后场景

放大逻辑：同一产品/信息，在不同场景展示，触达不同需求阶段的人。

### VAR4 · 证据（凭什么信）

- 数据/数字
- 用户评价
- 前后对比
- 实操演示
- 权威背书
- 第三方检测

放大逻辑：同一主张，用不同证据支撑，提升不同人群的信任。

### VAR5 · 机制（为什么有效）

解释产品/方法为什么能解决问题。

- 科学原理
- 类比/比喻
- 可视化演示
- 专家解释
- 用户证言

### VAR6 · Offer（行动理由）

- 折扣/价格
- 套装/组合
- 赠品/附加价值
- 免邮/低门槛
- 限时理由
- 保证/退换

## 放大矩阵模板

填这个表来做放大决策：

```
原版爆款：[内容描述]
核心信息（发动机）：[一句话]

| 变量位 | 原版 | 是发动机吗 | 我的处理 | 具体方案 |
|--------|------|-----------|---------|----------|
| Hook | | 是/否 | 保留/升级/替换/差异化 | |
| 主角 | | 是/否 | | |
| 场景 | | 是/否 | | |
| 证据 | | 是/否 | | |
| 机制 | | 是/否 | | |
| Offer | | 是/否 | | |
```

## 放大前 Gate（必须过）

放大前 gate 共 5 条：**验证数据 / 指标不偏科 / 可一句话复述 / 非单点红利 / 发动机可移植**。

唯一权威定义见本 skill 的 `SKILL.md` 模块五「放大前 Gate」，此处只引用不重复展开。

**S 级标准**：能持续产出且数据稳定的内容逻辑才值得系统放大。没过 gate 就放大 = 放大噪声。

## 变量替换的测试纪律

放大时每次只换一个变量（来自 Meta 框架核心原则）：

- 为什么：换多个变量 → 不知道是哪个变量起作用 → 无法优化
- 怎么做：第一批全保留原版逻辑（换皮），第二批换 Hook，第三批换场景……
- 对比：每批的数据对比，找出哪个变量替换最有效

## 与竞品逆向网格的关系

放大矩阵的逆向用法 = 竞品逆向解剖网格：

1. 把同领域多个竞品的爆款填进矩阵
2. 看哪条核心信息被反复用不同格式/变量投放
3. 那条 = 他们验证过在赚钱/引流的核心信息
4. 竞品的投放行为替你做了「什么有效」的验证

这是比「猜什么会火」更可靠的选品/选题方法。
