# L4 · 放大架构 + 脚本生成

把前三层的发现变成你能直接用的东西：放大方案 + 差异化定位 + 可拍脚本。

这是整个 skill 组合的出口。前三层是「理解」，这一层是「行动」。

## 能力边界（诚实纪律 · 封路条款）

本层做的是**基于已证欲望结构的结构性放大策略**，不是爆款保证：
- **单帖是否爆不可事前预测**——爆款由算法分发 + 粉丝基数 + 运气支配（引擎侧 SMTPD/MusicLab/E1 三重实锤），任何「这条会爆」的承诺都是虚假宣称。本层禁止承诺具体某条内容会火，也禁止承诺「最佳发布时机」（回归结构主导，同样封路）。
- 本层能做的是**提高期望命中率**：把原版跑通的欲望发动机（受众级共振读出已验证 ρ≈0.5）迁移到你的领域，用差异化避免搬运。这是「押更好的结构」，不是「保证中奖」。
- 放大前 Gate（模块五）就是这条纪律的执行闸门——强制小批量验证、拒绝单点红利，防止把「一次偶然爆款」当成「可复制规律」。

## 前提

L4 建立在 L1-L3 之上。动手前必须确认：
- L2 的核心结构机制（什么钩子 + 什么叙事弧）
- L3 的核心心理结论（戳了什么痛点/欲望/触发器）

如果没有跑过 L3，先口头确认心理假设，否则脚本无根。

## 模块一：发动机识别

爆款的「发动机」 = 动了它这条就不火的那个核心元素。

识别方法：逐个假设「如果去掉这个元素，内容还火吗」：

| 元素 | 去掉后还火吗 | 判断 |
|------|-------------|------|
| 钩子的特定措辞 | | |
| 视觉奇观（如电焊机的火花） | | |
| 特定出镜者/达人 | | |
| 特定产品/场景 | | |
| 特定情绪转折 | | |
| 特定信息密度 | | |

**发动机特征**：去掉它完播率会断崖下跌的元素。一条内容通常只有 1-2 个真发动机。

**输出**：一句话讲清发动机是什么。例：
- 电焊机视频的发动机 = 纯视觉奇观（焊接火花+操作声），不需要任何文字和叙事
- Citta 香水的发动机 = 「真诚测评」人设 + 问题-放大-解决结构
- 车载香薰的发动机 = 「朋友买了100万的车你就送这个」的豪车锚定钩子

### 广告内容专用发动机分类

广告内容的发动机和非广告不同——非广告靠情感/奇观/共鸣驱动，广告靠转化机制驱动。识别广告发动机时，检查以下 8 种类型，判断这条广告的核心驱动力是哪个：

| 发动机类型 | 核心机制 | 识别信号 | 典型场景 |
|-----------|---------|---------|---------|
| **价格发动机** | 价格优势/折扣/性价比是核心卖点 | "只要XX""限时XX折""比XX便宜" | 电商/促销/白牌 |
| **稀缺性发动机** | 限量/限时/独家制造紧迫感 | "仅剩XX件""限时XX小时""独家发售" | 预售/限量/直播间 |
| **权威发动机** | 专家/机构/数据背书建立信任 | "XX认证""XX推荐""临床验证" | 健康/科技/金融 |
| **社会证明发动机** | 用户量/评价/排行榜制造从众 | "XX人已买""好评XX万""销量第X" | 大众消费品/电商 |
| **情感发动机** | 故事/共鸣/价值观建立情感连接 | 催泪故事/励志叙事/价值观表达 | 品牌/公益/情感品类 |
| **好奇发动机** | 悬念/揭秘/反常识激发探索欲 | "你绝对想不到""揭秘""真相" | 知识付费/新奇产品 |
| **身份发动机** | 使用产品 = 成为某种人 | "成功人士的选择""精致女人的XX" | 奢侈品/生活方式/高端 |
| **恐惧发动机** | 痛点放大/损失厌恶驱动行动 | "你再不XX就晚了""XX正在毁掉你" | 保险/健康/教育 |

**判断方法**：遮住这条广告最突出的那个元素，如果观众购买意愿断崖下跌 → 那就是发动机。
- 注意：广告可能同时有多个发动机（如「稀缺性+价格」双驱），但要区分主次
- **常见错误**：把情感元素误判为发动机（很多广告有情感渲染但真正驱动转化的是价格/稀缺性）
- **校准教训**：之前 skill 对广告内容倾向识别「情感发动机」，对价格/稀缺性不够灵敏。识别广告发动机时，优先检查转化机制类发动机（价格/稀缺性/权威/社会证明），再检查情感类

## 模块二：放大矩阵

复用 Meta 1×6×5=30 框架的逆向思维。读 `references/amplification-matrix.md` 获取完整矩阵模板。

把爆款的元素拆成 6 个变量位，逐个判断怎么处理：

| 变量位 | 原版用了什么 | 我的处理 | 策略 |
|--------|-------------|---------|------|
| Hook（钩子） | | | 保留/升级/替换/差异化 |
| 主角（谁在说） | | | 保留/升级/替换/差异化 |
| 场景（在哪说） | | | 保留/升级/替换/差异化 |
| 证据（凭什么信） | | | 保留/升级/替换/差异化 |
| 机制（为什么有效） | | | 保留/升级/替换/差异化 |
| Offer（行动理由） | | | 保留/升级/替换/差异化 |

四种处理策略：

- **保留**：发动机元素，原样保留（但换皮换领域）
- **升级**：原版做得不够好的地方，做得更好（更高质量的视觉/更强的证据/更精准的人群）
- **替换**：非核心变量，换成适合你领域的版本
- **差异化**：必须和原版不同的地方（避免搬运，建立辨识度）

**关键判断**：哪些是发动机（必须保留），哪些是壳（可以换）。

## 模块三：差异化定位

回答一个问题：你的版本和原版的核心区别是什么。

### 差异化维度（至少选一个做到极致）

1. **人群差异化**：原版打 A 人群，你打 B 人群（更细分/更精准/原版忽略的）
2. **场景差异化**：原版在 A 场景，你换到更贴你产品的 B 场景
3. **情绪差异化**：原版走 A 情绪（如搞笑），你走 B 情绪（如温情/震撼）
4. **证据差异化**：原版的信任建立方式弱，你用更强的证据（真实验证/数据/对比）
5. **价值差异化**：原版只给情绪价值，你额外给实用价值（教程/清单/方法论）
6. **风格差异化**：原版的视觉/语言风格，你用完全不同的风格（UGC vs 精品/快节奏 vs 慢叙事）

### 差异化定位一句话

格式：「和 [原版] 不同，我的版本 [差异化方向]，因为 [我的优势/人群需求]」

例：
- 「和车载香薰原版不同，我的版本从车主第一视角拍，因为我的产品是车载场景原生的」
- 「和 Citta 测评不同，我的版本用 7 天连续记录代替一次测评，因为持久性是香水的核心质疑」

### 反搬运 gate

三个问题，任何一个答「否」就要重新差异化：
1. 把我的版本和原版放一起，观众能一眼看出是两个不同创作者的作品吗？
2. 我去掉原版的任何一个视觉元素/措辞/场景，我的版本还成立吗？
3. 如果原版创作者看到我的版本，会觉得是「致敬」还是「搬运」？

## 模块四：脚本骨架 + 放大决策要点

**本层只出骨架，完整成稿走 L5 `viral-content-generator`。** 本模块产出分镜结构定义、文案要点和钩子候选方向——它们是放大决策的载体（命脉变量落在哪一镜、差异化体现在哪里）。完整成稿（逐字口播稿/成品标题/完整图文）的唯一出口收敛在 L5，本层不产出可直接发布的成稿。

### 分镜骨架（分镜结构定义）

产出逐镜分镜骨架，每镜记录：

| 镜号 | 时长 | 画面 | 屏幕文字 | 音频/口播 | 表演指导 | 功能 |
|------|------|------|----------|-----------|----------|------|
| 1 | 0-3s | | | | | 钩子 |
| 2 | 3-7s | | | | | 建立问题 |
| ... | | | | | | |

功能列标注每镜的叙事作用：钩子/建立问题/放大痛点/产品出场/展示证据/机制解释/offer/CTA/回扣

### 文案要点（骨架级）

三部分：

**口播要点**：逐段口播要点 + 情绪指示（停顿、重音、语气变化的标注规范）。完整逐字口播稿由 L5 生成

**屏幕文字**：每镜的屏幕文字（精简，不是口播全文）

**标题/描述/标签**：
- 标题候选（3 个，不同钩子路径）
- 描述（SEO 友好，含关键词）
- 话题标签（平台适配，混合大词+中词+小词）

### 钩子候选

至少产出 3 个前 3 秒版本，每个标注：

| 版本 | 看到什么 | 听到什么 | 读到什么 | 心理触发路径 | 预期钩子强度 |
|------|---------|---------|---------|-------------|-------------|

心理触发路径例：好奇缺口 → 痛点共鸣 → 利益承诺

## 模块五：放大前 Gate

复用 Meta 框架的放大前 gate（2026-07-20 记录），防止放大噪声。在产出脚本骨架后、实际投入生产前过这个 gate。**本节是放大前 gate 的唯一权威定义（5 条）**，`references/amplification-matrix.md` 与编排器只引用不重复：

1. **验证数据**：这个逻辑在你自己的领域有验证数据吗？（不是 1-2 条偶然爆款；哪怕小样本测试也行）
   - 如果没有：先小批量测试（3-5 条），不要直接 all in
2. **指标不偏科**：CTR/完播/互动/转化至少两类同时说得过去（个人创作者简化为：完播率 + 互动率 两项）
   - 偏科 = 单指标幻觉，先补短板再放大
3. **可一句话复述**：核心信息能一句话讲清吗？（痛点 → 机制 → 结果）
   - 如果不能：结构有问题，回去重构
4. **非单点红利**：这个爆款逻辑是否依赖原版的单点红利（特定达人/一次性事件/特殊场景）？
   - 如果是：你不能复制，需要找到可复制的版本
5. **发动机可移植**：原版的发动机在你的领域/产品上能成立吗？
   - 如果不能：换发动机，不要硬套外壳

**Gate 结论**：通过 / 需小批量验证 / 需重构

## 纪律

- 发动机识别必须做反向假设验证（去掉还火吗），不能凭感觉
- 差异化必须过反搬运 gate，三个问题都要回答
- 脚本骨架要有完整分镜结构，不能只给文案要点；完整成稿走 L5
- 钩子至少 3 个版本，标注心理触发路径
- 放大前 gate 必须跑，不跑 = 放大噪声（用户最痛恨的）
- 平台阈值标注是经验值不是官方数据，不要当成硬规则
