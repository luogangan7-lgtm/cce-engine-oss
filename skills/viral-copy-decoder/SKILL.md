# 文案拆解器（纯文本 · 直接跑引擎 fragment）

输入一段文字，输出它在人心里发生了什么：**打中谁、激发什么情绪、引发什么行动倾向**，以及**怎么优化欲望命中**。

这一层不做视觉、不做结构、不做评论区——只吃**纯文案**，然后把它喂给认知因果引擎的 `fragment` 出口，读出四层心理占比。它是 suite 里唯一的**纯文本应用层**：其余 viral skill（L1 视觉/L1.5 表现/L2 结构）需要视频或图文素材，而文案/广告词/标题/正文/邮件是引擎**最强也最充分**的通道（文本=决策面，创作者/受众级共振读出已被外部真值验证 ρ≈0.5，两轮预注册）。

## 这层和别的层的分工

| 你手里有什么 | 用什么 |
|------|--------|
| 一段纯文案（广告词/标题/正文/邮件/slogan） | **本 skill**（直接跑引擎 fragment） |
| 评论区一堆评论 | `viral-comment-intelligence`（L3.5） |
| 两人聊天记录 | `viral-dialogue-decoder`（L4.6） |
| 一条视频/图文爆款要从头拆 | `viral-content-recon`（编排器，走视频漏斗） |
| 想反推某个人的稳定核心欲望（需多源信号/时间轴） | `viral-person-decoder`（L4.5） |

**一句话定位**：comment-intelligence 拆的是「观众自己写的字」，dialogue-decoder 拆的是「两个人来回的字」，**本 skill 拆的是「你要发出去的那段字」**——三者都是文本原生、都跑在同一块已证的引擎通道上。

## 引擎调用（本层的核心动作，不是可选步骤）

引擎在 `$CCE_ROOT/`，出口 `scripts/cce_predict.py`。**本层的读数一律来自引擎，不靠人肉猜占比**。

```bash
cd $CCE_ROOT && source .env
# 拆一段文案：读四层占比 + 打中谁 + 激发什么情绪/行动倾向
python3 scripts/cce_predict.py fragment --text "<你的文案原文>" --n 5
```

**何时调 / 参数**：
- **每次拿到一段文案就调**——这是本层的第一步，先有引擎读数再做人读解释。
- `--n 5`：同一段文案采样 5 次取占比均值。**这只降解析噪声，不加证据**（单条文案 `n_eff=1` 不叠加）。`--n 1` 也能用，但**幅值噪声大**，此时只读 RANK（排序），别读精确数值（实验0 结论：RANK 可信 / MAGNITUDE 需采样）。生产建议 `--n 3~5`。
- **文本 <25 字会被引擎硬拒**（返回 `REFUSED_INSUFFICIENT_TEXT_EVIDENCE`）：这是刻意的封路——实测该情形下模型约 1/3 概率返回**自信的退化幻觉先验**且不可自检，静默错误比显式失败更危险。**遇到硬拒不要绕过**：要么向用户要更多文案上下文凑够证据面，要么退化为「人读方向性 RANK」并**显式标注『引擎拒答·证据不足·仅方向性人读·不带引擎背书』**，绝不把人读结果冒充引擎结论。

**引擎输出契约**（`fragment` 恒返回，全占比+认怂形式，无固定点）：
- 四层各给 `posterior_top`（人群 prior 收缩后 top3）+ `inferred_raw_top`（M3 逆推原始 top3）+ `meta`（confidence/uncertainty/evidence_count/fresh_until/provenance）
  - **四层词表**：欲望9 / 需求17（如 `N03_提升能力`）/ 情绪13（如 `desire渴望`/`curiosity好奇`）/ 行动倾向7（如 `approach趋近`/`attend关注`）。欲望9类定义唯一权威源见 `viral-psychology-excavator/references/desire-taxonomy.md`（禁复制粘贴定义），需求/情绪/行动词表由引擎侧 `config/` 与 `results/cce_modules/01_ontology.md` 拥有。
  - **posterior vs raw 怎么读**：单条文案 `w=0.33`（prior 占 67%），`posterior` 被拉向「抖音创作者平均」——它是**校准期望**；`inferred_raw` 是**这条文案本身的信号**，看这条文案「跟平均不一样在哪」要读 raw。**RANK 主看 raw，数值稳健性看 posterior**。
- `downstream_chain_check`：因果链（欲望/需求→情绪/行动）独立预测 vs 逆推值的 `agreement_js`——**JS 小=两条独立路径互证=该层读数可信**；JS 大=逆推和因果链打架，该层结论降权。
- `caveats`：引擎自带的边界声明，**必须原样带进报告**（单点只到 state 层、prior 域限定抖音创作者、跨域需换 prior）。

## 三个输出模块

### 模块一：四层占比读（序稳健口径）

把引擎四层读数翻译成人话。**口径 = 主打 top1、兜 top2**：

- **欲望层**：报第一欲望（top1）作主结论；**若 top1 与 top2 占比差 <0.1 → 输出无序对**（如「成为欲+超越欲」），不硬排第一。p<0.2 的候选标「噪声位，不作结论」（仅作方向参考）。
- **需求层**：同口径，主打 top1 需求（如 `N03_提升能力`），兜 top2。需求是欲望的情境化落点，用它把抽象欲望翻译成「这段文案具体在满足什么」。
- **情绪层**：报占比最高的主导情绪（top1）+ 次情绪（top2），这决定文案的**情绪调性**（下游模块三用）。
- **行动倾向层**：报 top1 行动 + **重点算「趋近:关注」比值**（`approach趋近` / `attend关注`）——这是 CTA 转化力的核心信号（模块三用）。

**每层都要抄引擎的 meta**：confidence / uncertainty / 该层 `agreement_js`（来自 downstream_chain_check）。uncertainty 高或 agreement_js 大的层，结论显式降权。

### 模块二：这段文案打中谁 + 激发什么

**打中谁（受众画像）**——从欲望+需求占比反推会被这段文字共振的人群：
- 主人群 = 第一欲望+第一需求指向的人（如 成为欲×N03_提升能力 → 想变强、在意能力成长的进取型人群）。
- 次人群 = 第二欲望兜的那一支。
- **画像证据硬约束**：每一条人群属性断言（年龄/身份/处境/心态）必须能挂回**输入文案的逐字子串**或引擎某层的高占比读数。**无词证、无读数支撑的属性断言禁止输出**——这类断言统一降级为「低置信猜测」或直接删。禁止刻板印象补全（不因「搞钱」就默认男性/某年龄）。
- **粒度纪律**：只做**受众/人群级**画像（谁会共振）——这是已证粒度。**不做**「哪个具体的人会买」的单人断言（单帖/单人表现不可预测）。

**激发什么情绪、引发什么行动倾向**：
- 情绪：报主导情绪分布（模块一情绪层），一句话说清「读者读完这段字，心里最强的那股情绪是什么」。
- 行动倾向：报 top1 行动 + 趋近:关注比值的方向解读——**比值高（趋近>关注）= 文案在驱动转化动作**（点击/购买/领取/下单）；**比值低（关注≥趋近）= 文案只勾住了注意力、没推向行动**（读者会看、会好奇，但不动手）。这正是 CTA 是否有效的诊断。

### 模块三：优化建议（基于欲望占比 · 序稳健）

**所有优化建议都从引擎占比推导，禁止拍脑袋。** 四条算子：

1. **主打第一欲望**：文案的钩子/主张/价值点应最大化**第一欲望**的满足预览。若当前文案第一欲望占比不够突出（top1 与 top2 贴得很近），说明主张模糊——建议聚焦到单一最强欲望。
2. **兜第二欲望**：第二欲望作为副线埋在正文/次要卖点里，别喧宾夺主。若第一、二欲望是无序对（差<0.1），说明文案在两个欲望间摇摆——要么二选一聚焦，要么显式做双主张但承认会稀释。
3. **情绪调性按占比**：文案的措辞/语气应放大**主导情绪**（模块一情绪层 top1）。主导情绪是 `desire渴望` → 用「拥有后的画面」煽；是 `curiosity好奇` → 用信息缺口勾；是 `fear恐惧`/焦虑 → 用损失厌恶推。**情绪调性和主导情绪对不上 = 文案在自我打架**（例：想驱动渴望却全程说教）。
4. **CTA 强度看趋近:关注比值**：
   - 趋近:关注 **明显>1** → 文案已具转化势能，CTA 可以直给、强给（「点击领取」「立即下单」）。
   - 趋近:关注 **≈1 或 <1** → 读者停在「关注/好奇」没滑向「趋近/行动」，**直给 CTA 会转化不动**。先补一段把注意力转成动机的桥（痛点放大/结果预览/稀缺），再上 CTA；或把 CTA 降级为低成本动作（先「主页看看」而非「立即购买」）。

**优化建议的验收口径**：改完的文案**重新跑一遍 `fragment`**，看①第一欲望占比是否更突出、②主导情绪是否更集中、③趋近:关注比值是否上升。**这是可复现的验收 gate，不是「我觉得更好了」**——序稳健地比 RANK 和比值方向，不比精确幅值。

## 诚实边界（铁律 · 继承 2026-07 引擎对账结论）

对账依据：`$CCE_ROOT/docs/skill_engine_reconciliation_2026-07.md`。**三条封路全是窄的「确定性宣称」封锁，无一否定核心心理预测**——别把封路说成「文案层做不了心理预测」（那是自毁最强牌）。

1. **文本原生充分＝已证，但逆推＝推断非读心**。文案/广告/销售信是**决策面**，正是引擎已验证充分的通道（创作者/受众级共振读出 ρ≈0.5，两轮预注册，CI 0.28–0.69）。所以「打中谁、激发什么情绪/行动」是**受众级已证粒度、可信赖**。但四层占比是从文字**逆推的心理分布**——是**推断**，不是「读出了作者/读者内心的确定真相」（内在潜变量无真值仪器）。纪律是**不吹「确定真值」，而不是否认预测力**。

2. **禁单帖爆款/播放量/时机预测（封路）**。本层**只做「这段文案打中谁 + 怎么优化欲望命中」**。**绝不承诺「这条文案会火/会爆/播放量多少/什么时候发最好」**——单帖是否爆受算法分发+粉丝基数+运气支配，已三重实锤（SMTPD/MusicLab/E1）不可事前预测。欲望命中强 = 提高期望命中的**结构性信号**，**不是「这条会火」的保证**。

3. **全占比 + 序稳健算子**。只给**分布 + 置信**，读 **RANK（排序）/ 比值 / 方向 / top-k**。**禁卡精确幅值阈值**（不说「欲望占比要 >30%」这类伪精确门）。占比数值随采样波动，稳健的是次序和方向。

4. **粒度纪律：受众/人群级可预测，单条/单人表现不可预测**。可给「哪类人会共振」（已证）；**不给**「这条会带来多少转化/哪个具体的人会买」（脏真值域）。

5. **证据硬约束（fact-check 护栏）**。每条欲望/人群/画像断言的 evidence 必须是**输入文案的逐字子串**或**引擎某层高占比读数**——找不到词证/读数支撑就删。禁虚构引语、句外专名、句外具体数字、无词证的人口属性断言。前两位候选差 <0.1 输出无序对；p<0.2 标噪声位不作结论。
