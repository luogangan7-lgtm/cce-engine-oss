# L4.5 · 人的拆解（从所有信号反推核心欲望）

用户原话：「这等于做一套人的拆解 skill」。整个拆解体系——从视觉到心理到评论到行为——最终都指向一个问题：**这些人到底想要什么？** 回答了这个问题，才能精准定位人群，才能做千人千面的内容匹配，才能生成击中欲望的内容。

**核心认知**：人的需求会变化（今天想看搞笑明天想看情感），但每个人都有**核心欲望**——稳定的、底层的需求结构。核心欲望不轻易变。所有的内容消费、互动行为、评论表达，都是核心欲望在不同情境下的投影。我们的任务是从这些投影反推出核心欲望本身。

## 为什么需要这一层

L1-L3.6 拆解的是「一条内容」。L4.5 拆解的是「人」。区别：
- 拆内容：这条视频戳了什么欲望？（单次事件）
- 拆人：这个人/这类人的核心欲望是什么？（稳定结构）

**为什么拆人不只拆内容**：同一条视频，不同人看了反应不同——因为他们的核心欲望不同。有人看哭了（戳了归属欲），有人看完了划走（没被戳到），有人转发了（戳了社交身份）。理解人，才能理解为什么同一内容对不同人有不同效果，才能做千人千面的内容匹配。

## 前提

至少有以下信号之一（越多越好）：
- **内容消费记录**：这个人/人群常看什么类型的内容（来自 L1-L3.6 的拆解结果或平台数据）
- **行为数据**：点赞/评论/转发/收藏/关注的历史模式（来自 L3.6 或后台数据）
- **评论历史**：这个人/人群在评论区的表达（来自 L3.5）
- **创作者已发布的作品**：如果拆解的是创作者本人，他们的作品就是他们的欲望表达

如果只有一条内容的拆解结果 → 只能做「这条内容的观众人群」画像，不能做完整的人拆解。完整的人拆解需要**多条内容或多类行为**的聚合。

## 核心理论：欲望分层模型

用户的洞察：「需求也是分层次的，但是需求都会对应原始欲望」。这对应一个三层模型：

```
Layer 3: 原始欲望（Core Desire）        ← 不变。人性级别的驱动力。
    ↑ 对应
Layer 2: 情境需求（Contextual Need）     ← 随情境变化。同一个欲望在不同场景下的具体形态。
    ↑ 表现为
Layer 1: 可观测信号（Observable Signal） ← 行为/表达/消费。我们能看到的。
```

### Layer 3 · 原始欲望（9 类核心欲望）

欲望 9 类的完整定义与人性根源见唯一权威源：`viral-psychology-excavator/references/desire-taxonomy.md`（本层把 9 类欲望当作**人格特质**而非单次触发使用；触发视角的「安全感欲」在人格特质视角写作「被爱欲」，同源，见权威源的双视角说明）。

**关键**：每个人都有全部 9 种欲望，但**权重不同**。某个人的「核心欲望」是权重最高的 2-3 种。比如：
- 一个经常看理财/副业/效率工具的人：控制欲（掌控财务）+ 拥有欲（积累财富）+ 超越欲（超越同龄人）
- 一个经常看情感/治愈/萌宠的人：被爱欲 + 归属欲 + 确认欲
- 一个经常看健身/穿搭/美妆的人：成为欲（更好的自己）+ 超越欲（比现在更好）

### Layer 2 · 情境需求

同一个核心欲望，在不同情境下表现为不同需求：

| 核心欲望 | 工作日情境 | 深夜情境 | 周末情境 | 压力情境 |
|----------|-----------|----------|----------|----------|
| 被爱欲 | 看职场关系内容 | 看情感/孤独话题 | 看家庭/亲子内容 | 看治愈/安慰内容 |
| 控制欲 | 看效率/管理内容 | 看理财/规划内容 | 看DIY/整理内容 | 看时间管理内容 |
| 超越欲 | 看成功学/案例 | 看逆袭故事 | 看学习/成长内容 | 看励志/鸡汤内容 |

**为什么重要**：同一个人的核心欲望不变，但情境需求会变。如果只看某个时间点的行为，可能误判核心欲望。需要跨情境看模式。

### Layer 1 · 可观测信号

把所有可观测信号归类到对应的核心欲望：

| 信号类型 | 怎么读 |
|----------|--------|
| **观看的内容类型** | 内容的主题 = 情境需求的直接表达 |
| **完播的内容** | 看到底 = 预期被满足 = 内容匹配了欲望 |
| **点赞的内容** | 情感认同 = 欲望被触动（即时冲动） |
| **评论的内容** | 主动表达 = 欲望足够强要输出 |
| **转发的的内容** | 社交货币 = 内容代表了这个人的身份/品味 |
| **收藏的内容** | 未来价值 = 实用需求（囤积安全感） |
| **关注的人** | 持续价值预期 = 信任 + 归属 |
| **搜索的关键词** | 主动需求表达（比被动推荐更精准） |
| **发布的内容** | 创作者的欲望外化（想被外界看到什么） |

## 三级分析粒度（个人 → 多人 → 全体）

用户明确要求：「整个 skill 必须能通过碎片信息解析到个人、多人、全体等方面」。同一个方法论，三种分析粒度：

### 级别 1 · 个体级（从碎片还原一个人）

**输入**：一个人的内容消费记录 / 行为数据 / 评论历史 / 发布的作品
**目标**：还原这个人的核心欲望结构 + 稳定画像

**碎片信息处理**：现实中你拿不到一个人的完整数据——只有碎片（他看过的几条内容、发过的几条评论、点赞过的东西）。从碎片还原人的方法：
1. **三角定位**：用 3 个以上不同类型的碎片交叉验证。只看一类碎片（比如只看点赞）容易被误导。点赞+评论+发布 三角验证 > 单独看任何一个
2. **频率 > 单次**：一个人偶然看了一条情感视频 ≠ 被爱欲强。连续 2 周高频看情感内容 = 被爱欲是核心。频率和持续性是稳定特质的证据
3. **矛盾信号处理**：一个人既看理财（控制欲）又看萌宠（被爱欲）→ 不是矛盾，是多元欲望结构。标注主次即可
4. **时间衰减**：近期行为权重高于远期。半年前看健身不代表现在还是健身人群

**个体级特殊价值**：能回答「这个人下周想看什么」「什么内容能让这个人转发」「这个人的消费决策路径」——精准到个体级的内容推荐。

### 级别 2 · 群体级（一类人的共性画像）

**输入**：一类人群的聚合行为数据（同一条内容的观众 / 同一个账号的粉丝 / 同一个兴趣标签的用户）
**目标**：提取这类人的核心欲望结构 + 群体画像

**这是最常用的级别**。L1-L3.6 拆解一条内容后，那条内容的观众 = 一个群体。多条同类内容的观众聚合 = 更大群体。

**群体级方法**：
1. **分布优先于均值**：不要只看平均画像，看分布。一个群体的评论如果 40% 是痛点表达、30% 是社会认同、20% 是欲望表达 → 群体的主导欲望由这个分布决定
2. **高赞权重**：群体里高赞评论代表最大公约数的共鸣。低赞评论可能是边缘声音
3. **子群体识别**：一个大群体通常有 2-3 个子群体（比如 Ed Sheeran 评论区的「恋爱中人」和「单身自嘲」是两个子群体）。每个子群体的欲望权重不同
4. **群体边界**：标注这个画像适用于哪类人，不要过度泛化。「Ed Sheeran Perfect 的观众」≠「所有音乐爱好者」

### 级别 3 · 全体级（宏观人群趋势）

**输入**：一个平台/品类/时代的宏观数据（热门榜单 / 品类趋势 / 年度报告）
**目标**：识别当前社会层面的集体欲望走向

**全体级方法**：
1. **趋势信号**：什么类型的内容在整体上升？什么在下降？上升的 = 集体欲望在增强
2. **跨品类对比**：不同品类的高增速方向反映不同的社会欲望（理财涨=控制欲增强；治愈涨=焦虑增大；知识涨=成为欲增强）
3. **代际差异**：不同年龄段的热门内容反映代际欲望差异（Z世代偏好身份表达；千禧偏好实用控制；X世代偏好怀旧归属）
4. **时效标注**：全体级结论时效性强。标注分析时间和数据窗口

**全体级特殊价值**：能回答「现在做什么赛道有机会」「下一波热点可能在哪」「哪个平台的哪类人群在增长」——战略决策级洞察。

### 三级联动

个体→群体→全体 不是孤立的。最好的分析是三级联动：
- 从全体级发现趋势（「治愈系内容在上升」）
- 用群体级确认方向（「25-35岁都市女性是核心人群」）
- 到个体级精准匹配（「这个具体用户的被爱欲权重最高，推荐这类内容」）

反过来也成立：
- 从个体级发现异常（「这个人同时看理财和玄学」）
- 用群体级验证（「理财+玄学交叉的人群在增长吗？」）
- 到全体级确认趋势（「2026年理性+灵性混合消费是上升趋势」）

**三级粒度的引擎背书状态（诚实标注 · 已证/方向性分级）**：
- **个体级**（级别1）：desire/need/emotion 层身份结构预测**已证**（SS 0.44–0.76，4 次复现）；但 action 层（「什么内容能让这个人转发」）无个人化增益、用人群 prior，标为**方向性**。
- **群体级**（级别2）：受众级共振读出**已证**（ρ≈0.5，两轮预注册，CI 0.28–0.69）——最稳的一级。收藏型 vs 评论型创作者对立两极已两批复现。
- **全体级**（级别3）：宏观趋势为**方向性**（机制自洽，尚无外部真值），时效性强，结论标「趋势推断待数据验证」，不当已证事实断言。

## 四个分析模块

### 模块一：信号收集与归类

把所有可观测信号收集并归类到 8 种核心欲望：

**信号归类矩阵**：

| 核心欲望 | 典型内容主题 | 典型行为模式 | 典型评论表达 |
|----------|-------------|-------------|-------------|
| 拥有欲 | 产品测评/开箱/好物推荐/房产/投资 | 收藏率高/购买行为 | 「求链接」「多少钱」 |
| 成为欲 | 健身/穿搭/美妆/学习/技能/个人成长 | 关注学习类账号/完播率高 | 「我想成为」「怎么做到的」 |
| 摆脱欲 | 解压/治愈/吐槽/维权/避坑 | 完播率高/评论区共鸣 | 「我也是」「终于有人说」 |
| 确认欲 | 价值观/立场/群体共鸣/金句 | 转发率高 | 「代表我说了」「+1」 |
| 超越欲 | 成功学/逆袭/对比/排名/竞争 | 完播+关注 | 「凭什么他能」「我也要」 |
| 归属欲 | 圈层文化/小众爱好/地域/行业 | 关注+评论互动 | 「自己人」「同是XX人」 |
| 控制欲 | 效率/管理/理财/规划/DIY/整理 | 收藏率极高 | 「学到了」「马克」 |
| 被爱欲 | 情感/治愈/萌宠/家庭/孤独 | 完播+深夜活跃 | 「哭了」「好温暖」 |

**操作**：把目标人/人群的所有信号填入矩阵，统计每种欲望的信号强度（信号数量+信号深度）。

### 模块二：核心欲望排序

从信号矩阵计算每种欲望的权重：

**权重计算（定性方法，不需要精确数学）**：

```
某欲望权重 = (相关内容消费量 × 1) + (相关点赞 × 2) + (相关评论 × 3) + (相关转发 × 4) + (相关收藏 × 3) + (相关关注 × 5)
```

行为越主动（关注>转发>评论>收藏>点赞>观看），权重越高。因为主动行为 = 欲望更强。

**输出**：8 种欲望按权重排序。前 2-3 名 = 这个人的**核心欲望结构**。

**关键洞察**：大多数人的核心欲望是 2-3 种的组合，不是单一的。组合模式比单一欲望更能定义一个人。常见组合：
- 控制欲 + 拥有欲 + 超越欲 = 「成就驱动型」（常看理财/效率/成功学）
- 被爱欲 + 归属欲 + 确认欲 = 「情感连接型」（常看治愈/情感/萌宠）
- 成为欲 + 超越欲 + 确认欲 = 「自我提升型」（常看健身/学习/穿搭）
- 摆脱欲 + 被爱欲 + 归属欲 = 「寻求出口型」（常看解压/吐槽/治愈）

### 模块三：稳定画像构建

从核心欲望结构推导稳定画像：

**画像维度**：

1. **核心欲望结构**（模块二的结果）：前 2-3 名欲望 + 组合类型
2. **人群标签**：一句话概括（「成就驱动型都市青年」「情感连接型宝妈」）
3. **人口特征推断**（从内容主题和行为模式）：
   - 年龄段（内容主题反映生命阶段：带娃/考研/退休/职场）
   - 性别倾向（内容消费的性别分布）
   - 地域特征（方言/本地话题/地域文化符号）
   - 生活状态（独居/合租/已婚/有娃/学生/职场）
4. **心理特征**：
   - 价值观倾向（务实/理想主义/享乐/奋斗）
   - 情绪基线（积极/焦虑/平和/波动）
   - 风险偏好（保守/中性/激进）
5. **内容偏好**：
   - 偏好的内容形态（短视频/图文/长视频/直播）
   - 偏好的内容深度（秒懂/轻思考/深度）
   - 活跃时段（反映生活节奏）
   - 获取信息的渠道偏好（推荐feed/搜索/关注页）
6. **决策模式**：
   - 冲动型 vs 理性型（点赞多的内容 vs 收藏多的内容）
   - 从众型 vs 独立型（转发热门内容 vs 收藏小众内容）
   - 即时满足型 vs 延迟满足型（完播娱乐 vs 收藏学习）

**画像不是标签堆砌**。好的画像能用一句话回答：「这个人最深处想要什么，他/她每天在做什么来满足这个想要，什么内容能击中他/她」。

### 模块四：内容击中公式（内容匹配见 L5）

内容匹配策略的展开与执行（欲望→触发器→主题→形态的完整映射、内容方向设计、生成建议）职责归 L5：**内容匹配见 L5 `viral-content-generator`**。

本层只输出一行**内容击中公式**：`触发器 × 主题 × 形态`（由模块二的核心欲望结构推导），作为 L5 的直接输入，不在本层展开内容生成建议。

## 纪律

1. **核心欲望是推断，且这个推断已被外部真值验证（诚实纪律）**。我们从行为/内容逆推欲望——这是**推断不是直接读心**，行为可能有多重解释，所有结论标注信心度（高/中/低）。但「推断」不等于「没有预测力」：受众/创作者级欲望共振读出已被外部真值验证（ρ≈0.5，两轮预注册），个体级身份结构预测 SS 0.44–0.76（4 次独立复现）。**纪律是不宣称「读出了你内心的确定真相」（内在潜变量无真值仪器 Cronbach-Meehl），而不是否认预测力**——我们能预测欲望结构（已证），只是不吹「确定真值」。
2. **避免刻板印象**。不要因为某人看美妆就判定「女性/虚荣」。看美妆可能是职业需要、是送礼物、是纯好奇。用多条信号交叉验证，不要用单一信号下定论
3. **区分稳定特质和情境波动**。一次深夜看情感内容 ≠ 核心欲望是被爱欲。要看长期模式。如果只有短期数据，标注「短期画像，可能不代表稳定结构」
4. **隐私边界**。如果是分析具体个人（而非人群），注意数据伦理。只用公开可获取的行为数据，不做侵入性推断
5. **画像会过时**。人的核心欲望相对稳定但不是永远不变。重大生命事件（结婚/生子/失业/搬家）会改变权重。标注画像有效期
6. **欲望无好坏**。不给欲望贴道德标签。拥有欲不等于贪婪，被爱欲不等于脆弱。这是人性分析不是道德评判
7. **追问建设性欲望的缺席**（真实数据校准发现 2026-07-21）：6条真实爆款校准发现，中国短视频的主驱动力全部是补偿性的（缺什么补什么），几乎没有建构性的（有什么要展示）。拆解时必须追问：「为什么这里没有自我实现/成就感/创造喜悦？」是因为内容类型？赛道生态？还是中国文化语境？
8. **区分 certainty 和 sharpness**（真实数据校准发现 2026-07-21）：确定的（certainty）不等于锋利的（sharpness）。一条分析可能「很确定地说了一个平庸的结论」，也可能「大胆地说了一个可证伪的洞察」。后者更有价值。标注两个独立维度
9. **每条画像必须附自我证伪条件**：什么信号出现时，你的画像假设会崩塌？（如「如果这个人开始大量收藏而非点赞，则『镜像认同』假设不成立」）。可证伪的画像是科学，不可证伪的是算命
