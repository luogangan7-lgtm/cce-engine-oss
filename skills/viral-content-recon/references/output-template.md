# 标准输出模板

viral-content-recon 编排器的完整拆解报告输出模板。

## 使用说明

跑完十层漏斗后，用这个模板合成交付物。交付物四件套：
1. 拆解报告（L1-L3.6 的发现）
2. 差异化蓝图（L4 的放大方案）
3. 可拍脚本（L4 的分镜骨架 + L5 的完整成稿）
4. 人群画像 & AI 内容套件（L4.5 的核心欲望画像 + L5 生成的标题/图片提示词/图文/标签）

## 批量拆解的精简模板

批量拆解 10+ 条内容时，不需要每条都写完整报告。用精简版：

```markdown
# [内容标题/描述]

**数据**：播放 XX / 点赞 XX
**钩子**：[类型] — [一句话]
**叙事弧**：[类型]
**发动机**：[一句话]
**心理深度**：[层级] — [一句话]
**人群**：[一句话]
**触发器**：[2-3个]
**可复用元素**：[1-2点]
**差异化方向**：[一句话]
```

精简版用于快速筛选，筛出 2-3 条代表性爆款后再跑完整拆解。
