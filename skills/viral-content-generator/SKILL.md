# L5 · 内容生成（从拆解到自己的爆款）

拆解别人爆款的终极目的：做出自己的。这一层把 L1-L4.5 的所有发现转化成可执行的 AI 生成指令，产出完整的内容套件。

**核心原则**：AI 生成不是凭空创作。每条生成内容都必须有**拆解锚点**——来自 L3 的核心欲望、L4 的放大矩阵、L4.5 的人群画像。没有拆解的 AI 生成 = 通用 AI 写作 = 没有差异化。

**能力边界（诚实纪律 · 封路条款）**：本层生成的是**锚定已证欲望结构的内容**，不是爆款保证。「内容欲望锚定对不对」可以验证（对照 L3/L4.5 拆解 + 出稿前置 Gate），但「这条发出去会不会爆」**不可事前保证**——单帖爆款受算法分发+粉丝基数+运气支配，已被证明不可预测。L5 的承诺止于「内容精准锚定目标人群的核心欲望 + 保留发动机 + 不搬运」，**不越界承诺播放量或必爆**。

## 前提

- 最好已完成完整漏斗（L1-L4.5）。至少需要 L3（心理）和 L4（放大矩阵）的结果
- 如果没有拆解结果：必须口头确认目标人群 + 核心欲望 + 差异化定位，否则不生成
- 用户原话：「我们最终并不仅仅只是做视频的脚本，而是如果通过 AI 生成这些视频、文案、标题、图片、搭配图文等等。这样整个 skill 组合才算是闭环的」

## 生成原则（铁律）

1. **欲望锚定**：每条内容的底层目的 = 满足目标人群的核心欲望（L4.5 的结果）。如果内容不锚定任何核心欲望，不生成
2. **发动机保留**：L4 识别的爆款发动机必须在生成内容里保留。丢了发动机 = 内容失魂
3. **差异化必做**：L4 的差异化定位必须体现。生成的不是搬运，是「同发动机不同外壳」
4. **平台适配**：不同平台的内容形态不同（L3.6 的 algorithm-signal-map）。同一拆解结果要生成不同平台版本
5. **事实安全**：不编造数据/案例/引用。如果需要数据但没有，标注「需要真实数据填充」

6. **传播力设计**：每条生成内容必须回答「凭什么被转发」。转发=社交货币。内容要让分享者觉得自己有品味/有信息/有立场。在生成时明确标注内容的社交货币属性（实用型/身份型/娱乐型/价值观型）
7. **参与度设计**：每条生成内容必须内置「让人参与」的钩子——评论区讨论话题/投票/征集/挑战/争议点。不设计参与钩子的内容 = 看完就走
8. **营销力设计**：如果内容有商业目的（带货/引流/品牌），必须自然植入而非硬广。植入路径在拆解阶段确定（L3 的成交驱动力 + L4.5 的人群匹配），在生成阶段执行
9. **触达力设计**：每条内容必须考虑冷启动触达——前3秒/标题/封面决定算法是否推给目标人群。生成时必须验证「算法标签匹配」（L3.6 的千人千面逻辑）

## 出稿前置 Gate（阻断式，任一不过 = 禁止交付成稿）

在交付任何成稿（脚本/文案/标题/图文/提示词套件）之前，必须逐项过以下 gate。这不是勾选建议，是**阻断条件**——任一项不通过，禁止交付成稿，返回修改后重过：

1. **事实安全**：无编造数据/案例/引用/统计；所有需要真实数据填充的槽位已显式标注「需真实数据填充」
2. **反搬运 3 问通过**（引用 L4 `viral-amplification-architect` 模块三的反搬运 gate）：①观众能一眼看出是两个不同创作者的作品吗？②去掉原版的任何视觉元素/措辞/场景后我的版本还成立吗？③原版创作者看到会认为是「致敬」而非「搬运」吗？——任一「否」= 不通过
3. **欲望锚定核对**（引用 L4.5 击中公式）：内容锚定了 L4.5 的击中公式（触发器 × 主题 × 形态）和核心欲望；无法指出具体锚定点 = 不通过

**Gate 结论必须写进 L5 报告**：通过（三项各附一句证据）/ 不通过（打回原因 + 待修改项）。

## 六个生成模块

### 模块一：视频脚本生成

**输入**：L4 的放大矩阵 + 分镜表框架 + L4.5 的人群画像 + L2 的钩子分类

**生成结构**：

```
【视频基本信息】
- 平台 / 时长目标 / 内容类型（口播/剧情/过程展示/混剪/Vlog）
- 目标核心欲望：【L4.5 结果】
- 差异化定位：【L4 结果】

【前3秒钩子】（至少3个候选版本）
版本A 钩子类型：【L2分类】
  - 画面：
  - 声音/口播：
  - 屏幕文字：
  - 心理触发路径：【欲望→触发器→行为】
版本B ...
版本C ...

【完整分镜表】
| 镜号 | 时长 | 画面描述 | 口播文案 | 屏幕文字 | 音乐/音效 | 表演指导 |
（逐镜展开，L4 放大矩阵的命脉变量在这里体现）

【结尾引导】
- 互动引导：（根据 L3.5 评论分析：观众想做什么 → 设计 CTA）
- 系列预告：（如果有系列化空间）

【话题标签】（5-8个）
- 核心标签 / 流量标签 / 精准标签 / 品牌标签
```

**生成提示词模板**（喂给 AI 的指令）：
```
你是一个爆款短视频编剧。根据以下拆解结果生成一条完整的视频脚本。

拆解锚点：
- 核心欲望：{L4.5的核心欲望}
- 目标人群：{L4.5的人群标签}
- 爆款发动机：{L4的发动机}
- 必须保留：{L4的命脉变量}
- 差异化定位：{L4的差异化}
- 推荐钩子类型：{L2的钩子分类}

要求：
1. 前3秒必须用指定钩子类型
2. 全程锚定核心欲望
3. 体现差异化定位
4. 适合{平台}的平台特征
5. 不编造数据
```

### 模块二：文案生成

**输入**：L4.5 的内容匹配策略 + L3 的触发器 + 平台特征

**文案类型**（按平台和场景分）：

| 文案类型 | 平台 | 字数 | 作用 |
|----------|------|------|------|
| 口播文案 | 视频类 | 按视频时长 | 视频主体内容 |
| 图文正文 | 小红书/B站 | 200-800字 | 图文主体 |
| 标题文案 | 全平台 | 10-30字 | 点击率核心 |
| 描述文案 | 全平台 | 50-200字 | 搜索SEO+补充 |
| 评论引导 | 全平台 | 20-50字 | 激发互动 |
| 评论区置顶 | 全平台 | 50-100字 | 引导讨论方向 |

**文案生成原则**：
- 标题用 L2 的钩子分类学（前3秒钩子=标题钩子）
- 正文按 L2 的叙事弧结构展开
- 嵌入 L3 的触发器（好奇心缺口/社会认同/情绪传染等）
- 结尾设计 L3.5 分析出的评论触发点（激发观众想说的欲望）
- 植入搜索关键词（L3.6 的 SEO 策略）

**完整填好的示例（地域美食图文封面，槽位全填）**：

```
【封面图提示词 · 示例：柳州螺蛳粉探店图文封面】

- 配色：暖色主导（红油橙红 + 酸笋米黄），背景深色木桌压暗对比，高饱和食欲色
- 文字叠加：「柳州人从小吃到大的这家 本地人排队 游客找不到」（无衬线粗体，白字红底描边，右上角两行）
- 风格参考：小红书美食探店头部账号封面风——近景大特写 + 蒸汽感 + 高对比
- MJ/DALL-E 提示词：close-up overhead 45-degree shot of a steaming bowl of Luosifen
  (river snail rice noodles), vibrant chili-red broth, pickled bamboo shoots and fried
  peanuts visible, chopsticks lifting noodles, rising steam, dark wooden table background,
  warm saturated food-photography lighting, shallow depth of field, appetizing editorial
  style, vertical 3:4 composition, empty space in upper right for text overlay
  --no text, watermark, hands, clutter
```

**差异化约束**（铁律）：L1 分析竞品的视觉语言时，结论是「失败视觉只作负面约束」。生成提示词时不复刻竞品的视觉风格，而是用 L4 的差异化定位指导新的视觉方向。

### 模块五：标题生成（全平台）

**输入**：L2 钩子分类学 + L4.5 核心欲望 + 平台标题规范

**标题生成框架**（每个内容至少生成 5 个标题候选）：

| 钩子类型 | 标题模板 | 适用欲望 |
|----------|----------|----------|
| 数字清单型 | 「N个___让你___」 | 控制欲/拥有欲 |
| 对比反差型 | 「before vs after」「别人vs我」 | 超越欲/成为欲 |
| 疑问好奇型 | 「你知道___吗」「为什么___」 | 好奇心（所有欲望） |
| 痛点共鸣型 | 「___的人一定懂」 | 确认欲/归属欲 |
| 结果展示型 | 「用了___天后」 | 拥有欲/成为欲 |
| 身份标签型 | 「作为___我___」 | 归属欲/确认欲 |
| 悬念缺口型 | 「第N个太___了」 | 好奇心（所有欲望） |
| 价值承诺型 | 「___分钟学会___」 | 控制欲/成为欲 |

**平台标题规范**：
- 抖音：15-30字，前10字决定是否展开看
- 小红书：15-20字，封面文字比标题更重要
- TikTok：英文 30-60 字符，前 20 字符决定
- YouTube：30-60 字符，关键词前置（SEO）
- B站：10-30字，可以更长更具体

### 模块六：话题标签生成

**输入**：L3.6 的搜索 SEO 策略 + L4.5 人群的内容搜索习惯

**标签组合策略**（每个内容 5-8 个标签）：

```
1个大流量标签（#品类词，如#好物推荐）
1-2个精准标签（#细分场景词，如#厨房收纳）
1个趋势标签（#当前热点词，如有热度的话题）
1-2个长尾标签（#具体需求词，如#免打孔置物架）
1个品牌/个人标签（#你的品牌名或系列名）
```

**为什么这么组合**：大流量标签带来曝光广度，精准标签带来目标人群，长尾标签带来搜索流量（长尾生命周期长），趋势标签蹭热度。

## 跨平台适配

同一个拆解结果，不同平台生成不同形态的内容：

| 平台 | 生成重点 | 形态 |
|------|----------|------|
| 抖音 | 前3秒钩子+完播+搜索关键词 | 短视频脚本+标题+标签 |
| 小红书 | 封面+标题+图文搭配+SEO | 图文套件+封面提示词+正文 |
| TikTok | 前3秒+音乐+全球适配 | 短视频脚本（英文/本地化） |
| YouTube | 缩略图+标题+观看时长 | 长视频大纲+Shorts版本 |
| Instagram | Reels完播+转发+视觉美感 | Reels脚本+Feed图文+Story |
| B站 | 三连+弹幕+社区文化 | 中长视频脚本+弹幕设计 |
| 视频号 | 社交裂变+中年人群适配 | 视频脚本+转发引导 |

## 三级投放粒度适配

同一个拆解+生成结果，可以适配到个人/多人/全体三种投放粒度：

| 投放粒度 | 内容策略 | 平台机制 | 典型场景 |
|----------|----------|----------|----------|
| **个人级**（精准推荐） | 极致个性化——核心欲望精确匹配 | 算法 For You 页推荐 | 私域/CRM/个性化推送 |
| **群体级**（兴趣标签） | 群体共性画像驱动——覆盖子群体核心欲望 | 兴趣标签定向投放/相似受众 | 信息流广告/达人种草 |
| **全体级**（广泛触达） | 最大公约数欲望——取所有人群都吃的核心 | 热门榜单/开屏/热搜 | 品牌曝光/大促活动 |

**生成时的适配**：
- 个人级内容：弱化泛话题，强化「只对这个人有意义」的细节
- 群体级内容：平衡 2-3 个子群体的欲望，找到交集
- 全体级内容：只用最底层的原始欲望（被爱/安全/归属/超越），不碰细分需求

## AI 语音参数模块

当内容包含 AI 生成配音时，音色选择是**第一决策**——它直接决定了人设可信度和欲望击中精度。选错音色 = 观众前 3 秒划走。

### 步骤 1：从 L4.5 人群画像 → 目标欲望 → 音色类型

| 目标欲望（L3 拆解结果） | 推荐音色 | 语速 | 语调调性 | 情绪色彩 |
|------------------------|---------|------|---------|---------|
| 权威感/安全感 | 低沉浑厚 | 中-慢 | 下沉句尾、坚定 | 克制、自信 |
| 好奇心/成为欲 | 清亮穿透 | 中-快 | 上扬句尾、起伏大 | 兴奋、探索 |
| 归属欲/亲密感 | 柔和气声 | 慢 | 轻柔、低音量 | 温暖、安抚 |
| 真实感/共鸣 | 沙哑粗糙（或保留真人瑕疵） | 中 | 自然口语 | 真诚、不修饰 |
| 保护欲/可爱 | 稚嫩清脆 | 中-快 | 活泼、夸张 | 天真、快乐 |
| 专业信任/控制感 | 中性冷静 | 中 | 平稳、无大起伏 | 客观、精准 |

### 步骤 2：关键参数设定

**音色选择参数（给 TTS 工具的指令）**
- 性别 + 年龄感：与出镜者/人设一致（如「30岁男性」/「25岁女性」）
- 音色类型：从上表选择（如「低沉浑厚」/「清亮穿透」）
- 参考声音描述：给一个公众已知的声音类型作参考（如「类似XX博主的声线」，不抄袭具体声音只借类型）
- 情绪基线：整条内容的底层情绪（如「克制自信」/「热情探索」）

**语速参数**
- 快（1.2x+）：紧迫感、信息密度高、年轻向——适合测评/开箱/知识口播
- 中（1.0x）：自然叙事——适合故事/vlog
- 慢（0.8x）：强调、深情、权威——适合情感/励志/luxury
- 混合：钩子段快（抓注意）→ 叙事段中（消化）→ 结尾慢（留余韵）

**语调/情绪变化曲线**
- 钩子（0-3s）：语调上扬 + 音量略高 + 悬念感
- 主体：语调随内容情绪走，关键痛点处加重音
- 结尾/CTA：语调下沉 + 放慢 = 权威感和确定感

**呼吸与停顿（真实感的关键）**
- 保留句间呼吸声 = 真实感（草根/情感向必须保留）
- 剪净呼吸 = 精致感（专业/品牌向建议剪净）
- 钩子前 0.3s 停顿 = 聚拢注意
- 关键数据后 0.5s 停顿 = 让观众消化

### 步骤 3：TTS 工具选择建议（2026）

| 需求 | 工具能力要求 | 备注 |
|------|------------|------|
| 中文自然语音 | 支持中文音色多样性的 TTS | 音色库要够大才能匹配欲望映射 |
| 情绪控制 | 支持 emotion/style 参数 | 不是所有 TTS 都能控情绪，优先选能控的 |
| 音色克隆 | 从真人声音克隆 | 有人设一致性需求的用克隆 |
| 多语种 | 跨平台分发需要 | 不同平台不同语言时 |

### 纪律
- **音色优先于文案**：同样的文案，音色对 = 留存；音色错 = 划走。先定音色再调文案节奏
- **不要用默认音色**：TTS 工具的默认音色通常是最泛的，不匹配任何精准欲望
- **AI 配音要标注**：平台合规要求，AI 生成语音需声明
- **真人 vs AI 的选择**：如果创作者本人声音有辨识度且匹配人设，真人 > AI。AI 配音适合无出镜或数字人场景

## 纪律

1. **不无锚点生成**。没有拆解结果的 AI 生成 = 通用写作 = 没有竞争力。必须先确认锚点
2. **不搬运原版**。L4 的差异化定位是底线。生成的所有内容必须能回答「我的版本凭什么不是搬运」
3. **多版本候选**。标题至少 5 个，钩子至少 3 个。AI 生成的第一版很少是最好的
4. **人工审核必做**。AI 生成的内容必须人工审核后才能发布。检查：事实准确性/品牌一致性/平台合规/文化敏感
5. **迭代闭环**。发布后用 L3.5（评论）和 L3.6（行为数据）验证效果 → 反馈给 L4.5 修正人群画像 → 优化下一轮 L5 生成。这才是闭环
6. **工具会变**。具体的 AI 工具（Midjourney/DALL-E/视频生成工具）会更新迭代。本 skill 的价值在于提示词框架和内容结构设计，不绑定具体工具
