# Bid-响应分类学（Bid-Response Taxonomy）——唯一权威源

> 本文件是 viral-dialogue-decoder（L4.6）中「bid 类型 × 回应类型 × 回应成本」完整分类的**唯一权威源**。
> SKILL.md 正文只保留摘要，完整判定标准以本文件为准。
> 理论根系：Gottman 的 emotional bid 概念泛化到全场景对话博弈——每个 bid 都是「转向请求」，回应就是「转向/转开/转对」。

## 一、bid 类型（6 基类）

bid = 一方发出的、期待对方给出情感/行动回应的试探。判定核心：**这条消息是否在向对方要一个回应**（要注意力/要共情/要确认/要行动）。纯信息传递（「明天 3 点开会」）不是 bid；带期待的信息传递（「明天 3 点开会，你来吗😊」）是。

| # | bid 基类 | 定义 | 典型信号 | 识别要点 |
|---|----------|------|----------|----------|
| B1 | **求关注** | 要对方的注意力落在自己身上 | 分享日常/新鲜事/自嘲/发图「你看」 | 内容本身信息价值低，功能是「看我」 |
| B2 | **求安慰/共情** | 要对方接住自己的情绪 | 诉说恐惧/委屈/疲惫/自我暴露 | 暴露脆弱面 = 高信任投入，接不住伤害大 |
| B3 | **边界试探** | 测试对方允许的亲密/玩笑/话题边界 | 玩笑化的越界句、试探性提问、撤回 | 常包装成玩笑——「开玩笑的」是安全气囊 |
| B4 | **亲密升级** | 明确推进关系层级 | 亲密假设句（「躲进我的怀里」）、称呼升级、邀约、身体/未来隐喻 | 与 B3 的区别：B3 问「可以吗」，B4 直接做 |
| B5 | **展示求认可** | 展示价值要正反馈 | 晒成就/才艺/见识/资源 | 回应缺席时会反复展示（升级或转移舞台） |
| B6 | **要承诺/确定性** | 要对方给出明确表态 | 「我们算什么」、要下次约定、要答复期限 | 最高风险 bid——把模糊态强制坍缩 |

## 二、回应类型（4 类 + 边界判例)

| 回应 | 定义 | 判定要点 |
|------|------|----------|
| **engage**（转向） | 接住 bid 并给出对应回应，可延展 | 含最小 engage（接住不延展，如引用+「哈哈哈哈哈」）——仍是 engage，看成本分级定温度 |
| **deflect**（转开-软） | 不接 bid 本体，转移话题/玩笑化/降级处理 | 「6」「哈哈然后呢」「说正事」——保留对话但拒绝该 bid 的层级 |
| **reject**（转对-硬） | 明确拒绝 bid 内容 | 「别这样」「我们不合适」「太贵了不要」——信息量大：至少对方还在给明确信号 |
| **ignore**（无转向） | 不回应该 bid（跳过它回别的，或整段不回） | 最低成本也最伤——bid 发出者无法定位失败原因 |

**边界判例**：
- 「哈哈哈哈哈」回应自嘲 bid = engage（自嘲要的就是笑）；「哈哈哈哈哈」回应表白 bid = deflect（笑不是表白要的回应）。**判定回应类型必须先判定 bid 想要什么**
- 单字「6」/「绝」= deflect 还是 engage 取决于 bid 类型：对展示 bid 可能是低成本 engage，对亲密 bid 是 deflect
- 隔很久后回应但内容认真 = engage（延迟≠ignore，见单方视角纪律）

## 三、回应成本分级（投入从高到低）

| 级别 | 形态 | 成本含义 |
|------|------|----------|
| C1 | 长文本回应（≥2 句/含追问） | 时间+思考+暴露自己，最高投入 |
| C2 | 引用回复 | 回到具体某条消息 = 精准注意力（读了且记得位置） |
| C3 | 短语（一句话内） | 维持性投入 |
| C4 | 单字（「嗯」「6」「哦」） | 最低语言成本，仅维持在线 |
| C5 | 纯表情 | 情绪贴纸，零语言成本 |
| C6 | 不回 | 零投入 |

**温度读数 = 回应类型 × 回应成本**。C1 级 deflect（长篇解释为什么不行）比 C4 级 engage（「嗯」）的关系投入更高。连续 bid-响应序列按「engage 升温 / deflect·ignore 降温 / reject 急降」记曲线，成本作权重，拐点即关键事件。

## 四、三场景映射表

### 场景 1 · 亲密关系 / 社交破冰（基类直用）

6 基类直接适用。补充场景专属信号：深夜时段 bid 权重上调（自我暴露阈值低）；撤回 = 失败预判的 B3/B4；平台亲密度量表（Soulmate 进度/亲密度心）= 双方投入的第三方读数。

### 场景 2 · 商业跟单（bid = 商业动作，回应分化 = 购买意向温度）

| 基类 | 商业形态 | engage 读作 | deflect 读作 | ignore 读作 |
|------|----------|------------|-------------|------------|
| B1 求关注 | 朋友圈式触达/节日问候/新品推送 | 客户在池 | 礼貌性维持 | 已流失预警 |
| B2 求共情 | 诉苦式拉近（「这单我真没赚」） | 关系户潜质 | 客户保持交易边界 | 越界了 |
| B3 边界试探 | 探预算/探决策链（「您这边预算大概…」） | 真实商机 | 未到火候 | 无意向或反感 |
| B4 升级 | **报价/发合同/催单** | 热单（议价=engage！） | 「再看看」「问下领导」= 温 | 冷单 |
| B5 展示 | 案例/资质/客户见证 | 在做功课=意向上升 | 信息过载 | 内容错位 |
| B6 要承诺 | 要答复期限/要定金 | 成交 | 拖延=有变量 | 单已丢，止损 |
| 阶段机 | 触达→需求确认→报价→异议→成交/流失 | | | |

**关键差异**：商业场景中 reject（「太贵了」）是高价值信号——异议=还在谈判；真正的死刑是 ignore。与亲密场景的温度读法相反侧重。

### 场景 3 · 团队/合作沟通（回应分化 = 协作投入度与信任度）

| 基类 | 团队形态 | 回应分化读作 |
|------|----------|-------------|
| B1 求关注 | 同步进展/晒产出 | ignore 常态化 = 协作降温前兆 |
| B2 求共情 | 吐槽阻塞/表达压力 | deflect（「先说结论」）= 关系纯事务化 |
| B3 边界试探 | 试探职责边界（「这块是不是该你们…」） | reject 清晰 = 健康；ignore = 灰色地带堆积 |
| B4 升级 | 提案/请求资源/拉人协作 | 采纳率 = 影响力读数 |
| B5 展示 | 秀方案/技术分享 | engage 率 = 团队学习氛围读数 |
| B6 要承诺 | 要 deadline/要负责人/要决议 | deflect 常态化 = 组织执行力问题（系统性信号，非个人） |
| 阶段机 | 组队→磨合→规范→高效→失速 | |

**关键差异**：团队场景禁止把个体回应模式直接归因个人态度——响应延迟/低成本回应大概率是负载问题。先排除系统性原因（会多/时区/负载）再读关系信号。

## 五、使用规则

1. 逐条消息先问「是不是 bid」→ 是则标基类 → 找对应回应 → 标类型+成本 → 入温度序列
2. 一条消息可含多个 bid（自嘲+邀约），拆开分别配对
3. 未被回应的 bid 也入账——单向欲望账户的原始凭证
4. 场景判定在拆解开始时锁定（相亲对话按场景 1，即使里面聊到了工作）；跨场景对话（客户变朋友）标注混合并分段适用
