# L4.6 · 双人对话拆解（bid-响应博弈与欲望对齐）

聊天记录是**两个欲望系统的实时碰撞现场**。广播内容（L1-L3.6）是「一对多」的欲望投射，对话是「一对一」的欲望协商——每条消息既是表达也是试探，每次回应既是内容也是表态。这一层把对话还原成 bid-响应序列，读出双方各自想要什么、当前什么状态、欲望在哪对齐在哪错位，最终回答一个问题：**下一步说什么（或不说什么）**。

**引擎背书（诚实标注 · 已证/方向性分级）**：对话是**文本原生**通道（聊天记录=逐字文本），引擎已验证充分。**对话情绪耦合已在真实双人对话验证 P=0.97**（一方情绪→另一方情绪传染），支撑本层「关系温度曲线 / bid-响应情绪动态」的读出——这部分是**已证**。但「下一步最优动作」属于**干预/说服层**（改变对方状态）：引擎当前只证到「读出状态与对齐」，未证到「干预效力」，因此下一步动作是**基于对齐度矩阵的结构性建议（方向性）**，非「照做必成」的已证杠杆——所有动作标「基于可见信号，需下一轮 bid 验证」（见纪律3）。

## 与 L4.5 person-decoder 的分工

| | L4.5 person-decoder | L4.6 dialogue-decoder |
|---|---|---|
| 对象 | 单人/人群的**稳定**欲望结构 | 两人互动的**动态**博弈 |
| 输入 | 多源行为信号聚合 | 一段（或多段）双人对话 |
| 输出 | 画像（他是谁） | 状态+对齐+下一步（此刻怎么办） |

两层可联动：L4.6 拆出的每一方欲望证据可喂给 L4.5 做单人画像；L4.5 的已有画像可作为 L4.6 的先验。

## 前提与输入完整度自评（报告开头必须声明）

输入：双人聊天记录（截图 OCR 或文本），最好带时间戳。开始前声明：

```
【输入完整度自评】
- 消息数量：N 条 | 时间跨度：X | 时间戳：✅有/⚠️无
- 平台信号（撤回/引用/表情/礼物/亲密度标识）：✅有/⚠️部分/⚠️无
- 视角：仅一方提供的截图（单方视角）/ 双方完整导出
- 确定性等级：<10 条消息 → 低确定性，结论以候选+概率形式输出
```

## 六个分析模块

### 模块一：对话结构还原

1. **参与者识别**：气泡方位/颜色/头像区分 A、B，全文用稳定代号（如「蓝绿方」「白发方」），禁止臆测姓名身份
2. **时间线重建**：按时间戳排序；标记**跨日边界**和**深夜段**（23:00-06:00 的消息单独标注——深夜对话的自我暴露阈值更低，权重不同）
3. **消息类型标注**：文本 / 图片 / 截图分享（分享第三方对话=把对方拉进自己的生活叙事，高投入信号）/ 通话记录（时长=硬投入证据）/ 表情 / 撤回（说了又收回=自我审查，试探失败或后悔）/ 引用回复（回到具体某条=精准注意力）/ 平台行为（礼物/亲密度标识/关系标签）

### 模块二：turn-taking 力学

对话的「物理层」，不看内容只看形态：

| 指标 | 怎么算 | 读什么 |
|------|--------|--------|
| 发起权分布 | 谁先开新话题的次数比 | 单边发起 >70% = 推进-筛选结构 |
| 响应延迟模式 | 各自的回复间隔分布（需时间戳） | 一方秒回一方隔小时 = 投入不对称（但见纪律3） |
| 消息长度比 | 双方平均字数/条数比 | 长短悬殊 = 输出意愿不对称 |
| 话题采纳率 | A 抛出的话题 B 接住展开了几个 | 采纳率低 = 兴趣错位或防御姿态 |
| 活跃时段重叠 | 双方发消息的时段分布 | 深夜重叠 = 共享私密时段（关系资产） |

### 模块三：bid-响应配对分析（核心）

**bid** = 一方发出的、期待对方给出情感/行动回应的试探。类型：求关注 / 求安慰共情 / 边界试探 / 亲密升级 / 自我展示求认可 / 要承诺确定性（商业场景映射为报价/催单/价值展示等，见 `references/bid-response-taxonomy.md`——bid×回应×成本完整分类学的唯一权威源，含三场景映射表）。

对每个 bid 标注回应四类之一：**engage**（接住并延展）/ **deflect**（偏转：转话题、玩笑化、降级处理）/ **reject**（明确拒绝）/ **ignore**（不回应）。

回应成本分级（投入从高到低）：**长文本回应 > 引用回复 > 短语 > 单字 > 纯表情 > 不回**。同是 engage，用长回应 engage 和用单个表情 engage 是两个温度。

**关系温度曲线**：把全部 bid-响应对按时间排成序列，engage 记升温、deflect/ignore 记降温、reject 记急降，再乘回应成本权重——得到这段关系的温度走势。**曲线的拐点比均值重要**：找到温度转折发生在哪个 bid，那就是关系的关键事件。

### 模块四：双向欲望解析 + 对齐度矩阵

对 A、B **各自独立**走欲望分类分析。欲望 9 类定义见唯一权威源 `viral-psychology-excavator/references/desire-taxonomy.md`（本层用人格特质视角，禁止在此重贴定义）。**每条欲望断言的 evidence 必须逐字引用消息原文**（带引号），无原文支撑的欲望不进结论。

然后做**对齐度矩阵**：

| 区域 | 定义 | 含义 |
|------|------|------|
| 交集欲望 | 双方都在这段对话里表达/满足的欲望 | 关系的粘合剂——维系动作往这里投 |
| 错位欲望 | 双方欲望指向冲突（如一方要亲密加速，一方要安全筛选） | 矛盾源——升级动作在这里翻车 |
| 单向欲望 | 一方反复 bid 而另一方未回应的欲望 | 未满足账户——持续赤字会驱动降温或外流 |

### 模块五：关系阶段状态机

```
破冰 → 试探 → 升级 → 稳定 ⇄ 降温 → 修复(→回试探/升级) 或 终止
```

| 阶段 | 信号判据 | 转换触发信号 |
|------|----------|-------------|
| 破冰 | 安全话题、礼貌句式、短消息 | 出现第一个个人化自我暴露 → 试探 |
| 试探 | 自我暴露互换、玩笑测边界、bid 频率上升 | 升级 bid 被 engage → 升级；连续 deflect → 停滞/降温 |
| 升级 | 亲密假设句、称呼变化、邀约、通话/见面 | 双方投入对称化 → 稳定；单边推进被拒 → 回试探或降温 |
| 稳定 | 日常分享无需由头、响应模式规律 | bid 响应率下滑、回应成本降级 → 降温 |
| 降温 | 单字/表情回应增多、发起权单边化、延迟拉长 | 修复 bid（道歉/示弱/高价值分享）被 engage → 修复 |
| 修复 | 一方主动重启+对方接住 | 成功回试探/稳定；失败 → 终止 |

输出：当前所处阶段 + 判据引用 + 最近一次阶段转换的触发消息。**阶段判定看趋势不看单条**——一次 deflect 不构成降温，连续模式才构成。

### 模块六：状态与需求判定

对每一方输出：
1. **当前状态**：情绪基线（从用词/表情/深夜活跃读）、生活情境（仅限消息中逐字提及的，如「考研」「加班」）、关系角色（**推进者** pursuer / **筛选者** gatekeeper / 对称互动）
2. **即时需求 vs 深层需求**：即时 = 这段对话里在要什么（陪伴/确认/成交答复）；深层 = 即时需求对应的核心欲望（引用模块四结论）。即时需求可以绕过，深层需求绕不过

## 可执行输出（拆解的最终交付）

```
### 下一步最优动作
- 说什么：【具体话术方向/内容】
- 不说什么：【当前禁区】
- 时机：【立即/等对方发起/特定时段】
- 为什么：【对应对齐度矩阵的哪条欲望证据——必须引用】

### 风险动作警告
- 【最容易犯的错误动作】→ 会踩中哪条错位欲望 → 预期后果
```

动作必须从对齐度矩阵推导：往交集欲望投入、绕开错位欲望、对单向欲望决定是补偿还是止损。禁止输出与证据无关的通用建议（「多关心对方」这类话 = 没拆）。

## 场景泛化层（三个预设）

同一套骨架（结构还原→turn-taking→bid-响应→欲望对齐→阶段→下一步），三种参数化：

| | 亲密关系/社交破冰 | 商业跟单 | 团队/合作沟通 |
|---|---|---|---|
| bid 主形态 | 情感试探/亲密升级 | 报价/催单/价值展示 | 提案/求助/认领/反馈请求 |
| 回应分化读作 | 关系温度 | **购买意向温度** | 协作投入度/信任度 |
| 阶段机映射 | 破冰→试探→升级→稳定 | 触达→需求确认→报价→异议→成交/流失 | 组队→磨合→规范→高效→失速 |
| 下一步动作 | 话术+时机 | 跟进策略（推单/让价/放置/养熟） | 沟通修复/职责重协商 |

各场景的 bid 类型完整映射表见 `references/bid-response-taxonomy.md`。

## 内置校准案例（Soul APP 相亲对话）

**输入概况**：Soul APP 私聊截图，深夜跨至凌晨，蓝绿气泡方 vs 白发头像方。平台信号：Soulmate 标签、亲密度半心、存在撤回记录。

**结构还原**：深夜地震话题开场（「好像地震了」——外部事件天然破冰，共同经历的即时素材）。蓝绿方跨 3 个对话分发地震经历（微信聊天截图 + 40:55 通话截图分享）——把白发方纳入自己的多平台生活叙事，高成本投入信号。时间线延伸至凌晨 5 点。

**bid-响应配对**（两个关键 bid 的分化）：
- **Bid 1（自嘲求关注）**：蓝绿方凌晨 5 点「我这精神头要放去读书 怎么样也能考研了」→ 白发方**引用回复**「哈哈哈哈哈」= **engage**，且用了引用回复（成本第二档）——安全幽默层被接住且被精准注意
- **Bid 2（亲密升级试探）**：白发方分享恐惧细节「考虑要不要躲起来」「厕所，或者跑下来 餐桌」（自我暴露，本身是共情 bid），蓝绿方借势升级「我还以为你要说躲进我的怀里呢」+🤭 → 白发方回应单字「**6**」= **deflect**（不 reject 不 ignore，用最低成本的网络语把亲密假设打回玩笑层）

**温度曲线拐点**：Bid 2 就是拐点——engage（引用+哈哈）→ deflect（单字）的落差，说明升级速率超过了对方当前阈值。撤回记录佐证蓝绿方存在自我审查（说了又收回的试探）。

**不对称结构**：蓝绿方 = 推进者（发起、分发截图、升级试探、凌晨在线输出），白发方 = 筛选者（回应但控制成本，接安全话题、挡亲密话题）。

**欲望对齐矩阵**（evidence 逐字）：
- 交集：**深夜陪伴**（双方凌晨仍在互动，归属欲/被爱欲交汇）+ **共同经历**（「好像地震了」共享事件，白发方愿意交出恐惧细节「考虑要不要躲起来」= 有限度的信任投入）
- 错位：**亲密速率**——蓝绿方要即时亲密确认（「躲进我的怀里」），白发方要安全筛选节奏（「6」）。错位在速率不在方向
- 单向：蓝绿方的被爱欲 bid 暂未被对等回应（半心亲密度佐证：平台量表也显示未满格）

**下一步最优动作**（给蓝绿方）：降级回安全话题（地震后续/考研梗延续——已验证被 engage 的层），**把节奏让渡给白发方**，等待其发起下一次自我暴露再跟进。为什么：交集欲望在共同经历层，错位仅在速率——降速可保交集。**风险动作**：继续亲密试探（第二次「怀里」类 bid）→ 踩中速率错位 → deflect 升级为 ignore，筛选者直接出局判负。**基于可见信号**：白发方的「6」也可能是其表达习惯而非降温，需下一轮 bid 验证。

## 纪律

1. **证据必须逐字引用**。每条欲望/状态/阶段断言后面必须跟消息原文（带引号）。无词证的属性断言（年龄/性别/职业/真实意图）**禁止输出**——「白发头像」是头像描述不是年龄判断。
   **evidence 字段的机器可核验硬约束（part7 校准回流，2026-07-22）**：evidence 只允许**从消息流里复制粘贴的连续子串**，禁止改写、概括、补字、拼接多条消息成一句。校准实测 M3 有 ~10–20% 的 evidence 不是逐字子串（case3 最严重）——**引用前先自检该串能否在原文里 Ctrl-F 到；找不到逐字原文的断言直接删掉，宁缺毋滥**。「意图归因」（把「6」判成「降级信号」、把撤回判成「自我审查」）属于**推断不是证据**，必须写进推断层并标「基于可见信号」，不得放进 evidence 字段冒充词证。
2. **低信息量降级**：<10 条消息 → 全部结论标「低确定性」，以候选+概率形式输出（「筛选姿态 60% / 表达习惯 40%」），禁止单一定论。
   **禁止伪精确百分比（part7 校准回流）**：信号稀疏（如 <20 条、单方视角）时，**欲望占比一律降级为「排序 + 高/中/低」，不给具体百分数**——校准实测同一段 19 条对话跑 3 次，A 方欲望 Top2 三次交集为空、百分比大幅漂移，说明细粒度百分比是幻觉精度。**只有 turn-taking 结构判定（推进者/筛选者）和 B 方主导欲望这类粗粒度结论才允许在稀疏输入下断言**（校准中这两项 3 次全稳定）。
3. **单方视角警告**：聊天记录只是行为流的投影，看不到对方的真实处境——回应慢≠冷淡（可能在忙），单字≠敷衍（可能是语言习惯）。所有推断标注「基于可见信号」；截图由一方提供时，警惕选择性截取
4. **隐私边界**：仅处理用户自己参与的对话，或已获对话双方授权的记录。拒绝用于监控、跟踪第三方私聊
5. **功能性解析，不做人格审判**：输出欲望/状态/需求/动作，不输出「渣」「海王」「舔狗」式道德标签。欲望无好坏（同 L4.5 纪律 6）
6. **阶段与温度看模式不看单点**：一条消息不定阶段，一次 deflect 不判降温
7. **每份拆解附自我证伪条件**：什么信号出现时当前判定作废（如「若白发方下次主动发起亲密话题，则『速率错位』假设不成立」）
8. **产品边界（硬约束）**：本层输出关系洞察，不输出针对特定个体的操纵话术脚本；下一步建议仅限双向健康关系或正当商业场景的沟通复盘，不做单方猎取式剧本
