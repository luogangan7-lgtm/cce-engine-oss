# L1.5 · 表现层审计

拆一条内容的「肉」：出镜者是怎么用身体和声音把内容演活的。L1 拆的是画面长什么样，本层拆的是**人**在画面里怎么表现——这是竞品框架普遍缺失的一层，也是把「同一条脚本」拍出天差地别感染力的关键变量。

## 什么时候跑这一层

- 内容里有出镜者（真人/数字人/动画角色对镜头说话或表演）
- 直播切片、口播、测评、剧情、教程——只要有人在镜头前表达
- **纯音频内容**（ASMR/播客/有声书/音乐/口播无画面或画面非关键）——只跑声音表达维度，跳过肢体/形象/镜头感
- 纯视觉奇观类（如电焊机操作画面无人说话）可跳过，标注「无表现层」

## 前提

建立在 L1（视觉取证）之上。先有镜头清单和景别判断，才能精准定位每个镜头里出镜者的表现。

## 拆解维度

### 1. 肢体语言（Body Language）

逐镜头或分段记录出镜者的身体表达。读 `references/body-language-atlas.md` 获取完整肢体语言分类库。

**姿势/姿态（Posture）**
- 站姿/坐姿/走动：是开放的（挺胸、展开、朝向镜头）还是封闭的（含胸、抱臂、侧身）
- 重心：稳（扎根感、权威）/ 动（活络、接地气）/ 摇摆（紧张、不自信）
- 与镜头的角度：正面（亲密、对峙）/ 3/4 侧（标准、专业）/ 侧面（叙事、回避）
- 姿势变化节拍：长时间固定 vs 随内容推进变化

**动作与手势（Movement & Gesture）**
- 手势类型：强调（划重点）/ 描绘（比划形状大小）/ 指引（指向产品/屏幕）/ 计数（掰手指）/ 开放掌（真诚、邀请）/ 封闭拳（力量、决心）/ 无手势（克制、冷）
- 动作幅度：大（外放、能量高）/ 中（自然）/ 小（内敛、专业）/ 无（静态）
- 动作节奏：与语速同步 / 与剪辑点同步 / 与音乐 beat 同步
- 是否有标志性动作（signature gesture）：观众能记住的反复出现的动作

**眼神（Eye Contact）**
- 看镜头的频率：高频直视（亲密、对峙、强钩子）/ 间歇（自然交流）/ 不看（叙事、回避）
- 眼神方向：看镜头（对观众说话）/ 看产品（展示）/ 看画外（叙事、对话感）/ 游移（紧张、不专业）
- 眼神强度：坚定（权威、真诚）/ 温柔（亲和）/ 闪躲（不可信）/ 凝视（强调、暧昧）
- 眨眼频率（高=紧张/兴奋，低=专注/压迫感）

**面部表情（Facial Expression）**
- 微表情：真正的情绪闪过（可信）/ 刻意表演（假）
- 表情丰富度：丰富（感染力强）/ 单一（冷感、酷）/ 木讷（无感染力）
- 笑的质感：真笑（杜兴式，眼角有纹）/ 假笑（只有嘴）/ 不笑（严肃、酷）
- 表情与内容情绪的匹配度：一致（可信）/ 错位（出戏）

**走位与空间关系（Blocking & Proxemics）**
- 在画面里的位置变化：固定（专注）/ 走动（能量、空间感）/ 推近镜头（亲密升级、强调）
- 与道具/产品的空间关系：贴近（亲密、拥有感）/ 保持距离（专业、客观）
- 与镜头的距离变化：由远及近（拉近距离、建立亲密）/ 由近及远（退守、客观化）

### 2. 声音表达（Vocal Delivery）

读 `references/vocal-delivery-guide.md` 获取完整声音表达指南。

**音色（Timbre）—— 声音的物理底色**
- 基础音色类型：低沉浑厚（权威、性感、信任）/ 清亮穿透（活力、年轻、注意）/ 沙哑粗糙（阅历、真实、性感）/ 柔和气声（亲密、ASMR、安抚）/ 稚嫩清脆（可爱、纯真、保护欲）/ 中性冷静（专业、客观、高级）
- 音色与人设的匹配：权威内容配低沉音色 = 协同；年轻活力配清亮 = 协同；反之错位产生不信任
- 音色与目标欲望的映射（关键——这决定了 AI 配音选什么声音。以下为映射候选，供 L3 采纳裁决，本层不下心理结论）：

| 音色类型 | 最易击中的欲望 | 典型场景 |
|----------|--------------|----------|
| 低沉浑厚 | 权威感/安全感/性吸引力 | 知识口播、商业、 luxury 广告 |
| 清亮穿透 | 好奇心/成为欲/活力感 | 测评、开箱、教程、年轻向 |
| 沙哑粗糙 | 真实感/共鸣/阅历感 | 故事、情感、vlog、草根逆袭 |
| 柔和气声 | 归属欲/安全感/亲密感 | ASMR、情感电台、睡前、疗愈 |
| 稚嫩清脆 | 保护欲/可爱/纯真 | 萌宠、亲子、二次元 |
| 中性冷静 | 安全感/专业信任/控制感 | 科技、金融、测评（客观向） |

- 音色的辨识度：有没有让人一听就记住的声音特征（辨识度 = 社交货币 = 关注理由）
- AI 配音提示：如果内容用 AI 生成语音，音色选择是**第一参数**，优先级高于语速和语调。选错音色 = 人设崩塌

**语调（Tone）**
- 基础调性：兴奋 / 平静叙述 / 权威 / 亲切 / 神秘 / 喊话 / 耳语
- 语调变化：单调（催眠/无聊）/ 有起伏（生动）/ 戏剧化（强感染）
- 调性与内容的匹配：激情内容配激情语调 = 协同；严肃内容配嬉皮 = 错位
- 句尾处理：上扬（疑问、不确定、活泼）/ 下沉（肯定、权威、结束）/ 平（冷、克制）

**语速（Pacing）**
- 基础语速：快（紧迫、激情、信息密）/ 中（自然）/ 慢（强调、深情、权威）
- 语速变化：有没有快慢交替（交替 = 有节奏感，催眠 = 无变化）
- 关键处的减速：重要信息前/情绪转折处刻意放慢 = 强调信号
- 留白：说完关键句后的沉默时长（0.5-1s 的留白 = 让观众消化；过长 = 尴尬）

**停顿与重音（Pauses & Emphasis）**
- 停顿位置：句中（制造悬念）/ 句间（分段消化）/ 钩子前（聚拢注意力）/ 关键信息后（让观众记住）
- 停顿时长：短（节奏）/ 中（消化）/ 长（戏剧、压迫）
- 重音落点：重音在动词/数字/痛点词 = 强化记忆；落在虚词 = 浪费
- 呼吸声：保留（真实、ASMR 感）/ 剪掉（精致、专业）

**情绪渲染（Emotional Coloring）**
- 声音里带的情绪：激动 / 感动 / 愤怒 / 克制 / 嘲讽 / 真诚 / 表演感
- 情绪与面部表情是否一致（声画情绪同步 = 可信；不同步 = 出戏或刻意制造反差）
- 情绪递进：从头到尾情绪有没有变化弧（平淡到底 vs 越说越激动 vs 先高后收）
- 声音的「真」：听得出是念稿还是自然说话（念稿感 = 距离感；自然 = 亲切）

**口音与语言质感**
- 口音：标准音（普适）/ 地方口音（接地气、地域认同）/ 外国口音（异域感、新鲜）
- 用词风格：书面（专业、距离）/ 口语（亲切）/ 网络黑话（年轻、圈层）/ 方言（地域、真实）
- 语言瑕疵：保留（真实）/ 修剪（精致）—— 决定了内容的「人味」

### 3. 镜头感（On-Camera Presence）

**与镜头的关系**
- 把镜头当什么：朋友（亲切对话）/ 老师（权威输出）/ 情人（亲密低语）/ 旁观者（纪实）/ 不存在（沉浸叙事）
- 这种关系的稳定性：全程一致（人设清晰）/ 随内容切换（戏剧化）
- 「看观众」vs「被观众看」：主动交流（强 presence）/ 被动展示（弱 presence）

**能量值（Energy Level）**
- 基础能量：高（亢奋、激情、年轻向）/ 中（自然）/ 低（冷静、高级、文艺）
- 能量与内容/人群的匹配：年轻向配高能量；专业向配中低能量
- 能量波动：平稳（稳定人设）/ 起伏大（戏剧化，需要演技支撑）

**存在感（Screen Presence / "It" Factor）**
- 你能不能不看别人只看他：强 presence 的人即使不说话也吸睛
- 存在感来源：长相 / 气质 / 自信 / 表现力 / 镜头习惯
- 画面里多人时谁是焦点（焦点 = presence 最强者，不一定是主角）

### 4. 形象管理（Image & Styling）

**穿着（Wardrobe）**
- 风格：与内容定位是否匹配（专业内容穿休闲 = 不可信；生活向穿正装 = 距离感）
- 色彩：衣服颜色与背景/品牌色的关系（和谐 / 对比 / 冲突）
- 整洁度：精致（高级感）/ 随意（接地气）/ 凌乱（不专业除非刻意）
- 标志性元素：有没有反复出现的穿搭符号（建立辨识度）

**造型（Grooming）**
- 妆造：浓妆（精致、距离）/ 淡妆/素颜（真实、亲切）/ 角色妆（戏剧化）
- 发型：整洁（专业）/ 随性（自然）/ 个性（辨识度）
- 配饰：有（个性、记忆点）/ 无（干净、专注）

**气质（Persona Projection）**
- 整体气质类型：专家 / 朋友 / 榜样 / 草根 / 精英 / 文艺 / 叛逆
- 气质与人设的一致性：表现出的气质和内容主张的人设是否吻合
- 气质的「真」：是自然流露还是表演（观众能感觉出来，假 = 距离感）

### 5. 情绪表达质量（Emotional Expression Quality）

这是表现层的综合评判：出镜者的表现有没有让观众**代入**。

- **真诚度（Authenticity）**：观众感觉这是真人真情绪还是表演？真诚 = 信任 = 转化
- **代入感（Vicarious Induction）**：看出镜者表达时，观众能不能感同身受（高代入 = 强感染）
- **情绪传染力**：出镜者的情绪有没有「溢出」画面传染给观众
- **一致性**：肢体+声音+表情+眼神+形象，五个通道是否传达同一个情绪（全一致 = 可信、强感染；不一致 = 出戏或刻意反差）
- **层次感**：情绪表达有没有层次（从平静到激动 vs 一惊一乍到底）

## 纯音频内容分析模式

当分析对象是纯音频内容（ASMR/播客/有声书/纯音乐/口播音频，无画面或画面非关键），切换到纯音频模式：

### 适用场景
- ASMR 视频（画面是静态图或仅展示手部，声音才是主角）
- 播客/有声书（纯声音叙事，无视觉表演）
- 纯音乐内容（BGM/原创音乐/翻弹，无歌词或歌词非关键）
- 口播音频（声音质感是核心吸引力，如电台/夜话/讲故事）

### 纯音频模式的分析重点

**只分析声音表达维度**（跳过肢体语言/镜头感/形象管理/五通道一致性），但深度加倍：

1. **音色深度分析**（比视频模式更深入，因为没有画面分散注意力）
   - 基础音色类型 + 音色的物理特征描述（共鸣位置/声带闭合程度/气息比例）
   - 音色变化：全程一致 vs 有变化（变化点在什么内容处，为什么变）
   - 音色的「触感」：听众身体感受描述（酥麻/放松/紧张/温暖——ASMR 类尤其重要）

2. **声音空间感**（纯音频独有维度）
   - 立体声/双耳录音：左右声道交替/固定/移动（3Dio ASMR 的左右交替是核心触发器）
   - 近场效应：声音距离感（耳边/面前/远处——越近越亲密越触发 ASMR）
   - 空间混响：干声（贴耳/亲密）/ 微混响（自然空间）/ 大混响（空旷/史诗/神秘）

3. **声音的物理触发分析**（ASMR 专用）
   - 触发音类型：敲击/摩擦/轻语/唇音/呼吸/撕扯/刷扫/滴水
   - 触发音的频率分布：低频（闷/厚/安全感）/ 高频（脆/亮/警觉）/ 全频（丰富/满足）
   - 节奏模式：规律（催眠/安全感）/ 不规律（惊喜/保持注意）/ 渐变（从慢到快的情绪升级）

4. **音乐内容分析**（纯音乐专用）
   - BPM 和节奏感：慢（< 90 = 放松/深思）/ 中（90-120 = 自然/流行）/ 快（> 120 = 激情/舞曲）
   - 音色选择：模拟温暖（Lo-fi/爵士）/ 数字冷感（电子/Synthwave）/ 原声真实（民谣/古典）
   - 和弦情绪：大调（明亮/积极）/ 小调（暗沉/忧郁）/ 蓝调（性感/慵懒）/ 不协和（紧张/前卫）
   - 动态范围：压缩平坦（现代响度战争/持续冲击）/ 大动态（古典式/情绪起伏）

### 纯音频的爆款逻辑

纯音频内容的爆款发动机和视频不同：
- **ASMR**：发动机 = 生理触发（酥麻感是真实的身体反应，不可伪造）→ 欲望 = 安全感欲（亲密感/放松是其情绪外化）
- **播客/口播**：发动机 = 声音质感 × 内容深度（声音让人愿意听，内容让人听完）→ 欲望 = 归属欲/成为欲/确认欲
- **纯音乐**：发动机 = 情绪即触发（音乐直接绕过理性击中情绪）→ 欲望 = 取决于音乐类型（Lo-fi→安全感欲/史诗→超越欲/爵士→向往欲（美学向））

## 纪律

- 肢体语言判断必须给依据（具体动作），不能只说「开放姿势」
- 声音表达要具体到位置（第几秒语速变化、哪个词重音），不能只说「语速快」
- 形象判断必须关联内容定位（穿着对不对得起这个人设），不是单纯评美丑
- 真诚度判断要谨慎：无法 100% 确定，只能说「观感上真诚/有表演感」+ 依据
- 如果是 AI 数字人/动画角色，标注并按「拟人表现」分析，指出与真人的差异
- 表现层结论必须回答「换个人演会丢什么」，这是最有操作价值的产出

## 给 L3 的馈赠

表现层的发现不是孤立的，喂给 L3 心理挖掘：
- 肢体语言的开放度 → 信任感（开放 = 可信）
- 声音的温度 → 权威感/亲和感（暖声 = 亲和，冷声 = 权威）
- 眼神直视频率 → 亲密感（高频直视 = 拉近距离）
- 真诚度 → 转化力（真诚 = 信任 = 成交）
- 五通道一致性 → 可信度（一致 = 观众不怀疑 = 接受度高）
