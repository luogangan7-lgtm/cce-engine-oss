# 声音表达指南

viral-performance-audit (L1.5) 的声音表达拆解库。系统化拆解出镜者怎么用声音抓住观众。

---

## 一、语调（Tone）

### 基础调性分类

| 调性 | 特征 | 传递信号 | 适用内容 |
|------|------|----------|----------|
| 兴奋 | 音高上扬、能量足 | 激情、年轻、有趣 | 种草、开箱、娱乐 |
| 平静叙述 | 中音区、稳 | 可信、专业、故事感 | 测评、知识、叙事 |
| 权威 | 低沉、慢、稳 | 专业、可信、力量 | 专家、教程、高端 |
| 亲切 | 偏高、柔和、像聊天 | 亲和、朋友感 | 生活、Vlog、陪伴 |
| 神秘 | 低、慢、带气声 | 悬念、高级、故事 | 剧情、悬疑、文艺 |
| 喊话 | 大音量、高能量 | 号召、激情、接地气 | 带货、喊麦 |
| 耳语 | 小音量、近麦、气声 | 亲密、ASMR、秘密 | ASMR、深夜、亲密向 |

### 语调变化

- **单调**：催眠/无聊（除非刻意制造冷静高级感）
- **有起伏**：生动、有节奏感
- **戏剧化**：大起大落，强感染（需演技）

### 句尾处理（常被忽略但极重要）

| 句尾 | 效果 | 判断 |
|------|------|------|
| 上扬（↑） | 疑问、不确定、活泼、年轻 | 口语化、亲切 |
| 下沉（↓） | 肯定、权威、结束、可信 | 专业、有力 |
| 平（→） | 冷、克制、高级 | 文艺、酷感 |

**爆款信号**：钩子句尾上扬（抓注意）+ 结论句尾下沉（立权威）= 经典节奏。

## 二、语速（Pacing）

### 基础语速

| 语速 | 字/秒（中文参考） | 传递 | 适用 |
|------|-------------------|------|------|
| 快 | >5 | 紧迫、激情、信息密 | 娱乐、带货、快节奏 |
| 中 | 3-5 | 自然、平衡 | 大多数内容 |
| 慢 | <3 | 强调、深情、权威 | 故事、高端、情感 |

### 语速变化（节奏感的来源）

- **快慢交替**：有节奏感，避免催眠
- **关键处减速**：重要信息前/情绪转折处放慢 = 强调信号（观众潜意识会注意）
- **加速段**：信息密集段、激情段
- **恒定语速**：稳定但易催眠（专家可接受，娱乐向不行）

### 留白（Silence）

说完关键句后的沉默。

| 留白时长 | 效果 |
|----------|------|
| 0.3-0.5s | 自然分段，节奏感 |
| 0.5-1s | 让观众消化关键信息 |
| 1-2s | 戏剧、压迫、强调 |
| >2s | 尴尬（除非刻意 ASMR/艺术） |

**爆款用法**：钩子后 0.5s 留白 → 让观众反应「这是什么」→ 再展开。痛点句后 1s 留白 → 让观众对号入座。

## 三、停顿与重音（Pauses & Emphasis）

### 停顿位置

| 位置 | 功能 |
|------|------|
| 句中（主语后/动词前） | 制造悬念 |
| 句间 | 分段消化 |
| 钩子前 | 聚拢注意力（「……你知道吗？」） |
| 关键信息后 | 让观众记住 |
| 情绪转折处 | 让情绪发酵 |

### 停顿时长

- 短（0.3s 内）：节奏润滑
- 中（0.3-1s）：消化、强调
- 长（>1s）：戏剧、压迫、艺术

### 重音落点

重音落在不同词性，效果天差地别：

| 重音落点 | 效果 | 例 |
|----------|------|----|
| 动词 | 强化行动 | 「你**必须**试这个」 |
| 数字 | 强化记忆 | 「**7 天**见效」 |
| 痛点词 | 强化共鸣 | 「每次**失眠**都很崩溃」 |
| 对比词 | 强化反差 | 「不是 A，是**B**」 |
| 虚词（的/了/吗） | 浪费、怪 | 避免 |

**爆款信号**：重音精准落在痛点词和数字上 = 记忆点。

### 呼吸声处理

- 保留：真实、ASMR 感、接地气（草根/Vlog）
- 剪掉：精致、专业、流畅（精品/教程）
- 放大：ASMR、亲密向（刻意）

## 四、情绪渲染（Emotional Coloring）

### 声音里的情绪

声音是情绪最强的载体之一（甚至强于画面）。

| 情绪 | 声音特征 |
|------|----------|
| 激动 | 音高、快、大音量、气足 |
| 感动 | 颤音、慢、轻、带气声 |
| 愤怒 | 低、硬、爆破音重、快 |
| 克制 | 平、轻、紧绷感 |
| 嘲讽 | 拖长音、音调玩弄、假笑感 |
| 真诚 | 稳、中速、无过度修饰 |
| 表演感 | 过度修饰、不自然的起伏 |

### 声画情绪同步

- **同步**（声音情绪 = 面部情绪）：可信、强感染
- **不同步**：出戏，或刻意制造反差（高级玩法，需演技）

### 情绪递进

- **平淡到底**：稳定但易无聊（除非高级冷感）
- **越说越激动**：激情 buildup，感染力强
- **先高后收**：钩子激情 → 内容平静收 = 有层次
- **波浪式**：多次起伏 = 戏剧化、需演技

### 声音的「真」

- **念稿感**：节奏机械、重音不准、无自然停顿 → 距离感
- **自然说话**：有自然的嗯啊、停顿、自我修正 → 亲切、可信
- **判断方法**：听有没有「过于流畅」——真人说话会有小磕绊，念稿没有

## 五、口音与语言质感

### 口音

| 口音 | 效果 |
|------|------|
| 标准音（普通话/标准英语） | 普适、专业、可信 |
| 地方口音 | 接地气、地域认同、真实 |
| 外国口音 | 异域感、新鲜、特定人设 |
| 特定方言 | 圈层认同、地域爆款 |

### 用词风格

- 书面（专业词、长句）：专业、距离
- 口语（短句、语气词）：亲切、自然
- 网络黑话：年轻、圈层
- 方言：地域、真实

### 语言瑕疵

- 保留（嗯/啊/重复）：真实、人味
- 修剪干净：精致、专业
- 决定保留还是修剪 = 决定内容的「人味浓度」

## 六、声音表现力评分模型

快速评估出镜者声音表现力的 5 维度（每维 1-5 分）：

| 维度 | 1 分 | 5 分 |
|------|------|------|
| 节奏感 | 单调催眠 | 快慢起伏有韵律 |
| 重音精准 | 重音乱落或无 | 重音全落在关键词 |
| 情绪渲染 | 平淡无情绪 | 情绪饱满有层次 |
| 真诚度 | 明显念稿 | 完全自然说话 |
| 清晰度 | 含糊/吃字 | 字字清晰 |

总分 20+ = 强声音表现；15-19 = 中等；<15 = 需提升。

**注意**：这是辅助评估工具，不是硬性 gate。某些人设（冷感/酷）低分也可能是刻意选择。

---

## 使用建议

- 声音分析必须具体到位置（第几秒语速变化、哪个词重音），不能笼统说「语速快」
- 判断念稿感要谨慎：有些人天生说话流畅，不一定是念稿。看有没有「过于完美」的停顿
- ASMR/耳语类有专门的声音美学，不要用通用标准评判
- 如果只有字幕无原声（静音视频），标注「无声音层，无法分析」
