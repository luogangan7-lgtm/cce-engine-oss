# 肢体语言图鉴

viral-performance-audit (L1.5) 的肢体语言分类库。系统化拆解出镜者的身体表达。

---

## 一、姿势/姿态（Posture）

### 开放 vs 封闭

**开放姿势（Open Posture）**
- 特征：挺胸、双肩展开、身体朝向对话者/镜头、手脚不交叉
- 传递信号：自信、真诚、欢迎、权威（结合坚定眼神）
- 爆款应用：测评/知识类博主的「专家感」、生活向博主的「亲切感」
- 判断依据：肩线是否打开、身体中轴线是否朝向镜头

**封闭姿势（Closed Posture）**
- 特征：含胸、抱臂、侧身、手插兜遮住、身体转向一侧
- 传递信号：防御、不确定、紧张、回避（或刻意制造神秘/酷感）
- 爆款应用：剧情向的「有故事感」、酷感人设、刻意制造距离
- 判断依据：是否有交叉肢体、身体朝向偏离镜头

### 重心与稳定

| 重心状态 | 传递信号 | 适用场景 |
|----------|----------|----------|
| 扎根（重心下沉稳） | 权威、可信、专业 | 专家、教程 |
| 活络（重心移动） | 接地气、活力、自然 | 生活、Vlog |
| 摇摆（重心不稳） | 紧张、不自信（通常负面） | 避免或刻意表现紧张 |
| 前倾（重心朝镜头） | 积极、投入、想靠近 | 钩子、亲密交流 |
| 后仰（重心远离） | 放松、自信、或轻蔑 | 草根人设、点评类 |

### 与镜头角度

- **正面（0°）**：亲密、对峙、强 presence。口播钩子常用
- **3/4 侧（~30-45°）**：标准、专业、自然。大多数测评/教程
- **侧面（~90°）**：叙事、对话感、回避直视。剧情向
- **背身**：神秘、故事感、或刻意不露脸（神秘博主）

## 二、手势（Gesture）

### 功能分类

**强调手势（Batoning）**
- 动作：手指点、手掌切、拳头敲
- 功能：划重点、强化关键词
- 用法：说到数字/痛点/结论时配合

**描绘手势（Illustrators）**
- 动作：比划大小/形状/方向/距离
- 功能：可视化抽象概念
- 用法：「这么大」「从这里到这里」「快速地」

**指引手势（Pointing）**
- 动作：指向产品/屏幕/画面元素
- 功能：引导观众注意力
- 用法：展示产品细节、引用屏幕数据

**计数手势（Counting）**
- 动作：掰手指
- 功能：清单感、结构感
- 用法：「三个原因」「第一步」

**开放掌（Open Palm）**
- 动作：掌心朝上/朝外
- 功能：真诚、邀请、无可隐瞒
- 用法：建立信任、CTA「来看看」

**封闭拳（Closed Fist）**
- 动作：握拳
- 功能：力量、决心、愤怒
- 用法：情绪高潮、号召

**自我触摸（Self-Adaptors）**
- 动作：摸头发/鼻子/衣服/首饰
- 功能：通常传递紧张/不自在（除非刻意人设）
- 注意：高频自我触摸 = 紧张信号，但草根真实向可接受

### 幅度

| 幅度 | 传递 | 适用 |
|------|------|------|
| 大（超出肩宽） | 外放、能量高、激情 | 年轻向、激情向 |
| 中（肩宽内） | 自然、平衡 | 大多数内容 |
| 小（贴近身体） | 内敛、专业、克制 | 专家、高端 |
| 无 | 静态、冷、或紧张 | 文艺、酷感；避免不专业的静止 |

### 标志性动作（Signature Gesture）

反复出现的、观众能记住的动作。建立辨识度。
- 识别：跨多条内容反复出现的同一动作
- 价值：观众一看就知道是你
- 例：特定手势开场、特定动作配特定口头禅

## 三、眼神（Eye Contact）

### 看镜头频率

| 频率 | 效果 | 适用 |
|------|------|------|
| 高频直视（>70% 时间看镜头） | 亲密、对峙、强钩子 | 口播、直接对话观众 |
| 间歇（30-70%） | 自然交流 | 测评、教程 |
| 低频（<30%） | 叙事、沉浸 | 剧情、纪实 |
| 不看镜头 | 沉浸叙事、或回避 | 剧情向；避免不专业 |

### 眼神方向

- **看镜头**：对观众说话、建立连接
- **看产品/道具**：展示、引导注意
- **看画外**：对话感（像在和画外人说话）、叙事
- **游移**：紧张、不专业（除非刻意）

### 眼神强度

- **坚定凝视**：权威、真诚、强调
- **温柔注视**：亲和、亲密
- **闪躲**：不可信、紧张
- **长时间凝视（>3s 不眨）**：压迫感、暧昧、或强调

### 眨眼

- 高频眨眼：紧张、兴奋、或说谎（潜意识信号）
- 低频眨眼：专注、压迫、权威
- 正常：自然、可信

## 四、面部表情（Facial Expression）

### 微表情（Micro-Expressions）

持续 0.04-0.2 秒的真实情绪闪过，难以伪装。
- 价值：判断真诚度的硬证据
- 常见：轻蔑（嘴角单侧上扬）、惊讶（眉眼短暂上抬）、愤怒（眉间纹）、恐惧（嘴角下拉）
- 爆款应用：真诚测评的微表情 = 可信；刻意表演无微表情 = 假

### 笑的质感

| 笑的类型 | 特征 | 传递 |
|----------|------|------|
| 杜兴式真笑（Duchenne） | 眼角有鱼尾纹、脸颊上抬 | 真诚、快乐 |
| 社交假笑 | 只有嘴动、眼无变化 | 客套、或刻意 |
| 不笑 | 嘴角平 | 严肃、酷、专业 |
| 冷笑/讥笑 | 嘴角单侧上扬 | 轻蔑、讽刺（人设） |

### 表情丰富度

- 丰富（多种表情快速切换）：感染力强、戏剧化、年轻向
- 单一（一两个表情到底）：冷感、酷、人设稳定
- 木讷（无明显表情）：无感染力（除非刻意高级感）

### 表情与内容匹配

- 一致：可信、不出戏
- 错位：出戏（讲悲伤事却笑 = 出戏）、或刻意制造反差（高级玩法，需演技）

## 五、走位与空间关系（Blocking & Proxemics）

### 画面位置

- **固定居中**：专注、权威、主角感
- **固定偏侧**：留白构图、文艺、或让位给产品
- **走动**：能量、空间感、Vlog 感
- **推近镜头**：亲密升级、强调、情绪高潮

### 与镜头距离变化

- **由远及近**：拉近距离、建立亲密、走向观众
- **由近及远**：退守、客观化、结束感
- **距离恒定**：稳定、专业

### 与道具/产品空间

- 贴近：亲密、拥有感、熟悉
- 保持距离：专业、客观、敬畏

## 六、五通道一致性模型

判断感染力的核心框架：肢体+声音+表情+眼神+形象，五个表达通道是否传达同一个情绪。

| 一致性 | 效果 | 判断 |
|--------|------|------|
| 五通道全一致 | 可信、强感染、观众不怀疑 | 强表现 |
| 4/5 一致 | 基本可信，一个脱节通道需找原因 | 中等 |
| 3/5 以下一致 | 出戏、或刻意反差（需演技支撑） | 弱/特殊 |

**常见脱节**：
- 嘴上说「我很激动」但身体后仰、声音平 → 不一致 → 假
- 表情笑但眼神闪躲 → 不一致 → 不可信
- 语调兴奋但手势少 → 不一致 → 表演感

五通道一致性是判断「真不真」的硬指标，比单看任何一个通道都准。

## 使用建议

- 拆解时不必每个维度都写，抓最突出的 2-3 个特征深挖
- 肢体语言是「证据」不是「结论」——记录具体动作，再推断信号
- 跨文化差异：某些手势在不同文化含义不同（如 OK 手势），标注文化语境
- AI 数字人：按拟人表现分析，重点指出与真人的差异（微表情缺失、眨眼不自然等）
