# 评论分类库（Comment Taxonomy）

评论区分析的标准分类体系和解读指南。配合 viral-comment-intelligence SKILL.md 使用。

## 9 大评论类型详解

每类附：识别关键词模板、心理底层、放大启示、风险提示。

---

### 1. 痛点表达（Pain Expression）

**识别模板**：
- 「我也是…」「我之前…」「经历了同样的…」
- 「太真实了」「说到心坎里了」「谁懂啊」
- 直接描述自己的困境/痛苦/不满

**心理底层**：观众被内容触发了自己的痛点记忆，通过表达获得情绪释放 + 寻找同类（「不只我一个人这样」）。

**放大启示**：
- 这类评论是**选题金矿**——观众自己说了他们的痛苦，下一条内容直接深挖这个痛
- 痛点表达越具体、越长，价值越高（泛泛的「太难了」价值低，具体的「我带娃的时候…」价值高）
- 聚类多个相似痛点表达 → 这个人群的核心痛点就是它们

**风险提示**：无（痛点表达是正向信号，说明内容深度连接成功）

---

### 2. 欲望表达（Desire Expression）

**识别模板**：
- 「求链接」「在哪买」「什么牌子」「多少钱」
- 「我也想要」「太馋了」「好想试」
- 「已下单/已加购/已收藏」
- 「什么时候出」「等一个」

**心理底层**：内容成功激发了拥有欲/成为欲/向往欲，观众的下一步行为意愿被激活。

**放大启示**：
- 欲望表达集中 = 内容的转化路径通畅，L4 放大时保留这条路径
- 「求链接」多但转化少 → 考虑购买门槛是否太高（价格/获取难度）
- 「等一个」系列评论 → 观众在催更，有系列化空间

**风险提示**：欲望表达过多但无痛点表达支撑 → 内容种草力强但需求根基浅（可能是一次性热度）

---

### 3. 社会认同（Social Solidarity）

**识别模板**：
- 「我也是」「同款」「+1」「代表我说了」
- 「终于有人说出来了」「这才是真相」
- 「原来不是只有我这样」

**心理底层**：观众发现自己的感受/经历是普遍的，获得了「我不是异类」的安全感。归属欲 + 确认欲同时被满足。

**放大启示**：
- 社会认同集中 → 内容激活了群体归属感，适合做社群/粉丝运营
- 「代表我说了」类评论 → 内容替这个群体发声了，有 KOL/KOC 潜力
- 聚类社会认同评论的共同身份标签 → 这是你的核心粉丝画像

**风险提示**：社会认同如果绑定单一事件/人物 → 粉丝粘性强但破圈难（饭圈化风险）

---

### 4. 身份信号（Identity Signaling）

**识别模板**：
- 「作为XX人我…」「XX人路过」「XX专业的来回答」
- 地域标记（方言/「广东人」「东北人」「上海人」）
- 职业/年龄/身份标签自报（「90后宝妈」「程序员」「留学生」）
- 文化符号识别（「这个是XX文化的」「正宗XX做法」）

**心理底层**：观众通过标明身份来（a）claim 自己在这个话题上的发言权/归属权，（b）强化自我认同，（c）寻找同身份的其他人。

**放大启示**：
- 身份信号密集 → 内容成功激活了某个身份群体的认同
- 不同身份标签的分布 → 你的内容穿透了哪些人群（比平台后台的 demographics 更真实）
- 身份标签 + 痛点表达组合（「作为宝妈我太懂这种…」）→ 精准的人群+痛点组合，直接可用于 L4 的人群定位

**风险提示**：身份信号如果排他性强（「只有XX人才懂」「外人别评价」）→ 内容被某群体「圈地」，破圈阻力增大

---

### 5. 个人故事（Personal Story）

**识别模板**：
- 完整叙述自己的经历（通常 3 行以上）
- 带时间线/转折/结局（「我以前…后来…现在…」）
- 分享具体细节（人名/地点/数字）

**心理底层**：内容触发了观众的自我记忆（锚点效应/故事运输），观众通过分享自己的故事来（a）参与共建，（b）寻求建议/共鸣，（c）记录和表达。

**放大启示**：
- 个人故事是**最深的连接信号**——观众愿意花时间写自己的故事，说明内容真正走进了他们的生活
- 多个个人故事的共同主题 → 这个人群的生命体验核心命题
- 个人故事可直接转化为下一期内容的素材（征得同意/脱敏后）

**风险提示**：注意隐私——个人故事包含真实信息，用于分析没问题但对外引用必须脱敏

---

### 6. 情绪宣泄（Emotional Release）

**识别模板**：
- 纯情绪词：哈哈哈哈/哭了/笑死/绝了/呜呜呜/啊啊啊
- 表情包刷屏
- 重复内容里的金句（复读机效应）
- 短促感叹，少实质内容

**心理底层**：内容的情绪密度过高，观众来不及/不愿意组织语言，直接释放情绪。情绪传染成功的标志。

**放大启示**：
- 情绪宣泄多 → 内容的情绪感染力强（L1.5 表现层和 L1 音乐/画面功不可没）
- 但情绪宣泄为主、其他类少 → 连接是浅层的（爽完就走），转化力弱
- 情绪宣泄 + 少量痛点/欲望表达 = 最佳组合（先勾住情绪再建立深度）

**风险提示**：纯情绪宣泄的评论区容易「来得快去得快」，热度难持续

**tie-break**：评论带任何共鸣语义（「又学了新知识」「太真实了」）不记此类，记「社会认同」——见下方 tie-break 规则。

---

### 7. 提问求解（Information Seeking）

**识别模板**：
- 「怎么做」「在哪」「什么牌子」「多少钱」「有没有教程」
- 「这个是真的吗」「靠谱吗」「有没有副作用」
- 「有没有替代品」「平价推荐」

**心理底层**：内容激发了需求但没提供完整信息，观众主动补全信息缺口。好奇心 + 拥有欲 + 风险规避。

**放大启示**：
- 提问集中点 = 内容的信息盲区，下一条直接补这个盲区就是选题
- 同一个问题反复出现 → 这是高频需求，值得做成系列/合集
- 提问的深度反映观众阶段：「多少钱」=初期，「怎么搭配用」=已购买想深化

**风险提示**：提问无人回答 → 观众体验差，考虑在评论区主动回复或内容里预告下期解答

---

### 8. 异议/争论（Dissent & Debate）

**识别模板**：
- 「不对」「不同意」「太假了」「智商税」
- 和其他评论辩论（楼层式争论）
- 提出反面观点/数据/经历
- 阴谋论/质疑动机（「这是广告吧」「恰饭了」）

**心理底层**：
- 真实异议：内容踩了观众的某个信念/利益/经验
- 表达权争夺：观众想证明自己更懂/更对
- 投射：内容触发了观众自己的不满，借题发挥

**放大启示**：
- 异议集中且有数据/经历支撑 → 内容有事实硬伤或视角盲区，要正视
- 异议但无实质论据（纯「假的」「广告」）→ 可能是竞品黑/路过喷子，观察但不盲从
- 争论楼层高且双方都有道理 → 话题本身有张力，**这是放大金矿**——做一条专门探讨这个争议点的内容

**风险提示**：
- 异议涉及安全/健康/法律 → 必须正面回应，不能装看不见
- 争论演变成人身攻击/站队 → 社区毒性风险，需要管理
- 「恰饭」质疑集中 → 内容的商业属性太明显，下次更克制地植入

---

### 9. 幽默/玩梗（Humor & Memes）

**识别模板**：
- 段子/谐音梗/双关
- 复读内容里的金句（造梗成功）
- 跨内容玩梗（把其他梗带进来）
- 表情包/图片评论

**心理底层**：娱乐性参与。观众通过幽默来（a）展示自己的 wit，（b）融入社区氛围，（c）低成本参与。

**放大启示**：
- 幽默评论被高赞 → 内容有造梗力/二创空间，适合做梗图/表情包运营
- 同一个梗被反复玩 → 内容的标志性元素找到了，L4 可以强化
- 幽默评论多但痛点/欲望评论少 → 内容娱乐性强但需求连接弱

**风险提示**：幽默如果带冒犯性（地域黑/身材羞辱/性别歧视）→ 及时管理，避免社区毒性

**tie-break**：玩梗式提问按句子功能判——真在求答案记「提问求解」，问句只是表演载体记此类——见下方 tie-break 规则。

## 高频混淆边界 tie-break 规则（part5 校准回流，2026-07-22）

part5 校准实测：9 类单次分类 all-3-agree 仅 64%（pairwise 74.7%），混淆**系统性**集中在两对边界。分类遇到两可时按以下规则裁决：

1. **情绪宣泄 vs 社会认同**（短共鸣评论）：看有无**指向对象/群体**——带任何共鸣语义或指向对象/群体（「又学了新知识」「太真实了」「谁懂啊」）→ 记**社会认同**；仅纯情绪词/纯表情/纯语气词（哈哈哈/哭了/啊啊啊/表情包刷屏）→ 记**情绪宣泄**。
2. **幽默玩梗 vs 提问求解**（玩梗式提问）：**句子功能优先于句式**——问句形式不决定分类，看它在**求答案**还是在**表演**。存在真实信息缺口（问地点/价格/方法/真伪，期待被回答）→ 记**提问求解**；问句只是梗的载体、不期待回答（「[捂脸]为啥是钓鱼佬→误入歧途」）→ 记**幽默玩梗**。

生产环境做 9 类分布时建议 3-run 多数投票（见 SKILL.md 模块一）。

## 分布模式解读速查

| 分布特征 | 含义 | 行动建议 |
|----------|------|----------|
| 痛点+欲望占 >40% | 内容精准戳需求 | 保留路径，L4 强化满足感 |
| 社会认同+身份信号占 >30% | 群体归属激活 | 社群运营 + 身份化内容 |
| 提问求解集中 | 信息盲区 | 下期补盲区，做教程/详解 |
| 情绪宣泄压倒其他 | 感染力强但连接浅 | 加深度钩子（痛点/故事） |
| 异议争论集中 | 话题有张力 | 评估风险，可能做争议探讨 |
| 幽默玩梗主导 | 娱乐性强 | 加梗图运营，但别指望高转化 |
| 个人故事多 | 深度连接 | 征集故事做UGC系列 |
| 分布均匀无明显主导 | 触发广泛但浅 | 找一个深度方向聚焦 |

## 评论质量分级

用于排序哪些评论最值得分析：

| 级别 | 特征 | 分析价值 |
|------|------|----------|
| S级 | 高赞 + 痛点/欲望/个人故事 + 具体 | 最高，直接提取人群洞察 |
| A级 | 高赞 + 社会认同/身份信号 | 高，提取群体画像 |
| B级 | 中赞 + 任何有实质内容的类型 | 中，补充分析 |
| C级 | 低赞 + 情绪宣泄/幽默 | 低，统计感染力 |
| D级 | 水军/控评/无意义 | 忽略（但要识别并标注） |

分析时优先处理 S 级和 A 级评论，它们承载了 80% 的洞察。
