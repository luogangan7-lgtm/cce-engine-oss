# L3.5 · 评论智能（观众欲望的直接证据）

评论区是整个拆解体系里**信息密度最高的一层**。观看和点赞是被动行为（可能只是顺手），评论是主动输出——观众花力气打字，是因为内容戳到了某个足够强的点。高赞评论更是群体共鸣的信号放大器。

这一层不做空泛的「情感分析」，而是把每条评论当成**观众自发提交的欲望/痛点证词**，分类、归因、画像。

## 为什么评论层独立于 L3 心理挖掘

L3 是从**内容本身**推断观众心理（这条内容戳了什么）。L3.5 是从**观众的直接表达**验证和深化 L3 的推断。两者交叉验证：L3 说「这条内容戳了身份焦虑」，L3.5 的评论区如果确实充满身份焦虑的表达 → 证据闭环。如果评论区完全没提到焦虑而在吵另一个话题 → L3 的推断需要修正，或者内容意外触发了另一个心理层。

**一句话**：L3 猜观众在想什么，L3.5 让观众自己说。

**引擎背书（诚实标注）**：评论是**文本原生的决策面**（观众自发文字），正是认知因果引擎已验证充分的通道——从评论逆推的受众级欲望共振读出已有外部真值背书（ρ≈0.5，两轮预注册）。因此高赞评论→核心欲望的映射是**受众级已证粒度**（可信赖），但仍是「推断」非「读出确定真值」，且结论只适用于「高投入评论者」而非全体观众（见纪律1）。

## 前提

- 已有评论数据（抓取或手动复制）。没有评论区的纯视觉内容跳过此层
- 建议先跑完 L1（视觉）和 L2（结构），这样回溯触发源时能定位到具体画面/文案
- 最好已跑 L3，用 L3 的心理假设作为评论分类的先验框架

## 评论获取

优先用 `/Volumes/data/lead-miner/unified_scraper.py "URL" --max 100`（TikTok/YouTube 无登录 Playwright 方案，已验证）。抖音/小红书/Instagram 需手动复制或已登录浏览器。至少抓 50 条，高赞评论优先（前 30 条按赞数排序 + 后 20 条按时间排序，兼顾热度和新鲜度）。

## 五个分析模块

### 模块一：评论分类

每条评论归入以下 9 类之一（一条评论可能跨类，取主导类）：

| 类型 | 识别特征 | 欲望信号强度 |
|------|----------|-------------|
| **痛点表达** | 描述自己的相似困境/痛苦/不满 | ★★★★★ 最强 |
| **欲望表达** | 「我也想要」「求链接」「在哪买」「太馋了」 | ★★★★★ 最强 |
| **社会认同** | 「我也是」「同款经历」「代表我说了想说的话」 | ★★★★ 强 |
| **身份信号** | 表明自己属于某群体/标签（「作为XX人我…」「广东人路过」） | ★★★★ 强 |
| **个人故事** | 分享自己的完整经历/故事（通常较长） | ★★★ 中强 |
| **情绪宣泄** | 哈哈哈/哭了/愤怒/感动，纯情绪少信息 | ★★ 中 |
| **提问求解** | 问怎么做/在哪/多少钱/什么牌子 | ★★★ 中强 |
| **异议/争论** | 反对内容观点或和其他评论争论 | ★★★ 中强（暴露未满足的期待） |
| **幽默/玩梗** | 梗/段子/谐音/复读，娱乐性参与 | ★ 弱（但高赞=共鸣信号） |

9 类评论的完整识别模板与边界判例见本 skill 的 `references/comment-taxonomy.md`（独立使用本 skill 时也要读它）。

**生产环境建议（part5 校准回流 2026-07-22）**：9 类分布用 **3-run 多数投票**后再解读分布模式——单次分类 all-3-agree 仅 64%，类间误差 ±2-3 条足以翻转「分布模式解读」；两对高频混淆边界（情绪宣泄↔社会认同、幽默玩梗↔提问求解）的 tie-break 规则见 taxonomy 文件。

**分类不是目的，分类是为了看分布**。统计每类评论的占比和高赞集中度。分布模式比单条评论重要：
- 痛点表达 + 欲望表达占比 >40% → 内容精准戳到了真实需求
- 社会认同 + 身份信号占比高 → 内容激活了群体归属感
- 异议/争论集中且高赞 → 内容踩了某个有争议的线（可能是放大机会也可能是风险）
- 幽默/玩梗占主导但其他类稀少 → 内容火了但没建立深度连接（娱乐性强转化力弱）

### 模块二：评论→欲望映射

高赞评论是**最强共鸣信号**。把点赞数排名前 20% 的评论单独提取，逐一问：

**这条评论的作者想要什么？**（不是字面意思，是背后的核心欲望）

映射路径——欲望 9 类完整定义见唯一权威源 `viral-psychology-excavator/references/desire-taxonomy.md`，此处只保留**评论层独有的句式→欲望映射**：
- 「求链接」「在哪买」→ **拥有欲**
- 「我也想变成这样」「好羡慕」→ **成为欲**
- 「想住进去」「好想去」「这就是理想生活」「梦中情X」→ **向往欲（投射欲）**（想进入那个画面，不是群体归属——划界判据见权威源）
- 「我也是这样，太痛苦了」→ **摆脱欲** + **确认欲**（确认自己不孤独）
- 「作为XX人我太懂了」→ **归属欲** + **确认欲**（身份认同被验证）
- 「这说的是我吧」「替我说了」→ **确认欲**（被代表被理解）
- 「凭什么他能我不能」→ **超越欲** + 不公平感
- 「已下单/已收藏/已关注」→ **拥有欲** + **控制欲**

**输出**：统计前 20% 高赞评论映射到哪些欲望类。排名第一的欲望 = 这条内容击中的**核心欲望**。这个结论和 L3 的欲望解码交叉验证——如果一致，证据闭环；如果不一致，以评论区为准（观众的行为比推断更可信）。

### 模块三：评论者画像推断

从评论语言推断评论者群体（不是精确人口统计，是心理和行为特征）：

**语言信号**：
- 用词和表达方式 → 年龄段（「绝绝子」Z世代 / 「这东西真好」中年 / 专业术语从业者）
- 方言/地域标记 → 地域（「中」「巴适」「杠杠的」）
- 提到的具体场景 → 生活状态（带娃/独居/合租/养宠/健身/通勤）
- 痛点描述的具体程度 → 是否是目标人群（泛泛而谈=路人围观，细节精准=真实用户）

**行为信号**：
- 评论长度 → 投入度（长评论=深度连接，短评论=浅层参与）
- 是否回复其他评论 → 社区参与度（主动互动=想归属这个话题社区）
- 提问 vs 陈述 → 阶段（提问=刚被吸引想了解更多，陈述=已有经验想分享）
- 情绪强度 → 共鸣深度（强烈情绪表达=深层触动）

**输出**：评论者群体画像（2-3 个子群体），每个标注：
- 人群标签（一句话）
- 占评论总量的大致比例
- 核心欲望（模块二的映射结果）
- 内容创作启示（这群人还想看什么/还需要什么）

### 模块四：情感集群分析

不是逐条情感分析，而是找**评论区的情感模式**：

**常见集群模式**：
- **一致共鸣型**：绝大多数评论表达同一种情感（全在感动/全在愤怒/全在羡慕）→ 内容精准击中单一情绪
- **两极分化型**：评论分成两个对立阵营在争论 → 内容踩了争议线（话题本身有张力）
- **情绪递进型**：按时间顺序，早期评论和晚期评论情绪不同（先好奇→后被说服/先质疑→后感动）→ 内容有说服弧线
- **发散型**：评论各说各的，无主导情绪 → 内容触发了广泛但浅层的反应（火但不深）
- **情绪转化型**：评论区从负面情绪开始，但被其他评论/创作者互动扭转到正面 → 社区自愈力强

**输出**：判断评论区属于哪种模式 + 这个模式对内容策略的含义。一致共鸣型最适合复制放大；两极分化型要谨慎评估争议风险。

### 模块五：触发回溯

每类评论（尤其是高赞的）回溯到**内容的哪个元素触发了它**：

回溯方法：拿高赞评论的关键词/情绪，回到 L1 镜头清单和 L2 结构，定位具体画面/文案/音乐片段。

| 评论类型 | 常见触发源 |
|----------|-----------|
| 痛点表达 | 内容里描述困境的片段 / 「你是不是也…」的共情文案 |
| 欲望表达 | 产品展示的高光镜头 / 结果展示的 before-after |
| 社会认同 | 内容里的普遍性描述（「每个打工人都…」） |
| 身份信号 | 内容里出现地域/群体标签 / 方言 / 文化符号 |
| 个人故事 | 内容里的故事触发了观众自己的记忆（锚点效应） |
| 情绪宣泄 | 高情绪密度的画面+音乐组合 / 反转/punchline |
| 提问求解 | 内容展示了结果但没讲过程 / 提到了但不解释的东西 |
| 异议争论 | 内容里的观点/数据/对比触及了某群体的利益或信念 |
| 幽默玩梗 | 内容里的金句/槽点/可二创的元素 |

**输出**：高赞评论触发源表（评论内容摘要 → 触发源定位 → 心理机制）。这张表直接指导 L4 放大：触发源强的地方要保留或加强，触发源弱但评论多的地方是意外发现（可能藏着金矿）。

## 交叉验证（和 L3 心理挖掘）

跑完五个模块后，把结论和 L3 的推断做交叉验证：

| 维度 | L3 推断 | L3.5 评论证据 | 一致性 |
|------|---------|-------------|--------|
| 核心痛点 | （L3 结论） | 评论痛点表达集中指向？ | ✅/⚠️/❌ |
| 核心欲望 | （L3 结论） | 高赞评论欲望映射指向？ | ✅/⚠️/❌ |
| 目标人群 | （L3 结论） | 评论者画像匹配？ | ✅/⚠️/❌ |
| 情绪弧线 | （L3 结论） | 评论情感集群印证？ | ✅/⚠️/❌ |

- 全 ✅ → L3 推断可靠，可放心进 L4 放大
- 有 ⚠️ → L3 方向对但精准度不够，用 L3.5 修正后再进 L4
- 有 ❌ → L3 推断偏差大，以 L3.5 评论证据为准重写心理假设

**触发回溯精度等级定义：**
- **帧级**：能指出具体画面帧/时间戳触发评论（需要画面素材）
- **场景级**：能指出具体场景/段落触发评论（需要画面或详细描述）
- **语义场级**：只能指出歌词/标题/整体氛围触发评论（纯文本模式）

**纯文本模式降级规则**：当只有评论文本时，欲望识别正常输出，但触发回溯标注为"语义场级"，人群画像标注为"纯语言信号"。

## 纪律

1. **评论是不完全样本**。评论区的人 ≠ 所有观众。主动评论的人比沉默观众投入度更高、情绪更强。结论适用于「高投入观众」而非「所有观众」
2. **警惕水军和控评**。高赞评论如果风格高度一致、发布时间集中、账号特征相似 → 标注「疑似控评，结论降权」
3. **区分情绪和观点**。「哈哈哈」是情绪不是观点，「我觉得这不对」是观点。情绪型评论反映感染力，观点型评论反映说服力。两者对内容策略含义不同
4. **争议是双刃剑**。两极分化的评论区意味着话题有张力（可放大），但也意味着踩了某条线（有风险）。必须标注风险等级
5. **评论数据有时效性**。内容发布初期的评论和长期的评论模式可能不同。标注抓取时间距发布多久
