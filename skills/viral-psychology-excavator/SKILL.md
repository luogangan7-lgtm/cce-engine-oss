# L3 · 心理挖掘（最深一层）

拆一条内容的「魂」：它到底戳了人的什么。不是产品功能，不是视觉技巧，是观众心里那个被触动的东西。

这是整个 skill 组合的核心。用户原话：「最深层次的痛点、欲望、想要的点、想看什么、人群特点」——这五个维度就是本 skill 的五个输出模块。

## 前提

L3 建立在 L1（视觉）和 L2（结构）之上。心理分析不是空想，是从具体的画面、语言、结构里提取出来的。先确认 L1/L2 的结论再开始。

## 五个挖掘模块

### 模块一：痛点地图

把内容戳的痛点分四个层级（从浅到深）：

**层级 1 · 功能性痛点**
产品/服务解决的具体问题。例：助听器解决「听不清」。
这是表层，绝大多数内容停在这里。爆款通常会往下挖。

**层级 2 · 情感痛点**
功能问题带来的情绪。例：听不清 → 社交尴尬 → 怕被当老了 → 不敢参加聚会 → 孤独。
问自己：这个功能问题如果不解决，观众会有什么感觉？焦虑？尴尬？恐惧？愤怒？无力？

**层级 3 · 身份痛点**
和「我是谁」相关。例：需要助听器 = 承认自己老了 = 不愿意面对衰老 = 身份危机。
问自己：使用这个产品/关注这个话题，会让观众怎么看自己？会动摇他们的什么自我形象？

**层级 4 · 存在痛点**
和「意义感/归属感/被看见」相关。例：世界听力日的「deafness is something to celebrate」——
把「缺陷」重新定义为「身份骄傲」，戳的是存在级别的「我值不值得被接纳」。
问自己：这条内容在回答观众什么存在级别的问题？被爱？被理解？被尊重？有意义？

**输出要求**：
- 判断内容主要戳了哪个层级（可能跨层级）
- 最深戳到哪一层 = 这条内容的心理深度上限
- 越深的痛点，感染力越强，但触达人群越窄（深层痛点需要观众有对应的生命体验）

### 模块二：欲望解码

观众看完后想要的，不是产品，是产品背后的欲望。

**内容确定性等级**（校准改进 2026-07-21：情感模糊内容的欲望识别稳定性下降，需先自评）

做欲望解码前，先判断内容的「心理确定性」——即内容传达的心理信号有多明确：
- **高确定性**（叙事明确/IP鲜明/有明确冲突）：欲望识别稳定，可直接给出排序
- **中确定性**（有叙事但情感多元/可多重解读）：欲望排序可能有1-2位波动，标注「次欲望区间」
- **低确定性**（纯氛围/纯音乐/无明确叙事/情感模糊）：主欲望可能不稳定，必须给出2-3个候选并标注概率
  - 此时应优先依赖 L3.5 评论区证据来锚定主欲望（观众自己说的比推断更可靠）
  - 如果评论区也模糊，输出「欲望光谱」而非单一排序

**确定性自评拆分（part4 校准回流 2026-07-22）**：确定性自评必须拆成两个**独立**评分——
- **视觉/内容确定性**：素材本身传达的信号有多明确（画面/文案/结构是否清晰可读）
- **欲望推断确定性**：从信号到欲望结论这一步推理有多可靠
两者取**低者**定档；低者 ≤ 中时触发上面的「候选欲望+概率」模式，且欲望**排序**同样降级——输出「排序区间」而非固定排序。禁止只给一个笼统的整体确定性（part4 实测：同一条内容 3 次运行整体自评给出 低/中低/中 各一次，开关本身在漂）。

**最小信号量防过拟合（part5 校准回流 2026-07-22：过拟合不发生在证据字段，发生在画像/洞察字段）**

低信息量输入（单句/单图/少量评论/无上下文）时，防止用模板尾巴和无证断言填满输出：

1. **候选数量**：允许只给 2 个候选欲望，禁止为凑满 3 个而填充；概率 <0.2 的候选必须标「噪声位，不作为结论」。
2. **证据硬约束**：每个候选欲望的 evidence 必须是输入文本的**逐字子串**（禁止改写/意译），找不到逐字证据就删掉该候选。
3. **证据纪律扩展到所有自由文本字段**（人群画像 / audience_guess / key_insight / 洞察类字段）：
   - 禁止无词证的属性断言（年龄/性别/地域/平台习惯/身份锁定）；禁止虚构引语、句外专名、句外具体数字。
   - 每个断言标注**证据约束等级**：① **逐字引用**（输入原文子串）② **合理推断**（有输入词证支撑的一步推理，须写明依据词）③ **无证猜测**——第三种**禁止输出**，统一降级为「低置信候选」或直接删除。
4. **排序纪律**：前两位候选概率差 <0.1 时输出**无序对**（如「归属+确认」），不硬排第一位。
5. **模板噪声剔除（单句/标题模态）**：固定第三槽出现率异常的候选——某欲望跨样本反复出现在低概率位（≤0.25）且无独立逐字词证——视为模板噪声直接剔除（part5 实测：摆脱欲在 4/4 单句中固定占第三槽，纯属填充）。

欲望 9 类名称速查：**拥有欲 · 成为欲 · 摆脱欲 · 确认欲 · 超越欲 · 归属欲 · 控制欲 · 安全感欲 · 向往欲（投射欲）**（安全感欲在人格特质视角亦称「被爱欲」，见权威源的双视角说明；归属欲必须标机制子型，生活方式/家居/氛围/美学类内容优先检验向往欲——判据见权威源）

完整定义、人性根源与双视角说明的**唯一权威源**：`references/desire-taxonomy.md`。任何层需要欲望 9 类定义时一律引用该文件，禁止再复制粘贴定义。

**自我指涉强度**（真实数据校准发现 2026-07-21：身份声明式共振的结构特征）

评估内容能让观众通过互动（点赞/评论/转发）完成一次关于自己的低成本身份声明：
- **高自我指涉**：点赞 = 「我接受不完美的自己」/「我承认我也想藏」/「我懂这个圈层」——观众不是在消费内容，是在借内容表态
- **中自我指涉**：内容有部分镜像功能，但主要还是信息/娱乐消费
- **低自我指涉**：纯工具型内容（教程/测评），观众消费的是信息本身

**为什么重要（诚实纪律，勿越界）**：6条真实爆款校准发现，高赞内容（>8万赞）的欲望全部高度自我指涉——观众通过点赞完成零成本、零道德负担的身份宣告。它解释的是「谁会共振、共振有多深」的**结构机制**（受众级共振读出已被外部真值验证 ρ≈0.5，两轮预注册），**不是单帖爆款的事前预测指标**——单帖是否爆受算法分发+粉丝基数+运气支配，已三重实锤不可事前预测。自我指涉高 = 共振结构更强 = 放大方向的信号，**不是「这条会爆」的保证**。

**互动成本维度**（真实数据校准发现 2026-07-21）

不同互动行为有不同的心理成本（点赞最低，转发最高），决定数据走哪个指标。高赞≠高转发≠高收藏。互动按钮/行为→欲望的完整映射以 `viral-behavior-signals/SKILL.md`「核心概念：推荐算法在做什么」的功能-欲望表为唯一权威源，此处不重复。分析时必须标注：这条内容的欲望最适合驱动哪种互动？

**强制步骤（part4 校准回流 2026-07-22）**：有真实互动数据时，预判互动结构前必须先**逐项抄录**点赞/评论/转发/收藏四项数字并写出实际排序；预判结论与实际排序不符时，必须显式写出矛盾并修正结论——禁止凭「氛围内容=收藏型」等内容类型刻板印象直接下结论（part4 实测：3 次运行中 2 次对 74.7 万分享视而不见，按刻板印象判「收藏型」）。

**建设性欲望追问**（真实数据校准发现 2026-07-21）

中国短视频爆款的欲望底色是补偿性的（缺什么补什么），不是建构性的（有什么要展示）。拆解时必须追问：
- 这条内容的主驱动力是补偿性的（孤独→陪伴/焦虑→掌控/不安→安全）还是建构性的（成就→展示/美好→分享）？
- 如果是补偿性的：观众缺的是什么？内容补的是什么？
- 如果建构性欲望缺席：为什么？是内容类型决定的还是赛道生态决定的？

**标注判据（part4 校准回流 2026-07-22）**：建构性/补偿性标注**必须有评论区证据支撑**——评论区第一人称缺口表达（「想要」「羡慕」「我也想」）＝补偿性证据；晒单/展示/成就表达＝建构性证据。**无评论数据时标「不可判」**，禁止凭内容氛围猜（part4 实测：无判据时该标签在 3 次运行间随机翻转，接近抛硬币，不应进入下游结论）。

**同类对比防呆条款**（校准回流：编排器已知「同类共享欲望灵敏度不足」缺陷）

同类/同赛道内容对比拆解时，**禁止直接套用同一主欲望模板**。若两条同类内容拆出完全相同的欲望排序，必须二选一：
- 给出两者的差异化欲望权重（同名欲望但权重/修饰语/满足方式不同），或
- 显式论证为什么两者的欲望结构真的相同（并对照 L4 差异化维度说明差异到底落在哪一层）

**输出要求**：
- 主欲望：观众最强烈的那一个（带修饰语，如「想象性陪伴」而非「归属感」）
- 次欲望：被同时激发的
- 欲望满足方式：内容如何给了观众一个「欲望预览」（让他们感觉自己已经接近了那个欲望）
- 自我指涉强度：高/中/低（+一句话说明观众通过互动完成了什么身份声明）
- 互动成本预判：这条内容的欲望最适合驱动哪种互动（点赞/评论/转发/收藏）
- 建设性 vs 补偿性：主驱动力属于哪类？为什么？
- 自我证伪条件：在什么情况下以上假设会崩塌？（如「如果观众主要行为是收藏而非点赞，则镜像认同假设不成立」）


### 模块 2.5：内容胃口（想看什么 / 想要什么）

欲望回答「他们为什么被吸引」，内容胃口回答「他们具体想看到/得到什么形式的东西」。这是从心理层到生产层的翻译——知道了胃口，你就知道下一条该做什么形态的内容。

三个子维度：

**想看什么（内容形态胃口）**
这类人群偏好的内容形式和题材。不是抽象品类，是具体的画面/叙事类型：
- 他们刷到什么会停下：教程演示 / 开箱测评 / 剧情故事 / 知识科普 / 情感共鸣 / 过程解压(ASMR/制造) / 对比反差 / 榜单推荐
- 他们划走什么：说教 / 硬广 / 与自己无关的炫耀 / 信息密度过高看不懂 / 节奏太慢
- 他们会主动搜什么关键词（反映主动需求，比被动刷更精准）
- 他们收藏vs点赞vs转发的区别（收藏=实用刚需，点赞=认同，转发=社交货币）

**想要什么（获得感胃口）**
看完后他们想带走什么。不是产品，是内容给的价值颗粒：
- 实用价值：方法论/清单/教程/避坑指南/对比表（会收藏）
- 情绪价值：被理解/被治愈/被激励/被逗笑/被震撼（会点赞）
- 社交价值：能转给朋友/能发朋友圈/能炫耀品味（会转发）
- 身份价值：看完觉得自己属于某个群体/成为了更好的人（会关注）

**信息深度胃口**
他们愿意投入多少认知成本：
- 秒懂型：3秒内必须有刺激，不要思考（泛娱乐/情绪类）
- 轻思考型：愿意看30-60秒，接受简单逻辑（种草/测评/生活技巧）
- 深度型：愿意看完2-5分钟甚至追更（知识/剧情/专业领域）
- 判断这条内容匹配的是哪个深度，以及这个深度是不是人群的甜区

**输出要求**：
- 内容形态偏好：停下的类型 + 划走的类型
- 获得感主诉求：实用/情绪/社交/身份 哪个为主
- 信息深度甜区：秒懂/轻思考/深度
- 一句话翻译：「这个人群想看 [形态] 的内容，想要 [获得感]，愿意投入 [深度] 的注意力」——这句话直接指导你下一条做什么

### 模块三：人群画像

谁会被这条内容击中。不是泛泛的「25-35岁女性」，是心理特征画像。

画像维度：
- **人口统计**：年龄段/性别/地域/收入/教育/职业（能判断的才写，推测的标「推测」）
- **心理特征**：价值观/生活态度/消费习惯/内容偏好
- **生命阶段**：他们处于什么人生节点（刚毕业/刚结婚/刚当父母/中年危机/退休）
- **核心焦虑**：这个人群最焦虑的一两件事是什么
- **内容消费习惯**：他们在什么场景下刷到这类内容（通勤/睡前/带娃间隙/工作中摸鱼）
- **决策模式**：理性对比型 / 冲动型 / 从众型 / 权威追随型

**输出要求**：
- 一段话的核心画像（不是清单，是一个立体的人）
- 这个人群的心理标签词（3-5 个）
- 为什么是这群人而不是别人（排除逻辑：为什么其他人群不会被击中）

### 模块四：触发器矩阵

分析内容用了哪些认知触发器（来自心理学和行为经济学）。读 `references/trigger-library.md` 获取完整触发器分类。

核心触发器速查：

- **好奇心缺口**：制造信息不对称，必须看下去才能补上
- **模式打断**：打破观众的预期模式，强制注意力重新聚焦
- **社会认同**：展示别人也在用/也在做/也认可
- **权威**：借专家/机构/制服/数据建立信任
- **稀缺**：限时/限量/即将消失
- **损失厌恶**：不行动会失去什么（比获得什么更驱动）
- **情绪传染**：情绪在人群中传播，看到别人激动自己也激动
- **替代性体验**：通过看别人体验，自己获得近似满足（vicarious）
- **互惠**：先给予价值，触发回报欲
- **一致性**：触发观众对自己既有承诺/身份的维护
- **喜好**：让出镜者被喜欢（魅力/相似性/赞美）
- **故事运输**：用叙事把观众「transported」进故事世界

**输出要求**：
- 用了哪 2-4 个主触发器（通常不只一个）
- 每个触发器的具体表现（在内容的哪里、怎么用的）
- 触发器之间的协同（比如好奇心缺口 + 损失厌恶 = 「不看就亏了」）

### 模块五：情绪弧线与成交驱动力

#### 情绪弧线

观众情绪从头到尾怎么走的。画出弧线：

```
情绪
高 │            ╱╲
   │     ╱╲   ╱  ╲      ╱
   │    ╱  ╲ ╱    ╲    ╱
   │   ╱    ╳      ╲  ╱
低 │__╱_____________╲╱____
   0s    5s   10s   15s   20s
   好奇  紧张  释放  满足  行动
```

标注：
- 起点情绪（观众带着什么情绪进入）
- 情绪峰值（最高点在第几秒，是什么情绪）
- 情绪谷底（如果有，是什么情绪）
- 终点情绪（看完后的情绪状态）
- 情绪落差（峰谷差越大，记忆越深）

#### 成交驱动力

如果这条内容带货/引流/转化，驱动成交的终极心理是什么：

- **痛点驱动**：太痛了，必须解决（恐惧/焦虑转化）
- **欲望驱动**：太想要了，必须拥有（向往转化）
- **信任驱动**：太相信了，愿意跟随（权威/社会认同转化）
- **紧迫驱动**：再不行动就晚了（稀缺/损失厌恶转化）
- **身份驱动**：买了/做了 = 成为我想要成为的人（身份认同转化）
- **社交驱动**：别人都有了我也要有（从众/社交货币转化）

**输出要求**：
- 判断主成交驱动力
- 从看到成交的心理路径（观众从看到内容到掏钱，心里经过了哪几步）
- 转化漏斗的薄弱环节（哪个心理步骤没建立好会导致流失）

## 模块六：表现-心理映射（Performance → Psychology Bridge）

如果跑过 L1.5（表现层审计），把表现层发现翻译成心理影响。这是「为什么这种表演方式能击中观众」的解释层。

### 肢体语言 → 心理信号

| 表现 | 观众接收到的心理信号 | 在内容里的作用 |
|------|---------------------|----------------|
| 开放姿势（挺胸展开） | 自信、可信、权威 | 建立信任，适合专家/测评 |
| 高频直视镜头 | 亲密、被关注、一对一 | 拉近距离，适合口播/钩子 |
| 真诚微表情 | 「这个人没在演」 | 信任 = 转化的前提 |
| 大幅手势 | 能量、激情、投入 | 情绪传染，适合种草/激情向 |
| 身体前倾向镜头 | 积极、想靠近你 | 建立亲密，适合钩子段 |
| 杜登式真笑 | 真快乐、可共情 | 感染力，适合生活/情感向 |

反向：
| 表现 | 观众接收到的心理信号 | 风险 |
|------|---------------------|------|
| 封闭姿势（抱臂侧身） | 防御、不确定 | 降低信任（除非刻意酷感） |
| 眼神闪躲 | 不可信、紧张 | 破坏信任 |
| 假笑（嘴动眼不动） | 客套、表演感 | 距离感，降低代入 |
| 念稿感（节奏机械） | 「在背词不是在说话」 | 距离感，降低真诚度 |
| 五通道不一致 | 「哪里不对劲」 | 出戏，潜意识抗拒 |

### 声音表达 → 心理信号

| 声音特征 | 观众接收到的心理信号 | 适用 |
|----------|---------------------|------|
| 暖声（中频、柔和） | 亲和、可信、朋友感 | 生活/陪伴/种草 |
| 冷声（低频、稳） | 权威、专业、高端 | 专家/测评/高端 |
| 声音有情绪起伏 | 有感染力、「真的在意」 | 情感/故事向 |
| 自然的停顿和自我修正 | 真实、没在念稿 | 所有需要信任的内容 |
| 关键处减速+重音 | 「这句话很重要」 | 强调核心信息/痛点 |
| 留白后说结论 | 让结论更重 | 钩子/payoff |

### 真诚度 → 转化力的心理链

表现层的真诚度直接决定 L3 成交驱动力的强度：

```
真诚表现（五通道一致 + 自然说话 + 真情绪）
    ↓
观众感觉「这个人没在骗我」
    ↓
信任建立（权威/喜好触发器被激活）
    ↓
防御降低，接受度提高
    ↓
成交驱动力生效（痛点/欲望/紧迫才能驱动已建立信任的观众）
```

**反向**：如果表现层不真诚（念稿/假笑/五通道不一致），即使 L3 分析的痛点/欲望再准，观众潜意识抗拒，转化率打折。

### 情绪传染的心理机制

出镜者的情绪通过**镜像神经元**传染给观众：
- 出镜者真激动 → 观众生理上跟着激动
- 出镜者真感动（声音颤/眼眶湿）→ 观众跟着鼻酸
- 出镜者克制冷静 → 观众也冷静（高级感/专业感）

这就是为什么「真情绪」比「演情绪」感染力强——镜像神经元识别真假。

## 深挖技巧

当你觉得分析停在了表层，用这些问题把自己往下逼：

1. **「为什么」连环问**：观众想要X → 为什么想要X → 因为Y → 为什么Y重要 → 因为Z → 直到碰到身份或存在层级
2. **反向假设**：如果这条内容去掉XX元素，观众还会被击中吗？去掉的就是命脉
3. **替身思考**：如果你是目标观众，在一个具体的场景里（比如晚上11点缩在被窝里刷手机）刷到这条，你心里会闪过什么念头
4. **评论区挖掘**：如果有评论区数据，观众的评论是他们真实情绪的最直接证据。高赞评论 = 共鸣点，差评 = 触发抗拒的点
5. **空白对照**：同类内容里没火的那些，缺了这条的什么心理元素

## 纪律

- 心理分析必须有证据（画面/文案/结构/评论），不能空想
- 痛点要分清层级，不要停在功能层
- 人群画像是心理画像不是人口统计罗列
- 如果内容确实只戳了表层痛点，如实说，不要硬拔高
- 触发器要具体到「在哪里怎么用的」，不能只说「用了好奇心」
