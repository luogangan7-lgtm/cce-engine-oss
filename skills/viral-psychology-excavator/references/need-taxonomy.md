# 需求 17 类分类学（Need Taxonomy）——唯一权威源

> 本文件是 viral 引擎 v4 因果链「需求层」受控词表的**唯一权威源**，与 `desire-taxonomy.md`（欲望 9 类）平级。
> 机器可读版：`viral-skill-eval/config/need_taxonomy.json`（引擎/校验脚本读它，本文件是人读版，两者必须同步）。
> 引用路径：`viral-psychology-excavator/references/need-taxonomy.md`
> 版本注：2026-07-22 建立。目的——把因果链四层里唯一还没量化的需求层，从「自由文本无法量化」变成「可算跨模型 JS 散度、可做占比分布」，对标欲望 9 类 / 情绪 13 类的定长受控做法。

## 需求层在因果链里的位置

```
欲望(稳定潜变量) →(情境事件) 需求(情境化目标) →(评价 appraisal) 情绪 → 行动倾向 → 行为/话语(可观测)
```

需求是**欲望与情绪之间的中间层**。关键结构：**1 欲望 × N 情境 = N 需求**——同一稳定欲望经不同情境事件投影出不同需求。引擎做逆问题：从可观测话语反推需求层占比。

## 框架与原则（JTBD/ODI + Max-Neef）

- **JTBD/ODI 为主**：需求 = 情境化的「要达成的结果/任务」（outcome），单元是**「结果是什么」不是「怎么做」**——记录 outcome，不记录具体产品/手段。
- **need ≠ want**：缺失会导致功能失调的「要达成的结果」才是 need；单纯想要不是。
- **Max-Neef 九项矩阵为骨架**：生存/保护/情感/理解/参与/闲暇/创造/认同/自由——保证受控类目不漏基本需求维度（覆盖校验见末尾）。
- **ODI outcome statement 四要素**：方向(最小化/最大化/更快/更可靠) + 度量(时间/概率/程度/确定性) + 对象 + 情境。每类的 `jtbd_outcome_template` 按此写。

## 用法：受控类型 + 情境槽（核心机制）

标注一条内容的需求 = **受控需求类型（code，17 类，用于算分布）+ 情境槽 context_slot（半自由文本，记录触发情境）**。

- **受控部分**保证可量化：把 17 类 code 当定长键，像欲望 9 类那样算占比分布、跨模型 JS 散度（未出现类目权重=0）。
- **情境槽**保留 JTBD 情境化精神、承载内容特异性：如 `N02_掌控局面 × 情境「面对不确定的未来」`。
- **裸的需求类型标签视为未完成**，必须带情境槽（与 desire-taxonomy「裸标签视为未完成」纪律一致）。
- 同一内容各 need 实例的 weight 之和 = 1。

| **N08_提升形象** | 提升外在形象 / 被看见 | 让自己看起来更好、被更多人正向注视 | 认同 | 在[对外在呈现不满/想被看见]下，最大化外貌/风格带来的正向关注 |
| **N09_获得地位** | 获得地位 / 胜过他人 | 在某维度排到前面、被公认更强（相对排名） | 认同·参与 | 在[某维度与他人比较]下，最大化自己相对他人的排名/优越度 |
| **N10_自我确认** | 确认自我 / 被认同 | 确认我的选择/观点/身份是对的（自我价值确证） | 认同·情感 | 在[对自己有疑虑/想被肯定]下，最大化对「我的选择是对的」的确认度 |
| **N11_归属群体** | 归属群体 / 找到同类 | 找到同类、确认我是这群人一员（群体成员资格） | 参与·认同 | 在[想确认属于某群体]下，最大化对「我属于这群人」的归属确认感 |
| **N12_情感联结** | 建立/维系情感联结 | 和某人/某群人建立或维系有温度的联系（主动） | 情感 | 在[想加深与某人关系]下，最大化与该对象情感联结的深度与稳定度 |
| **N13_情感慰藉** | 获得情感慰藉 / 被接纳 | 被无条件接纳、被安慰、感到不孤单（被动接住） | 情感·保护 | 在[情感受伤/疲惫/自我怀疑]下，最大化被理解被接纳的慰藉感 |
| **N14_代入理想** | 代入理想生活 / 沉浸美好图景 | 想象性进入并停留在未拥有的理想图景，获替代满足 | 自由·闲暇 | 在[凝视理想生活图景]下，最大化想象性代入停留其中的沉浸/替代满足感 |
| **N15_放松休憩** | 放松解压 / 获得休憩 | 松下来、喘口气、恢复精力（紧张→松弛） | 闲暇 | 在[长期紧绷/疲惫]下，最大化身心的放松/恢复程度，暂时抽离压力 |
| **N16_表达创造** | 表达自我 / 创造产出 | 把内在的东西表达/创造出来，留下我的印记 | 创造·自由 | 在[有想法想外化]下，最大化把内在想法转化为可见产出的表达充分度 |
| **N17_追忆连接** | 追忆过去 / 连接来路 | 重新连上过去的自己/旧时光（时间性归属） | 认同·情感 | 在[被唤起旧记忆的线索触动]下，最大化与过去的连接与连续感 |

### 关键划界（易撞车处）

- **N07 占有资源 vs N14 代入理想**：N07 指向**可购买的具体物**（「求链接」）；N14 指向**不可直接购买的整体图景/状态**（「想住进去」）。与 desire-taxonomy 的拥有欲/向往欲划界严格对应。
- **N11 归属群体 vs N14 代入理想**：N11 = 「我属于这群人」（需群体存在）；N14 = 「我想进入那个画面」（不需任何群体）。承接欲望层归属欲/向往欲的划界。
- **N12 情感联结 vs N13 情感慰藉**：N12 主动建立/维系具体关系；N13 被动被接住、被安慰。
- **N02 掌控局面 vs N03 提升能力**：N02 是对**局面的支配权**；N03 是对**自身技能的掌握**。
- **N06 摆脱痛苦 vs N15 放松休憩**：N06 去除**特定负源**；N15 从**普遍紧绷态**回到松弛。

## 层间连接映射表（因果链量化的核心）

### 上连欲望层：欲望 × 情境 → 需求

同一欲望经不同情境投影出不同需求。给定内容主欲望 + 情境线索 → 可预测最可能激活的需求类型。

| 上游欲望 | 情境事件 | 主需求 | 备选需求 |
|----------|----------|--------|----------|
| 拥有欲 | 刷到能解决痛点/别人都在用的具体产品 | N07_占有资源 | N05, N08 |
| 成为欲 | 看到理想中的那种人/榜样示范 | N03_提升能力 | N08, N16 |
| 摆脱欲 | 正被某痛苦/低效/高压折磨 | N06_摆脱痛苦 | N05, N15 |
| 确认欲 | 内容替我说出心里话/印证我的选择 | N10_自我确认 | N04, N11 |
| 超越欲 | 社会比较——看到别人做到了不甘落后 | N09_获得地位 | N03, N08 |
| 归属欲 | 内容刻画一群人共同特征，对号入座 | N11_归属群体 | N12, N17 |
| 控制欲 | 生活某一面显得失控/一团乱 | N02_掌控局面 | N01, N05 |
| 安全感欲 | 察觉某风险/隐患可能落到自己身上 | N01_确定性 | N02, N06 |
| 安全感欲(被爱面向) | 情感疲惫/受伤时被治愈向内容触动 | N13_情感慰藉 | N12, N15 |
| 向往欲 | 刷到唯美/氛围向的理想生活/空间图景 | N14_代入理想 | N15, N17 |

### 下连情绪层：需求 × goal-congruence → 情绪

同一需求**满足(congruence 正)**与**受阻(congruence 负)**触发不同情绪。与 exp 脚本 `coherence_autocheck`（正 congruence 应配正向情绪 top）对齐。

| 需求 | 满足→情绪(top) | 受阻→情绪 |
|------|---------------|-----------|
| N01_确定性 | relief宽慰 / gratitude / approval | fear恐惧 / sadness |
| N02_掌控局面 | pride自豪 / relief / approval | fear / anger |
| N03_提升能力 | pride自豪 / curiosity / approval | sadness |
| N04_理解世界 | curiosity好奇 / approval / relief | curiosity(悬而未解) / fear |
| N05_优化效率 | relief宽慰 / joy / approval | anger / sadness |
| N06_摆脱痛苦 | relief宽慰 / gratitude / joy | sadness / anger |
| N07_占有资源 | joy喜悦 / desire / gratitude | desire(未满足) / sadness |
| N08_提升形象 | pride自豪 / joy / admiration | sadness |
| N09_获得地位 | pride自豪 / admiration / joy | anger(不甘/嫉妒) / sadness |
| N10_自我确认 | approval认同 / pride / gratitude | sadness / anger |
| N11_归属群体 | love爱 / approval / gratitude | sadness |
| N12_情感联结 | love爱 / gratitude / joy | sadness |
| N13_情感慰藉 | love爱 / relief / gratitude | sadness |
| N14_代入理想 | desire渴望 / admiration / joy | desire(愉悦性持续) / nostalgia |
| N15_放松休憩 | relief宽慰 / joy / love | sadness |
| N16_表达创造 | pride自豪 / joy / admiration | sadness |
| N17_追忆连接 | nostalgia怀旧 / love / gratitude | sadness / nostalgia |

> **向往欲特例（N14）**：coping 低（现实难拥有）**不转为强负向情绪**——现实中难拥有并不打断观看时的满足，「受阻」表现为 desire 渴望持续（愉悦性 longing）而非 sadness。这是与 N07 占有资源受阻(→sadness) 的关键区别，与 desire-taxonomy 向往欲划界一致。

## 3 个完整因果链示例

**① 拥有欲链（IT_ad_goods 带货）**
```
拥有欲 →(情境:刷到戳中痛点的同款,评论都在问链接)
→ N07占有资源[情境槽:看到能解决痛点的同款] outcome:尽快拥有该同款
→(评价: relevance高, congruence正, coping高)
→ desire渴望→想象拥有后joy喜悦 → approach趋近 → 「求链接/哪里买/已下单」
受阻变体: 缺货/买不起(congruence转负)→ desire持续+sadness → 转 attend关注(先收藏蹲)
```

**② 向往欲链（IT_life_kitchen 唯美厨房）**
```
向往欲 →(情境:光线氛围极佳、无叙事的理想厨房图景)
→ N14代入理想[情境槽:凝视理想厨房图景] outcome:想象性进入并停留其中
→(评价: relevance高, congruence正=画面即满足, coping低但不打断满足)
→ desire渴望+admiration钦佩+joy喜悦 → attend关注/approach(收藏追更) → 「想住进去/梦中情厨/收藏了」
关键: coping低不转强负向情绪——向往欲「受阻」= desire持续(愉悦longing)，非sadness；勾起旧日则叠nostalgia
```

**③ 安全感欲链（IT_kn_health 健康科普，满足/受阻分叉）**
```
安全感欲 →(情境:看到健康风险科普,察觉自己可能有隐患)
→ N01确定性[情境槽:意识到潜在隐患想弄清风险] outcome:弄清风险该怎么办、消除不知所措
→(评价: relevance高切身, congruence随是否给解法分正负, coping同理)
→ 满足(有解法): relief宽慰+gratitude → approach趋近(收藏照做) → 「收藏了/赶紧自查」
→ 受阻(只吓人无解法): fear恐惧 → avoidance回避/attend → 「吓得我/太可怕了」
演示: 同一需求N01经goal-congruence正负分叉出相反情绪，对齐exp脚本正congruence配正向情绪top规则
```

## 与其他权威源的关系

- **欲望定义**：`desire-taxonomy.md`（9 类）——本文件的 `upstream_desires` 引用其规范名，禁止复制欲望定义正文。
- **情绪 13 类 / 行动倾向 7 类的定长键**：定义在 `scripts/exp_v4_causal_chain.py` 的 `EMOTIONS` / `ACTIONS` 常量——本文件 `need_emotion_map` 的情绪名与之逐字对齐。
- **本文件只管需求层定义 + 上下连接映射**；引擎集成（把需求层接成定长受控分布、算 JS 散度）由 exp_v4_causal_chain.py 的集成 agent 负责，本文件不改脚本。
