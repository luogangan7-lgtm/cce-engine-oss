# 算法信号映射（Algorithm Signal Map）

各平台推荐算法如何使用行为信号的详细映射。配合 viral-behavior-signals SKILL.md 使用。

> 注：平台算法不公开且持续调整。以下信息来自平台官方博客、开发者文档、从业者的逆向测试（2024-2026 年）。标注【官方】/【业界共识】/【推测】。结论有时效性。

---

## 通用：行为权重排序

所有主流平台的行为信号权重，大致遵循「行为成本越高，权重越大」：

```
关注/收藏 > 转发 > 评论 > 点赞 > 完播 > 曝光未点击
（主动且承诺）  （主动+社交） （主动输出）（主动确认）（被动完成）（最弱）
```

但各平台具体权重不同，且同平台不同内容形态权重也不同。

## 抖音（Douyin）

### 核心权重信号

1. **完播率**【业界共识】—— 抖音最核心的指标。完播率高 = 进入下一级流量池的门槛
2. **互动率**（点赞+评论+转发综合）【业界共识】—— 决定推量上限
3. **复看率**【业界共识】—— 信息密度高/情绪密度高的内容会被反复看，算法加权
4. **关注转化**【业界共识】—— 关注权重高，鼓励创作者做系列
5. **搜索权重**【业界共识 2025-2026】—— 抖音强化搜索，被搜索词带量的内容获得额外推量

### 流量池机制

抖音内容发布后经历多级流量池测试：
- 初始池：200-500 曝光（测试基础数据）
- 二级池：1000-5000（完播率和互动率达标）
- 三级池：1万-10万（互动率持续好）
- 四级池：10万-100万
- 爆款池：100万+

**每级晋升的核心门槛**：完播率 + 互动率（具体阈值动态调整，且不同类目不同）。

### 关键特性

- **标签系统**：抖音给用户和内容打细粒度标签（兴趣标签 200+ 类目）。内容标签主要由前 3 秒+文案+话题标签决定
- **搜索化趋势**【2025-2026 官方博客】：抖音日活搜索量超过 8 亿，搜索权重显著提升。标题/文案/口播的关键词直接影响搜索流量
- **同城推量**：本地内容有地域流量倾斜。带 POI 的内容推给同城用户

### 人群匹配逻辑

抖音的千人千面：基于用户过去 7-30 天的行为构建兴趣画像，推内容时优先匹配标签。但会保留 ~15% 的探索推量（推标签外内容），避免信息茧房。

## TikTok

### 核心权重信号

1. **完播率 + 复看**【业界共识】—— TikTok 算法最看重
2. **For You 推量效率**【业界共识】—— FYP 是主要流量来源
3. **评论**【业界共识】—— TikTok 评论权重高于抖音（可能因为 TikTok 更重社区氛围）
4. **转发/分享**【业界共识】—— 外部分享权重高（TikTok 鼓励破圈）
5. **关注**【业界共识】—— 但 TikTok 关注页流量占比不如抖音高

### 关键特性

- **无明确流量池分级**【业界共识】：TikTok 的推量更连续，不像抖音有明显分级。但同样有「初始测试 → 扩大 → 爆发」的节奏
- **FYP 主导**：For You 页贡献 70%+ 流量。内容标签匹配 FYP 受众是核心
- **声音/音乐驱动**：用热门声音/音乐的内容获得额外推量。音乐标签是重要的内容标签
- **全球分发**：TikTok 内容可能跨语言跨地区推送（算法判断内容是否普适）

### 和抖音的差异

- TikTok 更重完播+评论，抖音更重完播+搜索+话题标签
- TikTok 破圈更容易（全球+音乐驱动），抖音本地化更深
- TikTok 关注页权重低，意味着单条爆款不必然带来粉丝增长

## 小红书（Xiaohongshu / RED）

### 核心权重信号

1. **点击率**【业界共识】—— 封面+标题决定点击，小红书最重点击率（因为信息流是瀑布流，用户主动选择）
2. **互动率**【业界共识】—— 点赞+收藏+评论
3. **收藏率**【业界共识】—— 小红书是「种草」平台，收藏权重尤其高（收藏 = 想买/想用）
4. **搜索 SEO**【业界共识 2025-2026】—— 小红书搜索权重极高，标题/正文的关键词直接影响搜索流量
5. **评论深度**【业界共识】—— 小红书评论权重高，长评论/楼层讨论尤其加权

### 关键特性

- **图文优先**【业界共识】：小红书原生就是图文平台，图文内容权重稳定。视频内容也能起量但不是主战场
- **封面决定一切**：瀑布流里用户看到封面先于一切。封面吸引力 = 点击率 = 一切数据的前提
- **长尾流量**【业界共识】：小红书内容生命周期长于抖音/TikTok。一篇好的图文笔记可以持续获得搜索流量数月甚至数年
- **笔记权重积累**：账号的笔记质量历史影响新笔记的初始推量

### 和其他平台差异

- 小红书重搜索 SEO 和长尾，其他平台重即时爆发
- 小红书重封面和标题，其他平台重前 3 秒
- 小红书重收藏（种草），其他平台重完播和转发

## YouTube（Shorts + 长视频）

### 核心权重信号

**Shorts**：
1. **完播率 + 复看**【业界共识】—— Shorts 算法核心
2. **订阅转化**【业界共识】—— Shorts 的关注转化权重高
3. **Shorts Feed 点击率**

**长视频**：
1. **点击率**（缩略图+标题）【业界共识】—— 长视频最重 CTR
2. **观看时长**【业界共识】—— 绝对观看时长（不是完播率），长视频更看重总时长
3. **满意度信号**【官方】：YouTube 官方说算法优化目标是「观众满意度」，通过调查+行为综合判断

### 关键特性

- **Shorts 和长视频算法不同**【官方】：Shorts 偏完播+推量，长视频偏点击+观看时长
- **频道权重**：YouTube 极重频道历史。新频道冷启动难，老频道新内容初始推量高
- **推荐系统论文**【官方】：YouTube 的推荐算法有公开论文（2016/2022），是候选生成+排序两阶段模型

## Instagram（Reels + Feed）

### 核心权重信号

1. **Reels 完播率**【业界共识】
2. **转发/分享**【业界共识 2024-2026】—— Meta 官方说转发是 Reels 增长的核心信号
3. **评论**【业界共识】—— Instagram 评论权重高于点赞
4. **Story 互动**（贴纸/投票/回复）

### 关键特性

- **转发权重上升**【官方 2024】：Instagram 负责人公开说分享/转发是 2024 年起最重要的信号
- **原图权重回归**【官方 2024-2025】：Instagram 算法重新鼓励原创图片而非视频
- **Reels 推荐 vs 关注页**：Reels 主要靠 Explore/Reels Feed 推荐，关注页权重下降

## B站（Bilibili）

### 核心权重信号

1. **完播率**【业界共识】
2. **一键三连**（点赞+投币+收藏）【业界共识】—— B站特有，三连是最高质量信号
3. **弹幕**【业界共识】—— B站特有，弹幕密度反映内容互动深度
4. **充电**（付费支持）—— 最高质量的单条信号

### 关键特性

- **三连文化**：B站用户有「三连」习惯，三连率是核心质量指标
- **弹幕互动**：弹幕是 B站独有的实时互动形式，弹幕密度高的视频数据稳定
- **长视频为主**：B站用户接受中长视频（5-30 分钟），算法对观看时长权重高
- **社区氛围**：B站用户社区属性强，评论区/弹幕文化重，内容需要尊重社区文化

## 怎么用这张表

### 分析自己的数据时

1. 查你的平台的第一权重信号 → 你的这条内容在那个信号上表现如何
2. 对比行业基准 → 偏弱的信号是什么，内容哪里可以改
3. 看你的内容生命周期符合平台特征吗 → 抖音内容如果数据只活 1 天是正常的，小红书内容如果 3 天就没流量说明 SEO 没做好

### 做新内容时

1. 先决定发哪个平台 → 查那个平台的第一权重
2. 第一权重是完播 → 优化前 3 秒和节奏
3. 第一权重是点击 → 优化封面和标题
4. 第一权重是收藏 → 增强实用性和可回看性
5. 第一权重是转发 → 增强社交货币属性

### 跨平台分发时

同一条内容发不同平台需要改：
- 完播型平台（抖音/TikTok/Shorts）：前 3 秒必须强，节奏紧凑
- 点击型平台（小红书）：封面+标题必须强，内容可以更详细
- 社区型平台（B站）：尊重社区文化，可以更长更深度
