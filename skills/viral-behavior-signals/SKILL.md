# L3.6 · 行为信号（算法和欲望的中间层）

用户的每个动作——多看一秒、点个赞、转发给朋友、收藏起来——都是一个**欲望投票**。平台用这些投票构建用户画像，做千人千面推送。创作者也能用同样的逻辑，从行为数据反推人群欲望。

这一层的核心认知：**行为信号 = 欲望的可观测投影。** 欲望本身不可见，但行为可见。你不需要问观众「你想要什么」，他们的行为已经告诉你了。

## 为什么需要单独一层

L3.5 分析评论（主动文字输出），L3.6 分析所有行为信号（包括沉默的动作）。大多数观众不评论——他们只是看、滑、偶尔点赞。但他们的行为模式同样承载欲望信息，而且因为样本量大（100% 观众 vs 可能 1-5% 评论），统计意义更强。

**L3.5 + L3.6 组合 = 完整的观众行为画像**：深度信号（评论，小样本高信息）+ 广度信号（行为数据，大样本低信息）。

## 前提

- 有创作者后台数据（抖音创作者中心/小红书专业号/TikTok Analytics/YouTube Studio 等）
- 如果分析别人的爆款（无后台数据），只能拿公开数据（播放量/点赞数/评论数/转发数），深度受限
- 建议先跑 L1-L3，用内容分析结论作为行为解读的先验

## 核心概念：推荐算法在做什么

在看具体信号之前，先理解**为什么平台要设计这些功能**。每个交互按钮都不是随意加的，它对应一种用户状态。下表是「平台功能/互动按钮→欲望」映射的**唯一权威源**（L3 等其他层引用本表，不重复粘贴）：

| 平台功能 | 算法用它来推断 | 背后的用户欲望 |
|----------|--------------|---------------|
| **播放/曝光** | 这个人是否对这个 topic/封面/标题感兴趣（首次点击） | 好奇心 / 即时需求 |
| **完播率** | 内容是否满足了这个人的预期（看到底了=没失望） | 预期匹配度 + 沉浸感 |
| **复看/重播** | 内容有值得反复看的元素（信息密度高/情绪密度高） | 深度学习需求 / 情绪反复体验需求 |
| **点赞** | 情感认同（不是理性认同，是「我喜欢」的冲动） | 喜好确认 + 情感共鸣 |
| **评论** | 内容激发了表达欲（有话要说=触动足够深） | 表达欲 + 连接欲 + 影响欲 |
| **转发/分享** | 内容代表了我的观点/品味，想给别人看（社交货币） | 社交身份构建 + 关系维护 + 利他 |
| **收藏** | 内容有未来价值（要回看/要用） | 实用需求 + 囤积安全感 |
| **关注** | 想持续看这个创作者的内容（信任+期待） | 归属感 + 持续价值预期 |
| **划走/跳过** | 内容没满足预期或不相关 | 内容-观众不匹配 |
| **停留时长** | 整体沉浸度（综合信号） | 内容的注意力抓取力 |

**关键洞察**：千人千面推送的本质是——平台为每个用户建了一个**欲望模型**，用户的每个行为都在更新这个模型。创作者如果理解了这些信号对应什么欲望，就能（a）解读自己/别人的数据背后的人群画像，（b）在创作时主动设计触发特定行为的内容。

## 四个分析模块

### 模块一：行为信号解读

逐个信号分析，从数字推断心理。

**完播率**
- 高完播（>50% 短视频 / >30% 中长视频）→ 内容的预期管理成功（开头承诺的，全程兑现了）
- 低完播 → 找流失点。如果后台有「观众流失曲线」，看哪个时间点掉得最多——那个点的内容出了问题（太慢/太复杂/承诺没兑现）
- 完播率是算法最看重的指标之一（尤其抖音/TikTok）因为它直接反映内容质量

**点赞率**（点赞数 / 播放数）
- 高点赞率（>5%）→ 内容触发了强烈的即时情感反应
- 低点赞率但高播放 → 内容被看了但没打动（可能是信息型内容，有用但不煽情）
- 点赞率 vs 完播率对比：完播高+点赞低 = 内容好但情感弱；完播低+点赞高 = 钩子强但后劲不足

**评论率**（评论数 / 播放数）
- 高评论率（>1%）→ 内容激发了表达欲，通常是有争议/有共鸣/有话题
- 评论率远高于点赞率 → 内容引发了讨论而非单纯认同（话题型内容特征）
- 低评论但高赞高完播 → 内容是「享受型」的，看完爽完就走（纯娱乐/纯视觉）

**转发率**（转发数 / 播放数）
- 转发是最强的社交行为信号——观众愿意用自己的社交信用为内容背书
- 高转发率 → 内容是社交货币（有用/有趣/有身份价值，分享出去能让自己显得好）
- 转发率远高于点赞率 → 内容的社交价值 > 情感价值（干货/实用/新闻类特征）
- 什么内容会被转发：「这个必须让XX看」（定向分享）vs「分享给大家」（广播）—— 前者说明内容击中了某个特定关系场景

**收藏率**（收藏数 / 播放数）
- 高收藏率 → 内容有未来使用价值（教程/攻略/清单/参考素材）
- 收藏率高但点赞率低 → 内容是工具型（有用但没情感）
- 收藏率是复购/复看意愿的领先指标

**关注转化率**（新增关注 / 播放数）
- 高关注转化 → 内容建立了信任和期待（观众想持续看）
- 低关注但高单条数据 → 内容本身好但创作者人设没建立（一次性内容）
- 关注转化和内容的「系列感」正相关——观众关注是因为预期还会有同类内容

### 模块二：信号组合 → 内容类型识别

单个信号会骗人，信号组合更可靠。常见组合和它们揭示的内容类型：

| 信号组合 | 内容类型 | 人群欲望 |
|----------|----------|----------|
| 高完播+高赞+低评论+低转发 | 沉浸享受型（视觉奇观/解压/ASMR） | 即时情绪满足 |
| 高完播+高赞+高评论+中转发 | 共鸣感动型（情感故事/价值观） | 情感共鸣+表达欲 |
| 中完播+中赞+高评论+高转发 | 话题争议型（观点/社会议题） | 表达欲+社交身份 |
| 低完播+高赞+低评论+低转发 | 钩子型（强开头弱后劲） | 好奇心满足即走 |
| 中完播+低赞+低评论+高收藏+高转发 | 实用工具型（教程/攻略/清单） | 实用需求+社交利他 |
| 高完播+中赞+中评论+高关注 | 人设建立型（系列/个人IP） | 持续价值预期 |
| 高完播+高赞+高评论+高转发+高收藏 | 现象级爆款（全维度强） | 多欲望同时满足 |

**用途**：用这个表给自己的内容定位——你的数据组合属于哪种类型？如果想在某个维度提升（比如想增加转发），对照看那类内容的特征，反向设计内容。

### 模块三：千人千面推送机制

理解算法如何用行为信号做推荐，才能知道**你的内容会被推给谁**。

**算法的基本逻辑**（简化模型）：

```
用户行为 → 更新用户兴趣标签 → 匹配内容标签 → 推送 → 观察行为 → 循环
```

**关键机制**：
1. **标签系统**：每个内容和每个用户都有一组标签（topic/风格/人群/情绪类型）。用户的标签来自他们看过/赞过/评论过/收藏过的内容
2. **行为权重**：不同行为对标签更新的权重不同。通用排序：完成关注/收藏 > 转发 > 评论 > 点赞 > 完播 > 曝光未点击。越主动的行为权重越高
3. **时间衰减**：近期行为权重高于远期行为（用户的兴趣在变化）
4. **探索 vs 利用**：算法大部分时间推「你认为会喜欢的」（利用已知兴趣），偶尔推「你不常看的」（探索新兴趣，防信息茧房）
5. **冷启动**：新内容会先小范围推给「最可能感兴趣的标签人群」测试数据，数据好再扩大推量

**对创作者的含义**：
- 你的内容的**前几秒决定了会被推给谁**——算法根据开头判断标签，推给对应兴趣人群。开头跑偏 = 推错人 = 数据差
- 被推给「非目标人群」是数据差的最大原因之一（不是内容不好，是推错了人）。标题/封面/开头必须精准信号，让算法判断正确
- 想破圈到新人群 → 内容里需要加入能触发「探索」行为的元素（新奇/反常识/跨领域引用），让算法愿意推给标签外的人
- 系列化内容更容易被算法稳定推量（建立了稳定的标签-人群匹配）

各平台（抖音/小红书/TikTok/YouTube/Instagram/B站/视频号）的算法信号权重详细映射见本 skill 的 `references/algorithm-signal-map.md`（独立使用本 skill 时也要读它）。

### 模块四：行为→人群画像

行为数据是人群画像的客观证据。从行为模式推断人群特征：

**时间分布**（什么时候在看）：
- 深夜高峰 → 失眠人群/夜班/独居/情绪化时段消费
- 通勤时段 → 上班族/学生
- 午休时段 → 职场人群
- 全天均匀 → 退休/自由职业/学生假期

**地域分布**（如果后台有）：
- 集中在某地域 → 内容有地域相关性（方言/本地话题/地域文化）
- 一线城市集中 → 内容偏都市人群口味
- 下沉市场集中 → 内容偏接地气/实用

**设备分布**（如果后台有）：
- 高端设备占比 → 消费力信号
- 低端设备占比 → 价格敏感人群

**行为深度**：
- 完播+点赞+评论+关注的「全勤观众」→ 核心粉丝，画像最清晰
- 只完播不互动 → 沉默观众（占大多数），用完播行为推断兴趣
- 只点赞不看完全 → 标题党受害者，信号弱

## 纪律

1. **区分相关和因果**。高完播可能因为内容好，也可能因为标题骗进来的人刚好不挑剔。数据是相关性的，不要过度归因
2. **样本量要够**。播放量 < 1000 的内容数据波动大，不具备分析价值。至少 5000+ 播放才有统计意义
3. **跨内容对比才有意义**。单条数据是孤证。同一个账号的多条内容对比，或同类爆款对比，才能看出模式
4. **算法在变**。各平台算法权重会调整（比如抖音从完播权重转向搜索权重）。标注分析时间，结论有时效性
5. **数据看板可能不准**。平台数据有延迟/去重/清洗。大趋势可信，精确数字保留怀疑
6. **先抄数再预判**（part4 校准回流 2026-07-22）。解读/预判互动结构前，必须先逐项抄录点赞/评论/转发/收藏四项真实数字并写出实际排序；结论与实际排序不符时必须显式写出矛盾并修正——禁止凭「氛围内容=收藏型」等内容类型刻板印象下结论（part4 实测：3 次运行 2 次忽略最强信号 74.7 万分享）
7. **本层是事后解读，不是事前数值预测（诚实纪律 · 封路条款）**。行为信号解读的是**已经发生**的数据，从数字反推心理——这是引擎已证方向（行为 = 欲望的可观测投影，受众级共振读出已验证 ρ≈0.5）。但**播放量/完播/点赞的绝对数值不可事前预测**：它们受算法分发权重 + 账号粉丝基数支配（脏真值），非内容质量的纯函数（引擎侧已实锤单帖数值不可预测）。因此本层只做**相对/结构/方向**解读（信号组合模式、比值排序、跨内容对比），不承诺「这条会有多少播放」，也不把单条绝对数值当内容优劣的唯一判据。
