# L2 · 结构解码

拆一条内容的「骨架」：它用什么公式把人留住、用什么结构把人带到 payoff。

## 前提

L2 建立在 L1（视觉取证）的镜头清单/图集结构之上。如果没跑过 L1，先口头确认或快速补一遍内容的时间线结构。

**形态分流**：视频走下面的「钩子/叙事弧/时间轴节奏/前3秒还原」主路径；图文（小红书图文笔记）走本文档「图文结构子模式」段（标题公式/首图钩子/正文信息结构/收藏诱因）——钩子分类学和叙事弧复用，时间轴维度替换为阅读结构。

## 拆解维度

### 1. 钩子分类

把前 3 秒（视频）或封面第一眼（图文）套入钩子分类学。读 `references/hook-taxonomy.md` 获取完整的钩子分类库（12 类 + 变体）。

核心钩子类型速查：

| 类型 | 机制 | 典型句式 |
|------|------|----------|
| 反差冲突 | 制造认知矛盾 | "不要XX，要XX" / "你以为XX？错了" |
| 问题好奇 | 激发求知欲 | "你知道为什么XX吗？" / "XX到底怎么做到的？" |
| 结果前置 | 先展示惊人结果 | 直接放成品/效果，再讲过程 |
| 身份锚定 | 让人对号入座 | "如果你是XX，你一定XX" / "XX人才懂的XX" |
| 痛点共鸣 | 直接说出观众的痛 | "你是不是也XX？" / "每次XX都很烦" |
| 利益诱惑 | 承诺具体收益 | "XX天XX效果" / "省下XX钱" |
| 悬念缺口 | 制造信息缺口 | "最后那个太离谱了" / "第3个你绝对没用过" |
| 权威背书 | 借势建立信任 | "XX专家说" / "XX机构验证" / 穿制服出镜 |
| 视觉奇观 | 纯视觉冲击无文字 | 83M 播放电焊机视频 = 纯操作画面 |
| 反常识 | 打破常识引发好奇 | "其实XX根本不需要XX" |
| 情绪共鸣 | 直接击中情感 | 金句开头 / 情感场景 |
| 社交货币 | 让人想转发炫耀 | "99%的人不知道" / "懂这个的都是行家" |

分析时：
- 指出用了哪 1-2 个主钩子（通常不只一个）
- 还原钩子的完整结构（看到什么 + 听到什么 + 读到什么文字，三者是否一致还是制造矛盾）
- 判断钩子强度（强/中/弱，依据是「如果换一个弱钩子这条还火吗」）

### 2. 叙事弧类型

从已有拆解库（TikTok 5 条 + 抖音车载香薰等）归纳出的类型：

**带货/种草类**
- **问题-放大-解决**（最常见）：提出问题 → 放大痛感 → 产品出场解决。Citta 香水、助听器、车载香薰都是这个
- **清单种草**：好物清单式，逐个介绍，每个一个卖点 + 一个场景。乔迁礼物推荐视频
- **对比反差**：之前 vs 之后 / 普通 vs 升级 / 别人 vs 自己
- **过程展示**：纯制作过程/操作演示，靠满足感传播。胡萝卜蜡烛、电焊机

**内容/故事类**
- **故事弧**：有起承转合的叙事，角色有变化。胡萝卜蜡烛的"Your daddy lives by himself"
- **情绪共鸣弧**：没有明确故事，靠情绪递进。世界听力日的心形助听器
- **知识密度弧**：高密度信息输出，每几秒一个知识点。科普/教程类
- **纯视觉奇观**：无叙事，纯靠视觉冲击。电焊机 83M 播放

分析时：
- 指出用了哪个叙事弧（可以是混合型）
- 画出弧线的情绪/张力曲线（起在哪、峰在哪、落在哪）
- 判断 payoff 时机（观众得到满足的时刻在第几秒，是否太晚导致流失）

### 3. 节奏分析

参考爆款方法论（2026-07-10，Paddy Galloway + MrBeast）：

- **每 5 秒一个兴趣点**：检查是否每个 5 秒段都有一个新的视觉/信息/情绪刺激
- **开环（open loop）**：在开头抛出的问题/悬念，什么时候闭合？
  - 开环数量：一条内容通常 1-3 个开环
  - 开环位置：前3秒抛出 vs 中段抛出
  - 闭合时机：太早闭合 = 观众走了；太晚闭合 = 观众等不住走了
- **信息密度曲线**：画出来，标注密度峰值和低谷
- **MrBeast 三指标思维**（用于评估，不是测量）：
  - CTR（点击率）→ 标题和封面决定
  - AVD（平均观看时长）→ 结构和节奏决定
  - AVP（平均观看百分比）→ 完播率，payoff 位置决定

### 4. 前 3 秒完整还原

逐帧还原前 3 秒（视频）或封面第一眼（图文）：

```
0.0-0.5s：看到[画面] + 听到[音频] + 读到[文字]
0.5-1.0s：[同上]
1.0-1.5s：[同上]
1.5-2.0s：[同上]
2.0-2.5s：[同上]
2.5-3.0s：[同上]
```

这个还原是整个拆解里最有操作价值的产出——前3秒决定 60%+ 的完播。

### 5. 结尾与 CTA

- 结尾类型：彩蛋 / 回扣开头 / 纯 CTA / 情绪余韵 / 突然结束
- CTA 强度：强（明确行动指令）/ 中（暗示行动）/ 弱（无 CTA，靠内容自然传播）
- 回扣：结尾是否呼应开头（好的回扣提升完播和复看）

## 图文结构子模式（小红书图文笔记）

图文没有时间轴、没有「前 3 秒」、没有逐帧——留人机制在**静态载体**上：封面第一眼 + 标题决定点击，首图 + 首段决定展开，信息梯度 + 收藏诱因决定收藏。跑图文模式时，用本子模式**替代**上面的「时间轴节奏 / 开环 / AVD/AVP / 前3秒逐帧」维度；钩子分类学（12 类）和叙事弧类型仍**复用**，只是触发窗从「时间流」改成「静态第一眼 + 阅读结构」。

### 1. 标题公式（标题党公式）

标题是图文的第一钩子（和封面并列）。拆解标题用了哪个公式：

- **数字清单**：「XX 个 / XX 步 / XX 天」——承诺可量化收益 + 制造完整性预期
- **身份锚定**：「XX 人必看 / XX 岁的我」——对号入座
- **痛点点名**：「还在 XX？/ 别再 XX 了」——直接戳痛
- **反差反常识**：「原来 XX 根本不用 XX / 我错了这么多年」
- **悬念缺口**：「第 X 个我居然没想到 / 后悔知道晚了」
- **利益前置**：「亲测有效 / 一次搞定 / 省下 XX」
- **情绪 valve**：「破防了 / 谁懂啊 / emo 了」——情绪共鸣型
- **权威/证据**：「三甲医生说 / 实测 30 天」

记录：用了哪 1-2 个公式 + 标题实际字数（小红书甜区 ≤20 字）+ 标题与封面文字是否呼应/互补/冗余。

### 2. 首图钩子（封面第一眼 = 图文的「前3秒」）

封面 + 首图承担视频里「前 3 秒」的全部留人职责。套用钩子分类学（见 `references/hook-taxonomy.md`），但触发窗是**静态第一眼**不是时间流：

- 首图 hook 类型（套 12 类钩子的静态版：反差/悬念/身份/痛点/利益…）
- 承诺-展示差（标题承诺 8 个、封面只展示 4 个 → 制造翻页缺口；L1 已记录差值，L2 判定其钩子强度）
- 首图与标题的钩子分工（封面给视觉冲击 / 标题给信息承诺 / 二者是矛盾制造好奇还是叠加强化）

### 3. 正文信息结构（阅读梯度，替代时间轴节奏）

图文看**阅读结构**不看时间节奏：

- **首段钩子**：正文第一句是不是 hook（决定展开率，等价视频前3秒）
- **信息梯度**：核心信息前置（干货直给）还是后置（故事铺垫）；每段信息密度
- **结构类型**：清单体（逐条并列）/ 故事体（起承转合）/ 教程体（步骤递进）/ 测评体（对比结论）
- **翻页/停留节奏**：图集哪张是翻页钩子（复用 L1 图集节奏）；正文哪段是「读到这里就够了」的满足点
- **开环与闭合**：图文也有开环（标题抛问题、正文中段留悬念），但闭合靠读者自控翻页/下滑，不是时间轴

### 4. 收藏诱因（图文特有的强互动信号）

收藏是图文（尤其小红书）的核心转化——等价于视频的完播 + 转发（收藏型 vs 评论型两极已由引擎证实）。拆解「为什么值得收藏」：

- **囤积型**：清单/攻略/模板/资源（「以后用得上」）
- **执行型**：步骤/教程/配方（「照着做」）
- **身份型**：金句/观点/审美（「这就是我」，收藏 = 自我声明）
- **备查型**：数据/对比/避坑（「决策时回来看」）

判定这条图文的收藏诱因属于哪型 + 收藏诱因埋在封面/标题/正文哪个位置。
（封路：收藏「量」的数值预测 = 脏真值，不可事前预测；此处只做诱因的**结构判定**，不做数值。）

## 纪律

- 钩子分析必须还原完整结构（看到+听到+读到），不能只说「用了好奇钩子」
- 叙事弧要画曲线，不只命名类型
- 前3秒逐帧还原是最有价值的产出，不能省略
- 不要在这里猜心理动机（那是 L3），只分析结构机制
