# L1 · 视觉取证

拆一条内容的「皮」：它长什么样、怎么动的、节奏怎么走的。不猜意图（那是 L3 的事），只记录和判断视觉事实。

## 输入要求

- 视频：本地文件路径 或 平台链接（需先下载，见下方素材获取）
- 图文：截图 / 链接 / 本地图片路径
- 如果用户只给了口头描述没给素材：所有结论标注「推测，无素材验证」

## 拆解维度

### 视频内容

#### 1. 镜头清单（逐镜表格）

对每个镜头记录：

| 镜号 | 时间段 | 时长 | 景别 | 运镜 | 主体 | 画面文字 | 转场方式 |
|------|--------|------|------|------|------|----------|----------|

景别分类：特写 / 近景 / 中景 / 全景 / 远景 / 微距
运镜分类：固定 / 推拉 / 摇移 / 跟拍 / 升降 / 手持 / 第一人称POV / 无人机

#### 2. 视觉工艺判断

判断内容的生产方式。参考 Loop 视觉工艺逆向（2026-07-13）的方法论：

- **实拍**：真人/真场景/真产品。判断依据：自然光影瑕疵、肤色真实度、环境音
- **3D CGI 渲染**：产品 packshot 常见。判断依据：跨 SKU 像素级一致性、理想化表面、次表面散射、悬浮透明底、索引色 PNG
- **手机/UGC 直拍**：竖屏、自然抖动、环境光、非专业构图
- **混合**：实拍人 + 渲染产品 / 实拍背景 + 动效叠加
- **AI 生成**：判断依据——六指数异常、文字渲染错误、不对称细节、过度平滑的皮肤、不合理的反射

判断时说清楚依据，不要只下结论。

#### 3. 节奏曲线

画出整条内容的变化时间轴：

```
0s────5s────10s────15s────20s────25s────30s
  │     │      │      │      │      │
  钩子  切镜   高潮   转折   证明   CTA
  打断  情绪   特写   反差   数据   行动
```

标注：
- 每个镜头切换点
- 每个视觉「变化」（景别跳变/色彩跳变/主体切换/文字出现消失）
- 音效/音乐变化点
- 估算每 5 秒内有几个视觉刺激点（信息密度）

#### 4. 色彩与光影

- 主色调（占画面面积最大的 1-2 个颜色，给色值）
- 配色逻辑（单色铺满+产品点缀 / 互补色对比 / 同色系和谐 / 高饱和冲击）
- 光线类型（自然光 / 影棚柔光 / 硬光 / 混合 / 暗调低调 / 高调过曝）
- 色温倾向（暖/冷/中性）

#### 5. 文字层

- 屏幕文字位置（顶部/中部/底部/全屏覆盖）
- 字体风格（无衬线粗体 / 手写体 / 像素体 / 品牌定制）
- 文字出现时机和停留时长
- 文字与画面的关系（补充说明 / 强调重复 / 矛盾对比 / 纯装饰）

#### 6. 音频层

- 音乐类型和情绪（BGM 是什么风格、什么情绪）
- 节奏：BPM 估算（快/慢/是否有变化）
- 音效：关键音效出现时机和功能（转场音/强调音/环境音/ASMR）
- 人声：语速（快/中/慢）、语调（兴奋/平静/叙述/喊话）、口音/语言
- 音乐与画面的同步点（音画对齐在哪里，对齐 = 强调）

### 图文内容（小红书/Instagram post/公众号/landing page）

> **图文模式定位（图文子模式）**：当拆解对象是图文笔记（编排器判定为「图文模式」）时，**本段就是 L1 的主路径**——图文没有时间轴/镜头/逐帧，视觉取证做的是「封面吸引力 + 配图信息 + 图文排版」，而非逐帧 video forensics。上面的镜头清单/节奏曲线/音频层在图文模式下不适用（跳过并标「图文无此维度」）。配图逐张的具体信息细节属 need 层，只在文本不足或需要视觉证据时按需解析——图片是**补充**，标题/正文文本才是主干（引擎最强通道，见编排器「两条一等路径」节的图文层映射）。

图文内容的视觉拆解比视频更重设计系统。读 `references/image-text-design-system.md` 获取完整设计拆解库（布局/字体/配色/层级/留白/网格/封面模板）。

#### 1. 封面分析（决定 80% 点击率）

参考小红书/Instagram 封面逆向方法论：

- **第一眼读懂度**：1秒/3秒/需要细读。1秒读懂 = 强封面
- **主视觉类型**：人像 / 产品 / 场景 / 纯文字 / 数据图 / 对比图 / 拼贴
- **文字 hook**：完整记录封面文字（这是钩子，不是装饰）
- **字数压缩度**：小红书封面理想 8-15 字，公众号头图可稍多
- **信息密度**：留白型（高级/文艺）vs 信息满（干货/清单）
- **承诺-展示差**（part4 校准固化 2026-07-22）：标题/文案承诺的数量 vs 封面（或图集）实际展示的数量之差（如标题承诺「8个」封面只展示 4 个）——差值本身是结构性翻页/停留钩子（「剩余 4 个我得滑进去看」的预期缺口），必须显式记录差值与其钩子效果

#### 2. 排版与视觉层级（Typography & Hierarchy）

- **视觉层级**：主视觉 > 次元素 > 文字，层级清不清晰决定 1 秒能不能抓到重点
- **字体选择**：
  - 无衬线粗体（思源黑/苹方粗）：现代、冲击、年轻
  - 衬线体（宋体/思源宋）：文艺、高级、杂志感
  - 手写体：亲切、个人、温度
  - 像素/复古体：复古、个性
- **字号对比**：标题与正文的字号比（大对比 = 强冲击，小对比 = 高级克制）
- **字重对比**：粗细搭配制造层级（全粗 = 平，全细 = 弱，粗细搭配 = 有呼吸）
- **行距与字距**：行距 1.2-1.5 倍舒适；标题紧凑（负字距）显冲击，正文松散显高级

#### 3. 布局与网格（Layout & Grid）

- **构图类型**：
  - 居中对称：稳定、正式、高级
  - 三分法：自然、平衡、专业
  - 对角线：动感、引导视线
  - 满版铺图：冲击、沉浸
  - 留白主导：文艺、高级、呼吸感
  - 网格拼贴：信息密、清单感
- **留白（Negative Space）**：留白多 = 高级/文艺；留白少 = 信息满/接地气。留白是设计语言不是空
- **对齐方式**：左对齐（自然阅读）/ 居中（正式/冲击）/ 右对齐（文艺/反常规）/ 混乱对齐（不专业除非刻意）
- **元素间距**：间距统一 = 专业；间距混乱 = 业余。间距是设计的隐形骨架

#### 4. 配色系统（Color System）

- **主色调**：占画面 60%+ 的颜色（给色值或色名）
- **配色逻辑**：
  - 单色系：高级、统一、克制
  - 互补色（橙蓝/红绿）：冲击、对比、抓眼
  - 类似色（同色系深浅）：和谐、温柔、高级
  - 高饱和撞色：年轻、活力、潮流
  - 莫兰迪/低饱和：文艺、质感、高级
- **文字与背景对比度**：高对比（白底黑字）= 清晰可读；低对比（灰字浅底）= 高级但费眼
- **品牌色运用**：是否用了品牌主色（辨识度）

#### 5. 图集结构与滑动节奏（Carousel Structure）

- **总张数**：小红书 3-9 张甜区；Instagram 可更多
- **每张图功能**：封面钩子 / 产品展示 / 使用场景 / 证据 / 对比 / 教程步骤 / 结尾CTA
- **图间叙事逻辑**：递进 / 并列 / 对比 / 时间线 / 步骤
- **翻页钩子**：哪张图是「翻页钩子」（让人想看下一张）。常见手法：
  - 封面写「第3张绝了」→ 引导翻到第3张
  - 每张图末尾留悬念（「接下来才是重点」）
  - 对比图把「之后」放后面（「翻到下一张看效果」）
  - 承诺-展示差（标题承诺 8 个、封面只展示 4 个 → 制造「剩余 4 个得滑进去看」的预期缺口）
- **视觉一致性**：图集整体风格统一（字体/配色/排版跨图一致）= 专业；风格跳 = 业余

#### 6. 正文排版（Body Copy Layout）

- **标题压缩**：小红书标题 ≤20 字，记录实际标题 + 压缩手法
- **分段方式**：短段（易读/年轻）vs 长段（深度/专业）
- **emoji 使用**：作为视觉分隔（年轻/亲切）vs 无 emoji（专业/高级）
- **列表 vs 段落**：列表（干货/清单感）vs 段落（故事/深度）
- **信息密度**：每段的核心信息点数量
- **口语化程度**：书面 / 口语 / 网络用语 / 方言
- **首行/首段钩子**：正文第一句是不是 hook（决定展开率）
- **CTA 位置**：结尾 CTA / 穿插 CTA / 无 CTA

### 单张独立图片（广告创意图/产品图/摄影作品/海报）

当分析对象是单张独立图片（不是图文帖子的图集），用这个专用协议。不依赖文字层和图集叙事，纯粹分析一张图为什么能抓住眼球。读 `references/single-image-atlas.md` 获取完整单图视觉分类库。

#### 1. 构图骨架（Composition Skeleton）

- **主体位置**：居中（稳定/正式）/ 偏左或偏右（动态/不对称）/ 满版（沉浸/冲击）
- **视觉重心**：观众目光第一落点在哪里（由亮度对比/色彩饱和度/线条引导决定）
- **视线引导线**：画面里有没有引导目光的线条（道路/河流/手臂/光束/几何线）
- **景深层次**：前景/中景/背景是否分层（分层 = 纵深感 = 沉浸；扁平 = 平面设计感）
- **负空间**：留白占比和位置（大面积留白 = 高级/呼吸感；满构图 = 信息密集/冲击）

#### 2. 光影叙事（Light Narrative）

- **光源类型**：自然光（真实/亲切）/ 人造光（可控/戏剧）/ 混合光
- **光源方向**：顺光（清晰/平淡）/ 侧光（立体/质感）/ 逆光（轮廓/氛围/神秘）/ 顶光（戏剧/压迫）/ 底光（恐怖/异常）
- **明暗对比度**：高对比（戏剧/冲击/焦点集中）/ 低对比（柔和/高级/均匀）
- **光质**：硬光（清晰阴影/锐利/男性化）/ 软光（柔和阴影/柔美/女性化）
- **特殊光效**：丁达尔效应/霓虹/赛博朋克光/烛光/蓝调时刻（golden hour/blue hour）—— 这些是强情绪触发器

#### 3. 色彩心理学（Color Psychology）

- **情绪色温**：暖色（亲密/食欲/温暖/安全）/ 冷色（距离/科技/冷静/专业）/ 中性（克制/高级/百搭）
- **饱和度策略**：高饱和（年轻/活力/抓眼/廉价感风险）/ 低饱和（高级/文艺/克制/莫兰迪）/ 局部饱和（主体突出/背景去饱和引导视线）
- **色彩对比**：互补色撞色（冲击/抓眼）/ 同色系渐变（和谐/高级）/ 黑白+一点亮色（经典/焦点）
- **品牌色识别**：是否运用了可识别的品牌色（辨识度/记忆锚点）
- **色彩与欲望映射**（以下为映射候选，供 L3 采纳裁决，本层不下心理结论）：
  - 红色系→激情/食欲/紧迫感/性吸引
  - 蓝色系→信任/科技/冷静/专业
  - 绿色系→自然/健康/生机/成长
  - 金色系→奢华/价值/成就/地位
  - 粉色系→温柔/浪漫/少女/可爱
  - 黑色系→高级/权威/神秘/力量
  - 白色系→纯净/简约/高端/留白

#### 4. 视觉签名（Visual Signature）

这是单图分析最有操作价值的产出——这张图区别于同类图的那个「一眼认出」的元素。

- **标志性元素**：有没有一个反复出现的视觉符号（品牌logo/标志性构图/独特道具/特殊滤镜）
- **风格指纹**：这张图的风格能不能归入一个可命名的类别（如「MUJI极简」「赛博朋克」「杂志大片」「ins博主风」「国潮」）
- **情绪锚点**：这张图传递的核心情绪用一个词概括（如「孤独」「温暖」「奢华」「自由」）
- **差异化空间**：如果要做类似图但不同，可以换哪个变量（换主体/换光向/换色调/换构图/换道具）

#### 5. 文生图复刻参数（AI Reproduction Parameters）

当用户要用 AI 文生图工具复刻这张图的「爆款感」时，提供关键参数：

- **风格描述词**：给文生图工具的风格关键词（如「editorial photography, warm tones, shallow depth of field」）
- **构图参数**：主体位置/景别/视角（俯拍/平拍/仰拍）
- **光影参数**：光源类型/方向/光质/特殊效果
- **色彩参数**：主色调/饱和度/对比度/色温
- **情绪参数**：画面传递的情绪关键词
- **负面提示词**：要避免的元素（如「no text, no watermark, no clutter」）

## 素材获取

需要下载视频时：
- TikTok / YouTube：用 `/Volumes/data/lead-miner/unified_scraper.py`（无登录 Playwright）
- 抖音 / 小红书 / Instagram：可能需要手动下载，或用已登录浏览器配合 `control-in-app-browser` / `control-chrome` skill
- 本地文件：直接分析

需要逐帧分析时：
- 用 ffmpeg 抽帧：`ffmpeg -i video.mp4 -vf fps=1 frames/%04d.jpg`（每秒1帧）
- 需要更密集时用 `fps=2`（每秒2帧）
- 抽帧后用视觉分析逐帧看

## 纪律

- 只记录视觉事实，不下心理结论（裁决权在 L3），但可产出映射候选（如色彩→欲望）供 L3 采纳
- 工艺判断必须给依据，不只下结论
- 节奏曲线用时间轴可视化，不用纯文字描述
- 如果素材不可得（只有描述），所有结论标「推测」
