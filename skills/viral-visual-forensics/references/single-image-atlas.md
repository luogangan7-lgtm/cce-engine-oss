# 单张独立图片视觉分类库

本文件是 L1 视觉取证 skill 中「单张独立图片」分析协议的参考库。
提供完整的构图、光影、色彩分类，帮助精准拆解单张图片为什么能抓住眼球。

## 一、构图类型库

### 按主体位置分

| 构图类型 | 视觉效果 | 情绪暗示 | 典型场景 |
|---------|---------|---------|---------|
| 居中对称 | 稳定/正式/权威 | 庄重/高级/仪式感 | 产品图/奢侈品/官方海报 |
| 三分法 | 自然/平衡/专业 | 舒适/和谐/可信 | 生活方式/旅行/美食 |
| 偏左/偏右不对称 | 动态/张力/现代 | 不安/好奇/前卫 | 街拍/创意广告/艺术摄影 |
| 满版铺图 | 沉浸/冲击/无法回避 | 震撼/压迫/全感官 | 旅行大片/运动/品牌主视觉 |
| 留白主导 | 高级/呼吸/文艺 | 克制/想象空间/奢侈 | 极简设计/杂志/高端品牌 |
| 对角线 | 动感/引导/速度 | 活力/方向感/叙事 | 运动品牌/美食/教程 |
| 框中框 | 聚焦/窥视/层次 | 神秘/聚焦/画中画 | 创意摄影/旅行/建筑 |
| 重复/网格 | 秩序/丰富/清单感 | 专业/信息密/系统化 | 产品矩阵/数据图/清单帖 |

### 视线引导线类型

- **显性引导线**：道路/河流/栏杆/走廊/手臂——观众目光沿线条移动
- **隐性引导线**：多人视线方向/光影方向/色彩渐变——暗示但不强迫
- **S曲线**：最优雅的引导线（河流/山路/人体曲线），让目光流动
- **汇聚线**：透视消失点（铁轨/走廊），制造纵深和聚焦
- **三角构图**：三个视觉焦点形成稳定三角形（古典绘画最常用）

### 饱和度策略

| 策略 | 视觉效果 | 情绪/定位 | 风险 |
|------|---------|---------|------|
| 全画面高饱和 | 抓眼/年轻/活力/刺激 | 年轻向/潮流/接地气 | 廉价感/视觉疲劳 |
| 全画面低饱和 | 高级/文艺/克制/质感 | 高端/审美/小众 | 不够抓眼/寡淡 |
| 主体高饱+背景低饱 | 主体突出/引导聚焦 | 专业/精致/控制感 | 需要技巧/构图要求高 |

## 四、视觉签名识别清单

判断一张图有没有「视觉签名」（可辨识的独特元素），检查以下维度：

1. **色彩签名**：有没有独特的配色组合让人一看就知道是谁（如 Wes Anderson 的粉+黄）
2. **构图签名**：有没有固定的构图习惯（如总是居中俯拍/总是对角线）
3. **光影签名**：有没有标志性的光效（如总是逆光/总是蓝调时刻）
4. **道具签名**：有没有反复出现的道具（如某个品牌的标志性产品摆放方式）
5. **字体签名**：文字叠加有没有固定字体风格（如手写体/无衬线粗体）
6. **滤镜签名**：有没有独特的后期风格（如胶片质感/青橙色调）
7. **情绪签名**：有没有一贯的情绪基调（如总是孤独/总是温暖/总是奢华）

**视觉签名 = 辨识度 = 社交货币 = 关注理由。** 没有签名的图片就是「好图但没有记忆点」。

## 五、文生图复刻参数模板

当用户要用 AI 文生图工具复刻一张图的「爆款感」时，提供以下结构化参数：

```
风格：[photography / illustration / 3D render / flat design / ...]
主体：[什么物体/人物/场景，具体描述]
构图：[主体位置 + 视角 + 景别]
光影：[光源类型 + 方向 + 光质 + 特殊效果]
色彩：[主色调 + 饱和度 + 对比度 + 色温]
情绪：[一个情绪关键词]
氛围：[环境/背景/质感描述]
负面提示词：[要避免的元素]
参考风格：[类似 XX 的风格（给方向不给具体名字）]
```

**原则**：描述「感觉」而非「复制」。目标是复刻爆款感，不是搬运原图。
