# 图文设计系统

viral-visual-forensics (L1) 图文内容的深度设计拆解库。系统化拆解封面/排版/布局/配色/图集/正文的设计语言。

---

## 一、封面模板库（Cover Templates）

小红书/Instagram 高点击封面的常见结构模式：

### 模板 1：大字冲击型
- 结构：满版图 + 超大标题文字居中或顶部
- 字数：5-12 字
- 适用：清单/盘点/强烈观点
- 示例结构：「XX 个必须知道的 XX」

### 模板 2：对比反差型
- 结构：左右分屏 or 上下分割，展示 before/after 或 A vs B
- 字数：每侧 3-8 字
- 适用：效果展示、测评、教程
- 示例结构：「普通版 vs 升级版」

### 模板 3：人像+文字型
- 结构：人物主体（半身/全身）+ 旁边或上方文字框
- 字数：8-15 字
- 适用：穿搭/美妆/生活方式/个人 IP
- 示例结构：「秋冬这样穿，回头率 200%」

### 模板 4：纯产品+卖点型
- 结构：产品居中 + 围绕产品标注卖点（箭头/气泡）
- 字数：每个卖点 3-6 字
- 适用：种草/产品推荐
- 示例结构：产品周围 3-5 个卖点标注

### 模板 5：数据/清单型
- 结构：数字突出（大号数字 + 简短说明）
- 字数：数字 + 5-10 字说明
- 适用：干货/数据/排行
- 示例结构：「TOP 10」「3 天瘦 5 斤」

### 模板 6：留白文艺型
- 结构：大量留白 + 小字 + 高质感图
- 字数：少（3-8 字）或无字
- 适用：文艺/高级/摄影/美学
- 示例结构：一张干净的照片 + 一句诗

### 模板 7：拼贴/九宫格型
- 结构：多张小图拼成一个画面
- 字数：少
- 适用：合集/清单/多产品展示
- 示例结构：9 宫格产品图 + 中心标题

## 二、字体速查（Typography Quick Reference）

### 中文字体性格

| 字体 | 性格 | 适用 |
|------|------|------|
| 思源黑体/苹方（粗） | 现代、冲击、年轻 | 标题、冲击向 |
| 思源黑体/苹方（常规） | 干净、中性、通用 | 正文、说明 |
| 思源宋体/宋体 | 文艺、高级、杂志 | 文艺、高端 |
| 楷体 | 传统、文化、正式 | 传统文化 |
| 手写体（汉仪/方正） | 亲切、个人、温度 | 个人 IP、生活 |
| 像素体/复古体 | 复古、个性、潮流 | 潮流、个性 |

### 英文字体性格

| 字体 | 性格 | 适用 |
|------|------|------|
| Helvetica/Arial（粗） | 现代、通用、冲击 | 标题 |
| Georgia/Playfair（衬线） | 优雅、杂志、高级 | 文艺、高端 |
|手写体（Brush Script） | 个性、温度、艺术 | 生活方式 |
| Monospace（等宽） | 技术、极客、代码 | 科技 |
| Condensed（窄体） | 紧凑、信息密、新闻 | 标题密 |

### 字号层级参考（小红书封面）

- 主标题：60-120px（占封面高度 15-25%）
- 副标题/卖点：30-50px
- 正文/说明：20-30px
- 大对比（主标是正文 3-4 倍）= 强冲击

## 三、配色系统（Color Systems）

### 高级感配色

- 莫兰迪色系（低饱和灰调）：文艺、质感
- 黑白灰 + 单点缀色：克制、高级
- 大地色系（棕/米/咖）：温暖、自然

### 冲击感配色

- 高饱和互补色（橙蓝/红绿/黄紫）：抓眼、对比
- 纯色大色块：年轻、潮流
- 荧光色：潮、前卫（慎用）

### 信任感配色

- 蓝色系：专业、可信、科技
- 绿色系：自然、健康、安全
- 白底为主：干净、专业

### 温暖感配色

- 暖橙/暖黄：温馨、食欲、活力
- 粉色系：少女、温柔、浪漫
- 红色：热情、喜庆、紧迫

### 对比度原则

- 文字与背景对比度 ≥ 4.5:1（WCAG AA）= 清晰可读
- 低对比（< 3:1）= 高级但费眼，仅适合大字或装饰
- 小字必须高对比，否则手机端看不清

## 四、布局原则（Layout Principles）

### 视觉层级（Visual Hierarchy）

观众看图的顺序，由设计引导：

1. **第一眼**（0.5s）：最大/最亮/最对比的元素
2. **第二眼**（1-2s）：次大的元素
3. **细读**（3s+）：文字内容

设计任务：确保第一眼抓到的是你想让观众首先注意的（通常是 hook 或主视觉）。

### 留白法则

- 留白 ≠ 空，留白是呼吸感
- 留白多：高级、文艺、聚焦
- 留白少：信息满、接地气、干货
- 四周留白（margin）统一 = 专业；忽多忽少 = 业余

### 对齐与网格

- 元素对齐到隐形网格线 = 专业
- 常见网格：三分线、黄金分割、对称中轴
- 跨图集的网格一致 = 系列感、专业
- 对齐混乱 = 业余感

### 间距系统

- 用一致的间距单位（如 8px 倍数：8/16/24/32）
- 间距统一 = 有设计感
- 间距随机 = 凑出来的感觉

## 五、图集设计（Carousel Design）

### 张数甜区

- 小红书：3-9 张（6-8 张最佳，信息量和耐心平衡）
- Instagram：3-10 张
- 太少（1-2 张）：信息不够，浪费 carousel 功能
- 太多（>10 张）：观众翻不完，后段曝光暴跌

### 图集节奏设计

**经典节奏**：
1. 封面（钩子，决定点击）
2. 引入/痛点（建立关注）
3-7. 主体内容（产品/步骤/对比/证据）
8-9. 总结 + CTA

**翻页钩子技巧**：
- 封面预告：「最后一张太绝了」
- 中间悬念：「但最让我惊喜的是…（翻页）」
- 对比前置：「先看之前（翻页）再看之后」
- 倒数感：「第 7 张是重点」

### 跨图一致性

- 同一套字体
- 同一套配色
- 同一种排版网格
- 同一种图片处理风格（滤镜/边框）
- 一致 = 系列专业感；跳 = 凑图感

## 六、正文排版（Body Copy）

### 小红书正文结构

```
[首句 hook — 决定展开率]
[空行]
[痛点/场景引入]
[空行]
[核心内容 — 分段，每段一个点]
[空行]
[总结/金句]
[空行]
[CTA — 评论/关注/收藏引导]
[话题标签]
```

### 排版技巧

- **首句必 hook**：问句/反差/数字/痛点，决定展开率
- **短段落**：手机端 2-3 行一段，不堆大段
- **emoji 分隔**：📌💡✅❌ 作为视觉锚点（年轻向）；不用 = 专业向
- **数字突出**：用阿拉伯数字不用汉字数字（「7天」>「七天」），更抓眼
- **列表化**：干货用列表，故事用段落
- **加粗/括号强调**：关键信息用【】或加粗（平台支持时）
- **CTA 明确**：评论引导（「你们觉得呢？」）/ 收藏引导（「建议先收藏」）/ 关注引导

### 标题压缩手法

小红书标题 ≤20 字（含标点）。压缩手法：
- 删虚词（的/了/吗）
- 用数字代替描述
- 符号代替连接词（「|」「—」「·」）
- 保留钩子词，删解释词

## 使用建议

- 不是每条图文都要拆全部 6 个维度，抓最突出的 2-3 个深挖
- 设计判断要关联内容定位（高级品牌用文艺配色 = 协同；接地气产品用文艺配色 = 错位）
- 跨平台差异：小红书重封面文字、Instagram 重图质、公众号重标题
- 如果是 UGC 随手拍，标注「无系统设计」，不硬套专业标准
