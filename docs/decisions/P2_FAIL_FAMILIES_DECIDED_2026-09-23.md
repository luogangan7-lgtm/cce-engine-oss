| **SET_MISMATCH** 8 张 —— 两支**有共同对象**，只因某支多给了一条指向别的东西的证据被拦 | **改资格协议 P2 → v2「见证交集」**：各支各自的对象集合取交集，非空即存在见证 x；交集外的证据**记账不拦** | 合同是 `∃x[P(x)∧Q(x)]` —— 一个**存在**量词。v1「所有证据对象恰好一个」比合同**严**，拦的是「多说了一句」而不是「对象错配」。**按合同字面执行，不按更严的实现执行** |

## ★★★ 代价，先说最贵的那条

**P2 v2 是资格协议变更，不是仪器变更；但它让 r2 的「过机械资格层」由 12/42 变 20/42 —— 这两个数「可比不可合」。**

- r2 的产物 `results/real_corpus_pilot_r2.json` **一个字节不改**（sha 由闸钉住）；12/42 仍是 v1 口径下的真读数。
- v2 口径的重算在 `results/p2_policy_v2_rescore.json`（`probes/p2_policy_v2_rescore.py`，零调用，由 r2 的 rows 现算）：PASS 12 → **20**，P2_FAIL 16 → **8**（= SUBSTRING 2 + DISJOINT 6），MALFORMED 6 不变。
- **不得**把 20/42 说成「资格层通过率提高了」—— 它是同一批证书在**更贴合同**的判据下的读数；提高的是判据的合同贴合度，不是抽取器。
- **不得**把「过机械资格层」读成「合格」：机械层只回答形式；语义（否定/归属/时态/引用层级/类型成员）**仍未验**，`is_citable_as_confirmed()` 仍恒 False。
