## 五类的成立条件（每类：成立 ⟺ … · 反例 · 怎么核 · 机器核不了什么）

前提沿用已升合同的 A 条：增量必须**关于某个对象 x**，且**不能由 x 的公开标识（型号名/品类名）本身推出**。五类是这条的**五种形状**，不是五个独立门槛；一段片段可以同时落两类。

| 类 | 成立 ⟺ | 反例（不成立） | 怎么核（可机械的部分） | 机器核不了 |
|---|---|---|---|---|
| **具体型号** | 片段把 x 从**品类**落到**一个可辨识的型号/SKU/代号**，且该型号身份是文本新给的（读者此前只知道品类） | 「hearing aids」「my aids」（只有品类）；型号名**已在对象标识里**（复述） | 片段含品类之外的专名 token（品牌+型号/数字代号），且该 token 不等于 `about` 本身 | 那个 token 是不是真型号（需要外部知识） |
| **数据** | 片段给出关于 x 的**可量化值**：数字+单位/计数/日期/价格/百分比 | 「a good while」「a lot」「much better」（模糊量） | 片段含数字或数词，且数字**紧邻**度量名词/单位 | 这个数是不是关于 x 的（对象绑定由 P2 管，不由本类管） |
| **使用细节** | 片段描述**一个具体的使用动作/设置/场景**：动词 + 具体参数或步骤（怎么戴、怎么充、开了什么模式、在什么场合） | 「I use it daily」（只有频率，无具体动作/参数）；「works great」（评价不是细节） | 片段含动作动词且带具体宾语/参数（模式名、步骤序号、场合名词） | 动作是否真实可行 |
| **纠错** | 片段**指名一个既有说法**（自己先前的、他人的、常见的）并给出**不同的值/事实**取代它 | 只给对值不指名被纠的说法（那落「数据」或「使用细节」）；「actually」一词单独不算 | 片段含对照结构：`not … but …` / `instead of` / `actually` **且**两侧各有一个可比较值 | 被纠的说法是否真的错 |
| **结构化经验** | 片段以**≥2 条并列项**组织关于 x 的经验：清单、编号、对比、先后序列 | 一句话感想；两句无并列关系的陈述 | 片段含 ≥2 个并列标记（编号/项目符/分号/`first…then`）且每项都关于同一 x | 并列项是否各自成立 |

**判定的共同规则**
1. 五类是**析取**：任一类成立 ⇒ 增量支 P 成立（合同原文括号里就是并列的五个）。
2. 每类先过 A 条（不由 x 的公开标识推出）；只报型号名却无任何关于它的陈述 ⇒ **不落具体型号**（那是复述，A 条已判死）。
3. 「怎么核」列的是**表层代理**，用于零调用预筛与降级判定，**不是**判据本身；表层过了语义未必成立 —— 这正是 r5/r6 学到的「超过零基线只证读了文本，不证读懂」。
4. 一段片段同时落多类只算**一次** P 成立，不叠加。
