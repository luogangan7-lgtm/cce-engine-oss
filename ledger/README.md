## 三、判断

**CCE 在"给定原文预测互动量"上无用，在"诊断并指导改写"上有用。**

- 预测侧：三种注入内容（九结 / 欲望+需求 / 外部先验）三次全负，最外部的那次最负（−.062）。机制：把结构化心理读出喂给已能读原文的判决器，会让它转去套先验而非直接读文本。换层、换 prompt 救不回来。
- 生成侧：主判 91.4%，CI 下界 84.2%，且不受 LLM 文本偏好污染。与站外 10 条投放（按 pain_seek playbook 写 → 5 条楼主亲回 → 2 条可观测行为改变）方向一致。
- 主体侧：聚合读出可捕获个体差异（欲望 .711 / 需求 .776），但该信息对预测无增量。**可用于画像与诊断，不可用于预测。**

## 四、方法学纪律（本轮血的教训）

1. 跨运行比较无效——基线自身波动 6.5pp。只信同场配对
2. 任何生成环节必须加长度/格式闸——11/44 条崩坏输出差点反转 C1 结论
3. 满分必须被质疑——58/58 触发对照，对照查出部分污染
4. 阈值先测方差再定——min_words 80、θ .35、中位数切档三次栽在拍脑袋
5. 配置声明的字段必须在代码中有引用——六例"定义了从没执行"，已建 consistency_check 硬闸
